# SearXNG 使用手册

本手册涵盖如何有效使用 SearXNG 进行搜索和自定义。

## 搜索语法

SearXNG 支持强大的搜索语法来优化您的查询：

### 引擎选择
- **`!` 前缀**：选择特定引擎或类别
  - `!wp paris` - 在维基百科中搜索 "paris"
  - `!images Wau Holland` - 搜索 "Wau Holland" 的图片
  - `!news climate change` - 在新闻引擎中搜索 "climate change"

### 语言选择
- **`:` 前缀**：选择搜索语言
  - `:fr !wp Wau Holland` - 在法语维基百科中搜索 "Wau Holland"
  - `:de climate change` - 用德语搜索 "climate change"

### 外部 Bang
- **`!!` 前缀**：直接重定向到外部服务
  - `!!youtube cats` - 直接重定向到 YouTube 搜索 "cats"

### 特殊查询
SearXNG 支持各种特殊查询功能：
- `random uuid` - 生成随机 UUID
- `avg 123 548` - 计算数字的平均值
- `user-agent` - 显示您当前的用户代理
- 哈希函数：`md5 text`、`sha1 text`、`sha256 text`
- 单位转换：`100 USD in EUR`、`10 km in miles`

## 配置的搜索引擎

SearXNG 配置了 **250 个搜索引擎**，默认启用了 **96 个**。引擎按类别组织：

### 类别
- **通用**：标准网页搜索引擎
- **图片**：图片搜索服务
- **视频**：视频搜索平台
- **新闻**：新闻聚合服务
- **地图**：地图和位置服务
- **音乐**：音乐搜索和流媒体
- **IT**：技术和编程资源
- **科学**：学术和科学数据库
- **文件**：文件共享和文档搜索
- **社交媒体**：社交平台搜索

### 子组
每个类别包含子组以进行更具体的搜索：
- 书籍、货币、翻译、网页、维基媒体等

## 界面自定义

### 首选项
通过设置图标访问首选项来自定义：
- **默认搜索语言**
- **启用的搜索引擎**
- **结果显示选项**
- **隐私设置**
- **主题和外观**

### 插件
SearXNG 包含有用的插件：
- **计算器**：执行数学计算
- **哈希**：生成各种哈希值
- **自我信息**：显示客户端信息
- **时区**：在时区之间转换
- **Tor 检查**：验证 Tor 连接
- **单位转换器**：在测量单位之间转换

## 隐私特性

### 匿名搜索
- 所有搜索默认都是匿名的
- 无 Cookie 或跟踪脚本
- IP 地址不会被记录（在正确配置的实例中）

### 结果清理
- URL 被清理掉跟踪参数
- 引荐信息被剥离
- 第三方脚本被阻止

## 高级用法

### API 访问
SearXNG 提供简单的 API 用于程序化访问：
```
GET /search?q=your_query&format=json
```

### 自定义引擎
您可以通过修改 `settings.yml` 文件添加自定义搜索引擎：
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### 键盘快捷键
- **`/`**：聚焦搜索输入框
- **`Esc`**：清除搜索或关闭对话框
- **`Enter`**：提交搜索
- **`Ctrl+Enter`**：在新标签页中打开结果

本综合手册应该帮助您充分利用 SearXNG 体验，同时保持完全的隐私和对搜索活动的控制。
