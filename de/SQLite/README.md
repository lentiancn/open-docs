## Über SQLite

SQLite ist eine C-Bibliothek, die eine kleine, schnelle, eigenständige, hochzuverlässige und vollständige SQL-Datenbank-Engine implementiert. SQLite ist die meistverwendete Datenbank-Engine der Welt und in alle Mobiltelefone sowie die meisten Computer integriert.

## Lizenz

SQLite befindet sich in der Public Domain und kann für jeden Zweck, kommerziell oder privat, kostenlos verwendet werden.
