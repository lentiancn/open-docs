# Installationsanleitung für SQLite

## Verfügbare Pakete

SQLite bietet verschiedene Download-Optionen für unterschiedliche Plattformen und Anwendungsfälle.

### Quellcode-Pakete

#### Vollständiger Quellcode-Baum
- **Datei**: `sqlite-src-3510300.zip` (13,55 MiB)
- Enthält den vollständigen kanonischen Quellcode-Baum für SQLite Version 3.51.3, einschließlich Testfällen und Erweiterungen
- Dies ist der Originalquellcode unter Versionskontrolle zum Zeitpunkt der Veröffentlichung

#### Amalgamation (Zusammengeführter Quellcode)
- **Datei**: `sqlite-amalgamation-3510300.zip` (2,74 MiB)
- C-Quellcode als Amalgamation (zusammengeführte Dateien)
- Ideal für die einfache Integration in bestehende Projekte

#### Autoconf-Paket
- **Datei**: `sqlite-autoconf-3510300.tar.gz` (3,06 MiB)
- C-Quellcode als Amalgamation mit zusätzlichem "configure"-Skript
- Perfekt für Unix/Linux-Systeme mit automatischer Konfiguration

### Dokumentation
- **Datei**: `sqlite-doc-3510300.zip` (11,10 MiB)
- Dokumentation als Bundle statischer HTML-Dateien

## Vorkompilierte Binärdateien

### Für Android
- **Datei**: `sqlite-android-3510300.aar` (3,43 MiB)
- Vorkompilierte Android-Bibliothek mit Java-Bindings
- Kann direkt in jedes Android Studio-Projekt integriert werden

### Für Linux
- **Datei**: `sqlite-tools-linux-x64-3510300.zip` (3,99 MiB)
- Befehlszeilentools für Linux auf x64-Architektur
- Enthält: 
  - SQLite-Befehlszeilen-Shell
  - sqldiff (Datenbank-Vergleichstool)
  - sqlite3_analyzer (Datenbank-Analysetool)
  - sqlite3_rsync (Remote-Kopierwerkzeug)

### Für Mac OS X
- **ARM64**: `sqlite-tools-osx-arm64-3510300.zip` (4,31 MiB)
- **x64**: `sqlite-tools-osx-x64-3510300.zip` (4,22 MiB)
- Befehlszeilentools für Mac OS X
- **Hinweis**: Diese Binärdateien sind nicht signiert. Nach der Installation müssen Sie folgenden Befehl ausführen:
  ```bash
  xattr -d com.apple.quarantine <programmname>
  ```

### Für Windows
- **ARM64 DLL**: `sqlite-dll-win-arm64-3510300.zip` (1,03 MiB)
- **x64 DLL**: `sqlite-dll-win-x64-3510300.zip` (1,29 MiB)
- **x86 DLL**: `sqlite-dll-win-x86-3510300.zip` (1,03 MiB)
- **x64 Tools**: `sqlite-tools-win-x64-3510300.zip` (6,14 MiB)
  - Enthält die Befehlszeilen-Shell und zusätzliche Werkzeuge

### WebAssembly & JavaScript
- **Datei**: `sqlite-wasm-3510300.zip` (662,48 KiB)
- Vorkompiliertes Bundle von sqlite3.wasm und JavaScript-APIs
- Fertig für die Verwendung in Webanwendungen

## Installation auf verschiedenen Systemen

### Linux (über Paketmanager)
Die meisten Linux-Distributionen bieten SQLite über ihre Paketmanager an:

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install sqlite3 libsqlite3-dev
```

**CentOS/RHEL/Fedora:**
```bash
# CentOS/RHEL
sudo yum install sqlite sqlite-devel

# Fedora
sudo dnf install sqlite sqlite-devel
```

### macOS (mit Homebrew)
```bash
brew install sqlite3
```

### Windows
1. Laden Sie das entsprechende Windows-Paket herunter
2. Extrahieren Sie die ZIP-Datei in ein Verzeichnis Ihrer Wahl
3. Fügen Sie das Verzeichnis zu Ihrem PATH hinzu (optional)
4. Führen Sie `sqlite3.exe` aus der Kommandozeile aus

## Kompilieren aus dem Quellcode

Für fortgeschrittene Benutzer, die SQLite aus dem Quellcode kompilieren möchten:

1. Laden Sie das `sqlite-autoconf`-Paket herunter
2. Extrahieren Sie das Archiv
3. Führen Sie die folgenden Befehle aus:
   ```bash
   ./configure
   make
   sudo make install
   ```

Alternativ können Sie das Amalgamation-Paket verwenden und `sqlite3.c` direkt in Ihr Projekt integrieren.

## Überprüfung der Installation

Nach der Installation können Sie die korrekte Funktionsweise überprüfen:

```bash
sqlite3 --version
```

Dies sollte die installierte SQLite-Version anzeigen.
