# Oracle Database 安裝指南

## Oracle Database 19c 安裝

### 系統需求

#### 作業系統支援
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### 硬體需求
- **記憶體**：至少 2GB RAM（建議 4GB 或更多）
- **磁碟空間**：至少 6.5GB 可用空間（企業版）
- **處理器**：支援的作業系統對應的處理器架構

### 安裝步驟

#### 1. 下載軟體
從 Oracle 軟體下載中心取得 Oracle Database 19c 安裝包：
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. 準備系統環境
```bash
# Linux 系統範例
# 建立 oracle 使用者和群組
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# 設定核心參數
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# 設定使用者限制
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. 執行安裝程式
```bash
# 解壓縮安裝包並執行安裝程式
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. 圖形化安裝精靈
- 選擇安裝類型（桌面類、伺服器類）
- 設定資料庫識別（全域資料庫名稱、SID）
- 設定管理密碼
- 埃及 root 腳本
- 完成安裝

### 免費版本安裝
Oracle Database Free (19c) 提供免費版本，可透過 Docker 快速部署：
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Oracle Database 26ai 安裝

Oracle Database 26ai 為最新版本，安裝指南請參考 Oracle 官方文件：
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### 容器化部署
Oracle Database 26ai 支援現代化的容器化部署方式：
```bash
# Docker 部署範例（具體映像檔名稱請參考官方文件）
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## 雲服務部署

### Oracle Cloud Infrastructure (OCI)
- 在 OCI 控制台中選擇 Database 服務
- 選擇 Oracle Database 版本（19c 或 26ai）
- 設定計算實體和儲存
- 自動完成安裝和設定

### 其他雲端提供者
- AWS RDS for Oracle
- Azure Database for Oracle
- Google Cloud 的 Oracle 解決方案

## 故障排除

### 常見問題
- **權限問題**：確保 oracle 使用者具有正確的檔案和目錄權限
- **連接埠衝突**：預設監聽連接埠 1521，確保連接埠未被佔用
- **記憶體不足**：調整 SGA 和 PGA 記憶體參數
- **字元集問題**：在安裝時正確選擇資料庫字元集

### 日誌位置
- 安裝日誌：`$ORACLE_BASE/cfgtoollogs/dbca/`
- 資料庫警報日誌：`$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
