# Oracle Database

Oracle Database ist ein Enterprise-gradiges relationales Datenbankmanagementsystem, das von Oracle Corporation entwickelt wurde.

## Dokumentationsversionen

- **Oracle Database 26ai** - Neueste Version (veröffentlicht 2026)
- **Oracle Database 19c** - Langzeit-Support-Version

## Dokumentationsstruktur

1. **Einführung** - Übersicht und Hauptmerkmale von Oracle Database
2. **Installationsanleitung** - Detaillierte Installationsschritte und Systemanforderungen
3. **Benutzerhandbuch** - Vollständige SQL-, PL/SQL-Programmierung und Verwaltungsvorgänge
4. **Häufig gestellte Fragen** - Häufige Fragen und Fehlerbehebung

## Offizielle Ressourcen

- Offizielle Dokumentation: https://docs.oracle.com/
