# Yarn インストールガイド

## Yarn 4+ (モダンバージョン) インストール

### 推奨インストール方法 (Corepackを使用)

Corepack は中間ツールで、プロジェクトごとにパッケージマネージャーのバージョンを設定できます：

```bash
# Corepack をグローバルにインストール
npm install -g corepack

# 新しいプロジェクトを初期化 (Yarn Berryを使用)
yarn init -2
```

### Yarn の更新

いつでも最新バージョンに更新するには、以下のコマンドを実行します：

```bash
yarn set version stable
yarn install
```

Yarn はプロジェクトを最新の安定版バイナリを使用するように設定します。

### Canary バージョンの使用

Yarn は頻繁にリリース候補ビルドを提供しています。安定チャンネルではまだリリースされていない機能が必要な場合：

```bash
yarn set version canary
```

これらのビルドは非常に安定しており、通常のチャンネルとの唯一の違いは、新しい破壊的変更を実装する際にメジャーバージョン間でより段階的な移行を行うことです。

### master から最新ビルドをインストール

リリース候補にも含まれていない、非常に新しい Yarn バージョンをテストしたい場合：

```bash
# master ブランチからクローン、ビルド、インストール
yarn set version from sources

# 特定のPRをテスト
yarn set version from sources --branch 1211
```

**注記**: `yarn set version from sources` コマンドは Corepack を利用できず、Yarn バイナリを `.yarn/releases` フォルダ内に保存し、プロジェクトの `.yarnrc.yml` ファイルから参照する必要があります。

## Yarn Classic (v1) インストール

### npm 経由でのインストール (推奨)

Node.js と一緒にバンドルされている npm パッケージマネージャー経由での Yarn インストールが推奨されます：

```bash
# Yarn Classic をインストールまたはアップグレード
npm install --global yarn
```

### インストールの確認

インストール後、以下のコマンドで Yarn が正しくインストールされているか確認します：

```bash
yarn --version
```

## バージョン選択の推奨事項

- **新規プロジェクト**: 最新の機能と改善を享受するために Yarn 4+ (モダンバージョン) の使用を推奨
- **既存プロジェクト**: 
  - すでに Yarn Classic を使用している場合は継続可能
  - より良いパフォーマンスと機能のためにモダンバージョンへの移行を検討
- **エンタープライズ環境**: モダンバージョンはワークスペースサポートと安定性保証を提供

## システム要件

- **Node.js**: すべてのバージョンで Node.js 環境が必要
- **npm**: Yarn Classic はグローバルインストールに npm を必要とする
- **Corepack**: モダンバージョンではバージョン管理に Corepack の使用を推奨

> **注記**: このドキュメントは yarnpkg.com および classic.yarnpkg.com 公式サイトの内容に基づいています。
