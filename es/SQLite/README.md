# SQLite

SQLite es una biblioteca de software que implementa un motor de base de datos SQL pequeño, rápido, autónomo, de alta confiabilidad y sin configuración.

## Características principales

- **Autónomo**: No requiere un servidor separado. La base de datos completa se almacena en un único archivo en el disco.
- **Sin configuración**: No hay necesidad de configurar o administrar. Simplemente enlaza la biblioteca con tu aplicación.
- **Transaccional**: Soporta transacciones ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad).
- **Multiplataforma**: Funciona en Windows, Linux, macOS, Android, iOS y muchos otros sistemas operativos.
- **Código fuente público**: El código fuente completo está en dominio público.
