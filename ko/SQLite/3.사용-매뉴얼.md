# SQLite 사용 매뉴얼

이 문서는 SQLite 명령줄 인터페이스(CLI)와 기본적인 SQL 사용법에 대해 설명합니다.

## 1. SQLite CLI 시작하기

### 기본 사용법
```bash
# 새 데이터베이스 파일 생성 또는 기존 파일 열기
sqlite3 database.db

# 메모리 데이터베이스 사용 (세션 종료 시 삭제됨)
sqlite3

# ZIP 아카이브 열기 (DOCX, JAR 등 ZIP 기반 포맷 지원)
sqlite3 document.docx
```

시작하면 다음과 같은 프롬프트가 표시됩니다:
```
SQLite version 3.x.x YYYY-MM-DD HH:MM:SS
Enter ".help" for usage hints.
sqlite>
```

### Windows에서 더블클릭 실행
Windows에서 `sqlite3.exe`를 더블클릭하면 임시 메모리 데이터베이스가 열립니다. 영구적인 디스크 파일을 사용하려면 다음 명령어를 사용하세요:
```sql
sqlite> .open ex1.db
```

전체 경로를 사용하여 파일 위치를 명확히 지정하는 것이 좋습니다:
```sql
sqlite> .open c:/work/ex1.db
```

## 2. 기본 SQL 명령어

### 테이블 생성 및 조작
```sql
-- 테이블 생성
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    age INTEGER
);

-- 데이터 삽입
INSERT INTO users (name, email, age) VALUES ('홍길동', 'hong@example.com', 30);
INSERT INTO users VALUES (NULL, '김철수', 'kim@example.com', 25);

-- 데이터 조회
SELECT * FROM users;
SELECT name, email FROM users WHERE age > 25;

-- 데이터 업데이트
UPDATE users SET age = 31 WHERE name = '홍길동';

-- 데이터 삭제
DELETE FROM users WHERE age < 20;
```

**중요**: SQL 문장은 세미콜론(`;`)으로 끝나야 합니다. 세미콜론을 생략하면 계속 입력을 기다리는 프롬프트(`...>`)가 표시됩니다.

## 3. 도트 명령어(Dot Commands)

SQLite CLI는 점(`.`)으로 시작하는 특수 명령어를 제공합니다. 이 명령어들은 SQLite 라이브러리가 아닌 CLI 프로그램 자체에서 처리됩니다.

### 주요 도트 명령어

#### 데이터베이스 관리
- `.open FILENAME` - 데이터베이스 파일 열기
- `.save FILENAME` - 현재 데이터베이스를 파일로 저장
- `.databases` - 연결된 데이터베이스 목록 표시
- `.tables [PATTERN]` - 테이블 목록 표시
- `.schema [TABLE]` - 스키마 정보 표시

#### 출력 형식 제어
- `.mode MODE` - 출력 모드 설정 (list, column, table, csv, json 등)
- `.headers on|off` - 열 헤더 표시 여부
- `.separator STRING` - 열 구분자 설정
- `.width NUM1 NUM2...` - 열 너비 설정

#### 파일 입출력
- `.output FILE` - 출력을 파일로 리디렉션
- `.once FILE` - 다음 명령어의 출력만 파일로 저장
- `.read FILE` - SQL 스크립트 파일 실행
- `.import FILE TABLE` - 데이터 파일을 테이블로 가져오기

#### 기타 유용한 명령어
- `.help [TOPIC]` - 도움말 표시
- `.quit` 또는 `.exit` - 프로그램 종료
- `.timer on|off` - SQL 실행 시간 측정
- `.show` - 현재 설정 값 표시

### 출력 모드 예제
```sql
-- 기본 list 모드 (파이프 구분자)
sqlite> .mode list
sqlite> SELECT * FROM users;
홍길동|hong@example.com|31
김철수|kim@example.com|25

-- column 모드 (정렬된 열)
sqlite> .mode column
sqlite> .headers on
sqlite> SELECT * FROM users;
name        email             age
----------  ----------------  ---
홍길동      hong@example.com  31
김철수      kim@example.com   25

-- CSV 모드
sqlite> .mode csv
sqlite> .headers on
sqlite> SELECT * FROM users;
name,email,age
"홍길동","hong@example.com",31
"김철수","kim@example.com",25

-- JSON 모드
sqlite> .mode json
sqlite> SELECT * FROM users;
{"columns":["name","email","age"],"rows":[["홍길동","hong@example.com",31],["김철수","kim@example.com",25]]}
```

## 4. 데이터베이스 스키마 조회

### 테이블 정보 확인
```sql
-- 모든 테이블 목록
.tables

-- 특정 패턴의 테이블만 표시
.tables user%

-- 전체 스키마 보기
.schema

-- 특정 테이블의 스키마만 보기
.schema users

-- 인덱스 목록
.indexes
.indexes users
```

### 내부 스키마 테이블
SQLite는 데이터베이스 스키마 정보를 `sqlite_schema` 테이블에 저장합니다:
```sql
-- 모든 테이블과 뷰 목록
SELECT name FROM sqlite_schema 
WHERE type IN ('table','view') AND name NOT LIKE 'sqlite_%'
ORDER BY name;

-- 모든 객체의 SQL 정의
SELECT sql FROM sqlite_schema ORDER BY tbl_name, type DESC, name;
```

## 5. 파일 입출력 기능

### 파일에서 데이터 읽기/쓰기
SQLite CLI는 두 개의 내장 SQL 함수를 제공합니다:

```sql
-- 파일 내용을 BLOB으로 읽기
SELECT readfile('image.jpg');

-- BLOB을 파일로 쓰기
SELECT writefile('output.jpg', image_data) FROM images WHERE id=1;
```

### 텍스트 편집 기능
대용량 텍스트 필드를 편집할 수 있는 `edit()` 함수:
```sql
-- 문서 본문을 외부 편집기로 편집
UPDATE docs SET body = edit(body) WHERE name = 'report-15';

-- 이미지 파일을 외부 프로그램으로 편집
UPDATE pics SET img = edit(img, 'gimp') WHERE id = 'pic-1542';
```

## 6. 데이터 가져오기 및 내보내기

### CSV 데이터 가져오기
```sql
-- CSV 파일을 테이블로 가져오기
.mode csv
.import data.csv users

-- 첫 행이 열 이름인 경우
.import --csv --skip 1 data.csv users
```

### 데이터 내보내기
```sql
-- CSV로 내보내기
.headers on
.mode csv
.once output.csv
SELECT * FROM users;

-- 전체 데이터베이스를 SQL 스크립트로 덤프
.dump

-- 압축된 백업 생성
-- 셸에서: sqlite3 database.db .dump | gzip -c > backup.sql.gz
```

## 7. ZIP 아카이브 작업

SQLite CLI는 ZIP 아카이브를 가상의 데이터베이스로 열 수 있습니다:
```sql
-- DOCX 파일 열기
sqlite3 document.docx

-- ZIP 내 파일 목록 확인
.schema
-- 출력: CREATE VIRTUAL TABLE zip USING zipfile('document.docx')

-- ZIP 내 파일 정보 조회
SELECT name, sz, mtime FROM zip;

-- ZIP에서 파일 추출
SELECT writefile(name, data) FROM zip WHERE name LIKE 'word/%';
```

## 8. 확장 기능 로드

런타임에 확장 기능을 로드할 수 있습니다:
```sql
-- 확장 기능 로드
.load /path/to/extension

-- 진입점 지정 (선택사항)
.load /path/to/extension entry_function
```

유용한 확장 기능 소스 코드는 SQLite 소스 트리의 `ext/misc` 디렉토리에서 찾을 수 있습니다.

## 9. 문제 해결

### 성능 최적화
- 여러 INSERT 문을 하나의 트랜잭션으로 그룹화:
  ```sql
  BEGIN;
  INSERT INTO ...;
  INSERT INTO ...;
  COMMIT;
  ```

### 데이터 복구
데이터베이스가 손상된 경우:
```sql
-- 가능한 데이터 복구 시도
.recover

-- 무결성 검사
PRAGMA integrity_check;
PRAGMA quick_check;
```

### 디버깅 도구
- `.eqp on` - 자동으로 EXPLAIN QUERY PLAN 실행
- `.trace` - 실행되는 각 SQL 문 출력
- `.stats on` - 실행 통계 표시
