# SearXNG

SearXNG is a free internet metasearch engine that protects your privacy by aggregating results from 250+ search services without tracking or profiling users.

## Official Resources
- **Website**: https://searxng.org
- **Documentation**: https://docs.searxng.org  
- **Source Code**: https://github.com/searxng/searxng
- **Public Instances**: https://searx.space

## Key Features
- Privacy-first metasearch engine
- No user tracking or data collection
- Supports Tor for enhanced anonymity
- Highly customizable and configurable
- Open source and community-driven
