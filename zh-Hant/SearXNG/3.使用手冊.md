# SearXNG 使用手冊

本手冊涵蓋如何有效使用 SearXNG 進行搜尋和自訂。

## 搜尋語法

SearXNG 支援強大的搜尋語法來最佳化您的查詢：

### 引擎選擇
- **`!` 前綴**：選擇特定引擎或類別
  - `!wp paris` - 在維基百科中搜尋 "paris"
  - `!images Wau Holland` - 搜尋 "Wau Holland" 的圖片
  - `!news climate change` - 在新聞引擎中搜尋 "climate change"

### 語言選擇
- **`:` 前綴**：選擇搜尋語言
  - `:fr !wp Wau Holland` - 在法語維基百科中搜尋 "Wau Holland"
  - `:de climate change` - 用德語搜尋 "climate change"

### 外部 Bang
- **`!!` 前綴**：直接重新導向到外部服務
  - `!!youtube cats` - 直接重新導向到 YouTube 搜尋 "cats"

### 特殊查詢
SearXNG 支援各種特殊查詢功能：
- `random uuid` - 產生隨機 UUID
- `avg 123 548` - 計算數字的平均值
- `user-agent` - 顯示您目前的使用者代理
- 雜湊函數：`md5 text`、`sha1 text`、`sha256 text`
- 單位轉換：`100 USD in EUR`、`10 km in miles`

## 設定的搜尋引擎

SearXNG 設定了 **250 個搜尋引擎**，預設啟用了 **96 個**。引擎按類別組織：

### 類別
- **通用**：標準網頁搜尋引擎
- **圖片**：圖片搜尋服務
- **影片**：影片搜尋平台
- **新聞**：新聞聚合服務
- **地圖**：地圖和位置服務
- **音樂**：音樂搜尋和串流媒體
- **IT**：技術和程式設計資源
- **科學**：學術和科學資料庫
- **檔案**：檔案共享和文件搜尋
- **社群媒體**：社交平台搜尋

### 子群組
每個類別包含子群組以進行更具體的搜尋：
- 書籍、貨幣、翻譯、網頁、維基媒體等

## 介面自訂

### 首選項
透過設定圖示存取首選項來自訂：
- **預設搜尋語言**
- **啟用的搜尋引擎**
- **結果顯示選項**
- **隱私設定**
- **主題和外觀**

### 外掛程式
SearXNG 包含有用的外掛程式：
- **計算機**：執行數學計算
- **雜湊**：產生各種雜湊值
- **自我資訊**：顯示客戶端資訊
- **時區**：在時區之間轉換
- **Tor 檢查**：驗證 Tor 連線
- **單位轉換器**：在測量單位之間轉換

## 隱私特性

### 匿名搜尋
- 所有搜尋預設都是匿名的
- 無 Cookie 或追蹤指令碼
- IP 位址不會被記錄（在正確設定的實例中）

### 結果清理
- URL 被清理掉追蹤參數
- 推薦資訊被剝離
- 第三方指令碼被阻止

## 進階用法

### API 存取
SearXNG 提供簡單的 API 用於程式化存取：
```
GET /search?q=your_query&format=json
```

### 自訂引擎
您可以透過修改 `settings.yml` 檔案新增自訂搜尋引擎：
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### 鍵盤快速鍵
- **`/`**：聚焦搜尋輸入框
- **`Esc`**：清除搜尋或關閉對話框
- **`Enter`**：提交搜尋
- **`Ctrl+Enter`**：在新分頁中開啟結果

本綜合手冊應該幫助您充分利用 SearXNG 體驗，同時保持完全的隱私和對搜尋活動的控制。
