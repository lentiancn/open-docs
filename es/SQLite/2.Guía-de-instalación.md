# Guía de Instalación de SQLite

## Instalación en diferentes sistemas operativos

### Linux

#### Ubuntu/Debian
```bash
sudo apt-get update
sudo apt-get install sqlite3 libsqlite3-dev
```

#### CentOS/RHEL/Fedora
```bash
# CentOS/RHEL
sudo yum install sqlite sqlite-devel

# Fedora
sudo dnf install sqlite sqlite-devel
```

### macOS

#### Usando Homebrew
```bash
brew install sqlite3
```

#### Preinstalado
SQLite generalmente viene preinstalado en macOS. Puede verificar la versión con:
```bash
sqlite3 --version
```

### Windows

#### Descarga binaria
1. Visite https://www.sqlite.org/download.html
2. Descargue los siguientes archivos:
   - `sqlite-tools-win32-x86-*.zip` (herramientas de línea de comandos)
   - `sqlite-dll-win32-x86-*.zip` (biblioteca DLL, si es necesario)
3. Extraiga los archivos ZIP en una carpeta de su elección
4. Agregue la carpeta al PATH del sistema

#### Usando Chocolatey
```cmd
choco install sqlite
```

#### Usando Scoop
```cmd
scoop install sqlite
```

## Verificación de la instalación

Después de la instalación, verifique que SQLite esté correctamente instalado ejecutando:

```bash
sqlite3 --version
```

Esto debería mostrar la versión instalada de SQLite.

## Compilación desde el código fuente

Si necesita compilar SQLite desde el código fuente:

1. Descargue el código fuente amalgamado de https://www.sqlite.org/download.html
2. El archivo principal es `sqlite-amalgamation-*.zip`
3. Extraiga el archivo y compile:

```bash
# Linux/macOS
gcc -o sqlite3 shell.c sqlite3.c -lpthread -ldl

# Windows (con MinGW)
gcc -o sqlite3.exe shell.c sqlite3.c
```

## Integración con lenguajes de programación

### Python
SQLite está incluido en la biblioteca estándar de Python:
```python
import sqlite3
```

### Java
Use el controlador JDBC de SQLite:
```xml
<!-- Maven -->
<dependency>
    <groupId>org.xerial</groupId>
    <artifactId>sqlite-jdbc</artifactId>
    <version>3.42.0.0</version>
</dependency>
```

### Node.js
Instale el paquete sqlite3:
```bash
npm install sqlite3
```

### C/C++
Enlace directamente con la biblioteca SQLite:
```c
#include "sqlite3.h"
```

## Primeros pasos

Una vez instalado, puede crear su primera base de datos:

```bash
# Crear/abrir una base de datos
sqlite3 mi_base_de_datos.db

# Dentro del prompt de SQLite
sqlite> CREATE TABLE usuarios (id INTEGER PRIMARY KEY, nombre TEXT);
sqlite> INSERT INTO usuarios (nombre) VALUES ('Juan');
sqlite> SELECT * FROM usuarios;
sqlite> .quit
```

Para obtener más información detallada sobre la instalación y uso, visite: https://www.sqlite.org/
