## SQLite とは

SQLite は軽量で自己完結型の SQL データベースエンジンです。以下の特徴があります：

- **サーバーレス**: アプリケーションに直接組み込まれるライブラリ
- **ゼロ設定**: インストールや管理が不要
- **トランザクション安全**: ACID 準拠のトランザクションをサポート
- **クロスプラットフォーム**: 多くのオペレーティングシステムで動作
- **パブリックドメイン**: 商用・非商用問わず自由に使用可能
