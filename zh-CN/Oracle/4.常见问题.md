# Oracle Database 常见问题

## 安装相关问题

### Q1: 安装过程中出现权限错误怎么办？
**A**: 确保使用 oracle 用户执行安装，并且该用户属于 oinstall 和 dba 组。检查 `/etc/passwd` 和 `/etc/group` 文件确认用户和组配置正确。

### Q2: 安装时提示内存不足如何解决？
**A**: Oracle Database 需要足够的内存。可以：
- 增加系统物理内存
- 调整内核参数：`kernel.shmmax` 和 `kernel.shmall`
- 在安装时选择较小的配置选项（如桌面类安装）

### Q3: 如何在 Docker 中运行 Oracle Database？
**A**: Oracle 提供官方 Docker 镜像：
```bash
# Oracle Database Free (19c)
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0

# 注意：首次启动可能需要较长时间初始化
```

## 连接问题

### Q4: ORA-12541: TNS:no listener 错误如何解决？
**A**: 此错误表示监听器未运行。解决方案：
```bash
# 启动监听器
lsnrctl start

# 检查监听器状态
lsnrctl status

# 确保监听器配置正确（listener.ora 文件）
```

### Q5: ORA-12170: TNS:Connect timeout occurred 错误？
**A**: 网络连接超时，检查：
- 数据库服务器是否可达（ping 测试）
- 防火墙是否阻止 1521 端口
- 监听器是否在正确的 IP 地址上监听
- tnsnames.ora 配置是否正确

### Q6: 如何重置 sys/system 密码？
**A**: 使用 orapwd 工具重置密码文件：
```bash
# 停止数据库
sqlplus / as sysdba
SHUTDOWN IMMEDIATE;

# 重新创建密码文件
orapwd file=$ORACLE_HOME/dbs/orapw$ORACLE_SID password=new_password force=y

# 启动数据库
STARTUP;
```

## 性能问题

### Q7: 查询很慢如何优化？
**A**: 性能优化步骤：
1. **分析执行计划**：使用 `EXPLAIN PLAN` 查看查询执行路径
2. **检查索引**：确保 WHERE 子句中的列有适当索引
3. **收集统计信息**：`EXEC DBMS_STATS.GATHER_TABLE_STATS`
4. **SQL 调优顾问**：使用 Oracle SQL Tuning Advisor
5. **检查等待事件**：查询 `v$session_wait` 视图

### Q8: 如何查看当前正在执行的慢查询？
**A**: 查询 v$session 和 v$sql 视图：
```sql
SELECT s.sid, s.serial#, s.username, s.status, 
       q.sql_text, q.elapsed_time, q.cpu_time
FROM v$session s, v$sql q
WHERE s.sql_id = q.sql_id
  AND s.status = 'ACTIVE'
  AND q.elapsed_time > 1000000; -- 执行时间超过1秒
```

### Q9: 内存使用过高怎么办？
**A**: 调整内存参数：
- **SGA_TARGET**: 系统全局区总大小
- **PGA_AGGREGATE_TARGET**: 程序全局区总大小
- **MEMORY_TARGET**: 自动内存管理（11g 及以上）

```sql
-- 查看当前内存使用
SHOW PARAMETER memory;
SHOW PARAMETER sga;
SHOW PARAMETER pga;

-- 动态调整（需要 sysdba 权限）
ALTER SYSTEM SET MEMORY_TARGET = 4G SCOPE=BOTH;
```

## 备份恢复问题

### Q10: RMAN 备份失败如何处理？
**A**: 常见 RMAN 问题排查：
- **空间不足**：检查备份目标目录空间
- **权限问题**：确保 oracle 用户对备份目录有写权限
- **归档日志缺失**：确保所有归档日志都可用
- **通道配置**：检查 RMAN 通道配置是否正确

### Q11: 如何恢复误删除的表？
**A**: 恢复方法取决于备份策略：
1. **闪回表**（如果启用）：
   ```sql
   FLASHBACK TABLE table_name TO BEFORE DROP;
   ```
2. **RMAN 时间点恢复**：
   ```rman
   RUN {
       SET UNTIL TIME "TO_DATE('2026-03-30 08:00:00', 'YYYY-MM-DD HH24:MI:SS')";
       RESTORE DATABASE;
       RECOVER DATABASE;
   }
   ```
3. **Data Pump 导入**：从最近的导出文件恢复

## 版本差异问题

### Q12: Oracle Database 19c 和 26ai 有什么主要区别？
**A**: 主要区别包括：
- **AI 功能**：26ai 集成了 AI 驱动的自动化管理功能
- **性能优化**：26ai 提供更智能的资源管理和查询优化
- **安全性**：26ai 增强了安全监控和威胁检测能力
- **云原生支持**：26ai 对容器化和云环境有更好的支持

### Q13: 从 19c 升级到 26ai 需要注意什么？
**A**: 升级注意事项：
- **兼容性检查**：使用 Database Upgrade Assistant (DBUA) 进行预检查
- **备份**：升级前必须完整备份数据库
- **测试环境**：先在测试环境验证升级过程
- **应用兼容性**：确保应用程序与新版本兼容
- **许可证**：确认新版本的许可证要求

## 日常维护

### Q14: 如何清理归档日志？
**A**: 归档日志清理方法：
```bash
# 使用 RMAN 删除已备份的归档日志
rman target /
DELETE ARCHIVELOG ALL COMPLETED BEFORE 'SYSDATE-7';

# 手动删除（不推荐，除非确定已备份）
rm $ORACLE_BASE/fast_recovery_area/*/archivelog/*.arc
```

### Q15: 表空间满了怎么办？
**A**: 表空间扩展方法：
```sql
-- 增加数据文件
ALTER TABLESPACE users ADD DATAFILE '/u01/app/oracle/oradata/ORCL/users02.dbf' SIZE 1G;

-- 扩展现有数据文件
ALTER DATABASE DATAFILE '/u01/app/oracle/oradata/ORCL/users01.dbf' RESIZE 2G;

-- 启用自动扩展
ALTER DATABASE DATAFILE '/u01/app/oracle/oradata/ORCL/users01.dbf' AUTOEXTEND ON NEXT 100M MAXSIZE UNLIMITED;
```

### Q16: 如何监控数据库健康状态？
**A**: 健康监控方法：
- **AWR 报告**：定期生成和分析 AWR 报告
- **ADDM 报告**：自动数据库诊断监视器
- **OEM**：Oracle Enterprise Manager
- **自定义脚本**：监控关键指标（会话数、锁、表空间使用率等）

## 故障排除

### Q17: 数据库无法启动怎么办？
**A**: 启动故障排查步骤：
1. **检查 alert log**：`$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
2. **检查控制文件**：确保控制文件存在且可访问
3. **检查数据文件**：确保所有数据文件存在
4. **检查参数文件**：spfile 或 pfile 配置是否正确
5. **尝试 mount 模式**：`STARTUP MOUNT` 然后逐步排查

### Q18: 出现死锁如何处理？
**A**: 死锁处理方法：
- **自动处理**：Oracle 会自动检测并终止其中一个事务
- **手动干预**：查询 `v$lock` 和 `v$session` 找到阻塞会话并 kill
  ```sql
  ALTER SYSTEM KILL SESSION 'sid,serial#' IMMEDIATE;
  ```
- **预防措施**：应用层面确保一致的访问顺序

## 许可证和成本

### Q19: Oracle Database 免费版本有哪些限制？
**A**: Oracle Database Free (19c/26ai) 限制：
- **CPU 限制**：最多 2 个 CPU
- **内存限制**：最多 2GB RAM
- **存储限制**：最多 12GB 用户数据
- **功能限制**：不包含企业版高级功能（如 RAC、Data Guard 等）

### Q20: 如何降低 Oracle 许可证成本？
**A**: 成本优化策略：
- **使用免费版本**：对于开发和小型生产环境
- **合理规划 CPU 许可**：根据实际使用情况购买
- **考虑云服务**：OCI、AWS RDS 等按需付费模式
- **定期审计**：确保许可证合规，避免超额使用
