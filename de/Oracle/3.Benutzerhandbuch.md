## Datenbankverbindung

### SQL*Plus-Verbindung
```sql
-- Lokale Verbindung
sqlplus username/password@localhost:1521/SID

-- Remote-Verbindung
sqlplus username/password@hostname:1521/service_name

-- Systemadministrator-Verbindung
sqlplus / as sysdba
```

## SQL-Grundoperationen

### Data Definition Language (DDL)
```sql
-- Tabelle erstellen
CREATE TABLE employees (
    employee_id NUMBER PRIMARY KEY,
    first_name VARCHAR2(50),
    last_name VARCHAR2(50) NOT NULL,
    email VARCHAR2(100) UNIQUE,
    hire_date DATE DEFAULT SYSDATE,
    salary NUMBER(8,2)
);

-- Tabellenstruktur ändern
ALTER TABLE employees ADD department_id NUMBER;
ALTER TABLE employees MODIFY salary NUMBER(10,2);
ALTER TABLE employees DROP COLUMN department_id;

-- Tabelle löschen
DROP TABLE employees;
```

### Data Manipulation Language (DML)
```sql
-- Daten einfügen
INSERT INTO employees (employee_id, first_name, last_name, email, salary)
VALUES (101, 'John', 'Doe', 'john.doe@example.com', 5000.00);

-- Daten abfragen
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > 4000
ORDER BY last_name;

-- Daten aktualisieren
UPDATE employees
SET salary = salary * 1.1
WHERE department_id = 10;

-- Daten löschen
DELETE FROM employees
WHERE employee_id = 101;
```

## PL/SQL-Programmierung

### Gespeicherte Prozeduren
```sql
CREATE OR REPLACE PROCEDURE update_employee_salary(
    p_employee_id IN NUMBER,
    p_new_salary IN NUMBER
)
IS
BEGIN
    UPDATE employees
    SET salary = p_new_salary
    WHERE employee_id = p_employee_id;
    
    IF SQL%ROWCOUNT = 0 THEN
        RAISE_APPLICATION_ERROR(-20001, 'Employee not found');
    END IF;
    
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END;
/
```

### Funktionen
```sql
CREATE OR REPLACE FUNCTION get_employee_name(
    p_employee_id IN NUMBER
) RETURN VARCHAR2
IS
    v_full_name VARCHAR2(101);
BEGIN
    SELECT first_name || ' ' || last_name
    INTO v_full_name
    FROM employees
    WHERE employee_id = p_employee_id;
    
    RETURN v_full_name;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RETURN NULL;
END;
/
```

### Trigger
```sql
CREATE OR REPLACE TRIGGER employees_audit_trigger
    BEFORE INSERT OR UPDATE OR DELETE ON employees
    FOR EACH ROW
DECLARE
    v_action VARCHAR2(10);
BEGIN
    IF INSERTING THEN
        v_action := 'INSERT';
    ELSIF UPDATING THEN
        v_action := 'UPDATE';
    ELSE
        v_action := 'DELETE';
    END IF;
    
    INSERT INTO employees_audit (
        employee_id, action, action_date, user_name
    ) VALUES (
        NVL(:OLD.employee_id, :NEW.employee_id),
        v_action,
        SYSDATE,
        USER
    );
END;
/
```

## Performance-Optimierung

### Index-Verwaltung
```sql
-- B-Tree-Index erstellen
CREATE INDEX idx_employees_last_name ON employees(last_name);

-- Bitmap-Index erstellen (geeignet für Spalten mit niedriger Kardinalität)
CREATE BITMAP INDEX idx_employees_department ON employees(department_id);

-- Funktionsbasierter Index erstellen
CREATE INDEX idx_employees_upper_name ON employees(UPPER(last_name));
```

### Ausführungsplananalyse
```sql
-- Ausführungsplan anzeigen
EXPLAIN PLAN FOR
SELECT * FROM employees WHERE last_name = 'Smith';

SELECT * FROM TABLE(DBMS_XPLAN.DISPLAY);
```

```sql
-- Tabellenstatistiken sammeln

-- Schema-Statistiken sammeln
EXEC DBMS_STATS.GATHER_SCHEMA_STATS('HR');
```

## Sicherung und Wiederherstellung

### RMAN-Sicherung
```bash
# Mit RMAN verbinden
rman target /

# Vollständige Datenbanksicherung
BACKUP DATABASE;

# Inkrementelle Sicherung
BACKUP INCREMENTAL LEVEL 1 DATABASE;

# Archivprotokoll-Sicherung
BACKUP ARCHIVELOG ALL;
```

### Data Pump Export/Import
```bash
# Gesamte Datenbank exportieren
expdp system/password FULL=Y DIRECTORY=DATA_PUMP_DIR DUMPFILE=full_db.dmp

# Spezifisches Schema exportieren
expdp hr/hr SCHEMAS=HR DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp

# Daten importieren
impdp system/password DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp
```

## Überwachung und Verwaltung

### Dynamische Performance-Views
```sql
-- Sitzungsinformationen anzeigen
SELECT sid, serial#, username, status, machine, program
FROM v$session
WHERE username IS NOT NULL;

-- Sperrinformationen anzeigen
SELECT session_id, lock_type, mode_held, mode_requested
FROM dba_locks;

-- Tablespace-Nutzung anzeigen
SELECT tablespace_name, 
       ROUND(SUM(bytes)/1024/1024, 2) AS size_mb,
       ROUND(SUM(maxbytes)/1024/1024, 2) AS max_size_mb
FROM dba_data_files
GROUP BY tablespace_name;
```

## Neue Funktionen von Oracle Database 26ai

Oracle Database 26ai führt KI-gesteuerte Automatisierungsfunktionen ein:
- **Automatisches SQL-Tuning**: KI analysiert Abfragemuster und optimiert automatisch
- **Vorhersagende Wartung**: Sagt potenzielle Probleme voraus und gibt Frühwarnungen
- **Intelligente Ressourcenverwaltung**: Passt dynamisch Speicher- und CPU-Zuweisung an
- **Erweiterte Sicherheitsüberwachung**: KI-gesteuerte Anomalieerkennung

Detaillierte Dokumentation zu neuen Funktionen finden Sie auf der offiziellen Oracle-Website.

## Best Practices

### Sicherheitskonfiguration
- Starke Passwortrichtlinien verwenden
- Transparente Datenverschlüsselung (TDE) aktivieren
- Feingranulare Zugriffskontrolle konfigurieren
- Datenbankaktivitäten regelmäßig prüfen

### Performance-Optimierung
- Tabellenstrukturen und Indizes angemessen gestalten
- Bind-Variablen verwenden, um Hard-Parsing zu vermeiden
- Statistiken regelmäßig sammeln
- Langsame Abfragen überwachen und optimieren

### Hochverfügbarkeit
- Angemessene Sicherungsstrategien implementieren
- Data Guard oder RAC konfigurieren
- Wiederherstellungsverfahren regelmäßig testen
- Systemgesundheitsstatus überwachen
