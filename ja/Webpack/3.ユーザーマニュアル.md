# ユーザーマニュアル

このマニュアルでは、Webpack 4 と Webpack 5 の両方向けの設定オプション、CLI の使用、およびベストプラクティスを含む Webpack のコア機能について説明します。

## 設定（Configuration）

Webpack はデフォルトで `webpack.config.js` という JavaScript ファイルを介して設定されます。このファイルは、Webpack がプロジェクトをビルドする方法を指示する設定オブジェクトをエクスポートします。

### 基本的な設定

```javascript
// Webpack 4 / Webpack 5（CommonJS）
const path = require('path');

module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

```javascript
// Webpack 5（ES Modules）
import path from 'node:path';

export default {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(import.meta.dirname, 'dist'),
  },
};
```

### 設定タイプ

Webpack は複数の設定ファイルタイプをサポートしています：

| タイプ | Webpack 4 | Webpack 5 | 説明 |
|------|-----------|-----------|------|
| CommonJS | ✅ | ✅ | `module.exports = {}` |
| ES Modules | ⚠️ 制限付き | ✅ 完全 | `export default {}` |
| TypeScript | ⚠️ ts-node 付き | ✅ ネイティブ | `.ts` ファイル |
| 複数設定 | ✅ | ✅ | 設定の配列 |

## エントリーポイント（Entry Points）

エントリーポイントは Webpack に依存関係グラフの構築を開始する場所を伝えます。

### 単一エントリー（Single Entry）

```javascript
// Webpack 4 & 5
module.exports = {
  entry: './src/index.js',
};
```

### 複数エントリー（Multiple Entries）

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    main: './src/index.js',
    vendor: './src/vendor.js',
  },
};
```

### 動的エントリー（Dynamic Entries）

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    page1: './src/page1.js',
    page2: './src/page2.js',
  },
};
```

### 配列付きエントリーオブジェクト（Entry Object with Arrays）

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    app: ['./src/index.js', './src/another.js'],
  },
};
```

## アウトプット（Output）

アウトプット設定は Webpack に生成したバンドルをどこに放出するかを指示します。

### 基本アウトプット（Basic Output）

```javascript
// Webpack 4 & 5
module.exports = {
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

### [name] を使用した名前付きアウトプット（Named Output with [name]）

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    main: './src/index.js',
    another: './src/another.js',
  },
  output: {
    filename: '[name].bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

### [hash] と [chunkhash] を使用したアウトプット（Output with [hash] and [chunkhash]）

```javascript
// Webpack 4 & 5
module.exports = {
  output: {
    filename: '[name].[contenthash].js',
    path: path.resolve(__dirname, 'dist'),
    clean: true, // Webpack 5 のみ - dist フォルダをクリーン
  },
};
```

### 設定比較（Configuration Comparison）

| 機能 | Webpack 4 | Webpack 5 |
|------|-----------|-----------|
| **Output.clean** | ❌ 利用不可 | ✅ dist フォルダを自動的にクリーン |
| **Output.pathinfo** | ✅ デフォルト true | ✅ デフォルト false（production） |
| **Output.hashFunction** | MD4 | MD4（デフォルト）、md4、xxHash64、bubblehash |
| **Output.module** | ❌ 利用不可 | ✅ ES module として出力 |
| **Output.environment** | ❌ 利用不可 | ✅ ES module サポート設定 |

## ローダー（Loaders）

ローダーは Webpack が JavaScript ファイル以外を処理できるようにします。

### 基本ローダー設定（Basic Loader Configuration）

```javascript
// Webpack 4 & 5
module.exports = {
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: 'babel-loader',
      },
    ],
  },
};
```

### ローダーオプション（Loader Options）

```javascript
// Webpack 4 & 5
module.exports = {
  module: {
    rules: [
      {
        test: /\.js$/,
        use: {
          loader: 'babel-loader',
          options: {
            presets: ['@babel/preset-env'],
            plugins: ['@babel/plugin-transform-runtime'],
          },
        },
      },
    ],
  },
};
```

### アセットモジュール（Webpack 5 のみ）

Webpack 5 は file-loader、url-loader、raw-loader の置き換えとしてアセットモジュールを導入しました。

```javascript
// Webpack 5
module.exports = {
  module: {
    rules: [
      // file-loader を置き換え
      {
        test: /\.(png|jpg|gif)$/,
        type: 'asset/resource',
      },
      // url-loader を置き換え
      {
        test: /\.svg$/,
        type: 'asset',
        parser: {
          dataUrlCondition: {
            maxSize: 8 * 1024, // 8kb
          },
        },
      },
      // raw-loader を置き換え
      {
        test: /\.txt$/,
        type: 'asset/source',
      },
    ],
  },
};
```

### ローダー比較（Loader Comparison）

| ローダータイプ | Webpack 4 | Webpack 5 | 置き換えモジュール |
|--------------|-----------|-----------|-----------------|
| **file-loader** | 必要 | ✅ 代替 | `asset/resource` |
| **url-loader** | 必要 | ✅ 代替 | `asset` |
| **raw-loader** | 必要 | ✅ 代替 | `asset/source` |
| **svg-url-loader** | 必要 | ✅ 代替 | カスタム処理 |

## プラグイン（Plugins）

プラグインはローダーよりも広範なタスクを実行します。バンドルの最適化から環境変数の注入まで。

### 基本プラグイン設定（Basic Plugin Configuration）

```javascript
// Webpack 4 & 5
const HtmlWebpackPlugin = require('html-webpack-plugin');
const webpack = require('webpack');

module.exports = {
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html',
    }),
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production'),
    }),
  ],
};
```

### 一般的なプラグイン（Common Plugins）

| プラグイン | 説明 | Webpack 4 | Webpack 5 |
|----------|------|-----------|-----------|
| **html-webpack-plugin** | HTML ファイルを生成 | ✅ | ✅ |
| **mini-css-extract-plugin** | CSS を別ファイルに抽出 | ✅ | ✅ |
| **clean-webpack-plugin** | 出力ディレクトリをクリーン | ✅ | ✅ |
| **terser-webpack-plugin** | JavaScript を最小化 | ✅ | ✅ |
| **filemanager-webpack-plugin** | ファイルシステム操作 | ✅ | ✅ |
| **module-federation-plugin** | モジュールフェデレーション | ❌ | ✅ |

### Webpack 5 のビルトインプラグイン（Webpack 5 Built-in Plugins）

Webpack 5 には Webpack 4 で外部だったいくつかのプラグインが含まれています：

| プラグイン | Webpack 4 | Webpack 5 |
|----------|-----------|-----------|
| **asset-plugins** | 必要 | ✅ ビルトイン |
| **module-federation** | 必要 | ✅ ビルトイン |
| **persistent-cache** | 必要 | ✅ ビルトイン |

## モード（Mode）

Webpack は3つのビルトインモードオプションを提供します：`development`、`production`、および `none`。

```javascript
// Webpack 4 & 5
module.exports = {
  mode: 'development', // または 'production' または 'none'
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

### モード固有の最適化（Mode-Specific Optimizations）

| 最適化 | development | production |
|--------|-------------|------------|
| **nodeEnv** | 'development' | 'production' |
| **debug** | true | false |
| **moduleIds** | 'named' | 'deterministic' |
| **chunkIds** | 'named' | 'deterministic' |
| **optimization.removeAvailableModules** | false | true |
| **optimization.removeEmptyChunks** | false | true |
| **optimization.splitChunks** | false | true |
| **optimization.minimize** | false | true |

## 開発ツール（Development Tools）

### ソースマップ（Source Maps）

ソースマップは、コンパイルされたコードを元のソースに戻すことでデバッグを助けるものです。

| オプション | Webpack 4 | Webpack 5 | 説明 |
|--------|-----------|-----------|------|
| `eval` | ✅ | ✅ | 最速、eval() でラップ |
| `cheap-eval-source-map` | ✅ | ✅ | 開発に適しています |
| `cheap-module-eval-source-map` | ✅ | ✅ | 元のソースを保持 |
| `source-map` | ✅ | ✅ | 最高品質、最慢 |
| `hidden-source-map` | ✅ | ✅ | バンドルから参照されません |
| `eval-source-map` | ✅ | ✅ | eval() で動作 |

### Webpack Dev Server

Webpack Dev Server はライブリロード付きの開発サーバーを提供します。

```javascript
// Webpack 4 & 5
const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  devServer: {
    static: {
      directory: path.join(__dirname, 'public'),
    },
    port: 9000,
    hot: true,
  },
};
```

### 設定比較（Configuration Comparison）

| 機能 | Webpack 4 | Webpack 5 |
|------|-----------|-----------|
| **devServer.static** | 文字列としてのディレクトリ | object プロパティ directory |
| **devServer.contentBase** | ✅ 非推奨 | ❌ 削除 |
| **watchOptions** | 直接プロパティ | 直接プロパティ |
| **server** | ❌ 利用不可 | ✅ 新しいサーバー設定 |

## コードスプリッティング（Code Splitting）

Webpack は、パフォーマンス向上のためにコードを複数のバンドルに分割できます。

### 動的インポート（Dynamic Imports）（Webpack 4 & 5）

```javascript
// Webpack 4 & 5
button.addEventListener('click', () => {
  import('./module').then((module) => {
    module.default();
  });
});
```

### マジックコメント（Magic Comments）（Webpack 4 & 5）

```javascript
// Webpack 4 & 5
import(
  /* webpackChunkName: "my-chunk" */
  /* webpackMode: "lazy" */
  './module'
).then((module) => {
  module.default();
});
```

### SplitChunks 設定（SplitChunks Configuration）

```javascript
// Webpack 4 & 5
module.exports = {
  optimization: {
    splitChunks: {
      chunks: 'all',
      cacheGroups: {
        vendor: {
          test: /[\\/]node_modules[\\/]/,
          name: 'vendors',
          chunks: 'all',
        },
      },
    },
  },
};
```

### 設定比較（Configuration Comparison）

| 機能 | Webpack 4 | Webpack 5 |
|------|-----------|-----------|
| **optimization.splitChunks.cacheGroups** | ✅ | ✅ |
| **optimization.chunkGroups** | ❌ 利用不可 | ✅ 利用可能 |
| **optimization.moduleConcatenation** | ✅（Optimization.concatenateModules） | ✅（Optimization.concatenateModules） |
| **fetchPriority** | ❌ 利用不可 | ✅ import() で利用可能 |

## モジュールフェデレーション（Module Federation）（Webpack 5 のみ）

モジュールフェデレーションは、Webpack 5 の新しい機能で、異なるビルド間でランタイムにコードを共有できます。

### ホスト設定（Host Configuration）

```javascript
// Webpack 5 - ホストアプリケーション
const ModuleFederationPlugin = require('webpack').container.ModuleFederationPlugin;

module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'host',
      filename: 'remoteEntry.js',
      exposes: {
        './Button': './src/Button',
      },
      remotes: {
        remote: 'remote@http://localhost:3002/remoteEntry.js',
      },
      shared: ['react', 'react-dom'],
    }),
  ],
};
```

### リモート設定（Remote Configuration）

```javascript
// Webpack 5 - リモートアプリケーション
const ModuleFederationPlugin = require('webpack').container.ModuleFederationPlugin;

module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'remote',
      filename: 'remoteEntry.js',
      exposes: {
        './Button': './src/Button',
      },
      shared: ['react', 'react-dom'],
    }),
  ],
};
```

この機能は Webpack 4 では利用できず、同様の機能にはサードパーティプラグインが必要です。


## ベストプラクティス（Best Practices）

### 設定の組織化（Configuration Organization）

```javascript
// Webpack 4 & 5 - 基本設定
const path = require('path');

module.exports = (env, argv) => {
  const isProduction = argv.mode === 'production';

  return {
    mode: argv.mode || 'development',
    entry: './src/index.js',
    output: {
      filename: isProduction ? '[name].[contenthash].js' : '[name].js',
      path: path.resolve(__dirname, 'dist'),
      clean: isProduction, // Webpack 5 のみ
    },
    module: {
      rules: [
        {
          test: /\.css$/,
          use: ['style-loader', 'css-loader'],
        },
      ],
    },
    plugins: [
      // production 固有のプラグイン
      ...(isProduction ? [] : []),
    ],
    optimization: {
      minimize: isProduction,
    },
  };
};
```

### バージョン固有のベストプラクティス（Version-Specific Best Practices）

#### Webpack 4

1. アセットには `file-loader`、`url-loader` を使用
2. `cache-loader` でキャッシュを設定
3. スコープホイストングに `optimization.concatenateModules` を使用
4. CSS 抽出に `ExtractTextPlugin` を使用

#### Webpack 5

1. file-loader/url-loader の代わりにアセットモジュールを使用
2. 再ビルド速度向上のために `cache.type = 'filesystem'` を有効化
3. マイクロフロントエンドにビルトインモジュールフェデレーションを使用
4. import() の最適化に `_magic comments` を使用

## Webpack 4 から Webpack 5 への移行（Migration from Webpack 4 to Webpack 5）

### ステップ1：Node.js を更新（Step 1: Update Node.js）

Webpack 5 は Node.js 10.13.0 以降が必要です：

```bash
# バージョンを確認
node -v

# 必要に応じて更新
nvm install 14
nvm use 14
```

### ステップ2：ローダーをアセットモジュールで置き換え（Step 2: Replace Loaders with Asset Modules）

Webpack 4：
```javascript
{
  test: /\.(png|jpg|gif)$/,
  use: 'file-loader'
}
```

Webpack 5：
```javascript
{
  test: /\.(png|jpg|gif)$/,
  type: 'asset/resource'
}
```

### ステップ3：永続的キャッシュを有効化（Step 3: Enable Persistent Caching）

Webpack 4：外部プラグインが必要
Webpack 5：ビルトイン
```javascript
cache: {
  type: 'filesystem',
},
```

### ステップ4：CSS 抽出を更新（Step 4: Update CSS Extraction）

Webpack 4：
```bash
npm install extract-text-webpack-plugin --save-dev
```

Webpack 5：
```bash
npm install mini-css-extract-plugin --save-dev
```

### ステップ5：プラグイン使用法を更新（Step 5: Update Plugin Usage）

いくつかのプラグインは Webpack 5 で置き換えまたは更新されています。互換性のためにプラグインのドキュメントを確認してください。
