# SearXNG Manual del usuario

Este manual cubre cómo usar SearXNG de manera efectiva para buscar y personalizar.

## Sintaxis de Búsqueda

SearXNG admite una sintaxis de búsqueda potente para refinar sus consultas:

### Selección de Motor
- **Prefijo `!`**: Seleccionar motor o categoría específica
  - `!wp paris` - Buscar "paris" en Wikipedia
  - `!images Wau Holland` - Buscar imágenes de "Wau Holland"
  - `!news climate change` - Buscar en motores de noticias "climate change"

### Selección de Idioma
- **Prefijo `:`**: Seleccionar idioma de búsqueda
  - `:fr !wp Wau Holland` - Buscar "Wau Holland" en Wikipedia francesa
  - `:de climate change` - Buscar en alemán "climate change"

### Bangs Externos
- **Prefijo `!!`**: Redirecciones directas a servicios externos
  - `!!youtube cats` - Redirigir directamente a la búsqueda de YouTube "cats"

### Consultas Especiales
SearXNG admite varias funciones de consulta especiales:
- `random uuid` - Generar un UUID aleatorio
- `avg 123 548` - Calcular el promedio de números
- `user-agent` - Mostrar su agente de usuario actual
- Funciones hash: `md5 text`, `sha1 text`, `sha256 text`
- Conversiones de unidades: `100 USD in EUR`, `10 km in miles`

## Motores de Búsqueda Configurados

SearXNG viene con **250 motores de búsqueda** configurados, con **96 habilitados por defecto**. Los motores están organizados en categorías:

### Categorías
- **General**: Motores de búsqueda web estándar
- **Imágenes**: Servicios de búsqueda de imágenes
- **Videos**: Plataformas de búsqueda de videos
- **Noticias**: Servicios de agregación de noticias
- **Mapas**: Servicios de mapeo y ubicación
- **Música**: Búsqueda y transmisión de música
- **TI**: Recursos técnicos y de programación
- **Ciencia**: Bases de datos académicas y científicas
- **Archivos**: Búsqueda de archivos y documentos
- **Redes Sociales**: Búsqueda en plataformas sociales

### Subgrupos
Cada categoría contiene subgrupos para búsquedas más específicas:
- Libros, Moneda, Traducir, Web, Wikimedia, y más

## Personalización de Interfaz

- **Idioma de búsqueda predeterminado**

### Plugins
SearXNG incluye plugins útiles:
- **Calculadora**: Realizar cálculos matemáticos
- **Hash**: Generar varios valores hash
- **Información Propia**: Mostrar información del cliente
- **Zonas Horarias**: Convertir entre zonas horarias
- **Verificación Tor**: Verificar conectividad Tor
- **Conversor de Unidades**: Convertir entre unidades de medida

## Características de Privacidad

### Búsqueda Anónima
- Todas las búsquedas son anónimas por defecto
- Sin cookies ni scripts de seguimiento
- La dirección IP no se registra (en instancias configuradas correctamente)

### Saneamiento de Resultados
- Las URLs se limpian de parámetros de seguimiento
- La información de referente se elimina
- Los scripts de terceros se bloquean

## Uso Avanzado

### Acceso API
SearXNG proporciona una API simple para acceso programático:
```
GET /search?q=your_query&format=json
```

### Motores Personalizados
Puede agregar motores de búsqueda personalizados modificando el archivo `settings.yml`:
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### Atajos de Teclado
- **`/`**: Enfocar entrada de búsqueda
- **`Esc`**: Borrar búsqueda o cerrar diálogos
- **`Enter`**: Enviar búsqueda
- **`Ctrl+Enter`**: Abrir resultados en nueva pestaña

Este manual integral debería ayudarle a aprovechar al máximo su experiencia con SearXNG mientras mantiene completa privacidad y control sobre su actividad de búsqueda.
