# Gestionnaire de paquets Yarn

Yarn est un gestionnaire de paquets open source centré sur la vitesse, la correction, la sécurité et l'expérience développeur, utilisé pour gérer les dépendances dans les projets JavaScript.

## Aperçu des versions

- **Yarn 4+ (Version moderne)**: Développement et maintenance actifs, fournit des fonctionnalités avancées comme les workspaces et le système de plugins
- **Yarn v3**: En maintenance, adapté aux grands monorepos et aux utilisateurs professionnels  
- **Yarn Classic (v1)**: En maintenance, gestionnaire de paquets Yarn traditionnel
