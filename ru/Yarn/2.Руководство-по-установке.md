# Руководство по установке Yarn

## Установка Yarn 4+ (Современная версия)

### Рекомендуемый метод установки (с использованием Corepack)

Corepack — это промежуточный инструмент, который позволяет настраивать версию менеджера пакетов для каждого проекта:

```bash
# Установить Corepack глобально
npm install -g corepack

# Инициализировать новый проект (с использованием Yarn Berry)
yarn init -2
```

### Обновление Yarn

Чтобы обновить до последней версии в любое время, просто выполните:

```bash
yarn set version stable
yarn install
```

Yarn настроит ваш проект на использование самого последнего стабильного бинарного файла.

### Использование Canary-версий

Yarn часто выпускает сборки Release Candidate. Если вам нужна функция, которая еще не выпущена в стабильном канале:

```bash
yarn set version canary
```

Эти сборки очень стабильны, единственное отличие от обычного канала заключается в более поэтапной миграции между основными версиями по мере внедрения новых критических изменений.

### Установка последней сборки из master

Если вы хотите протестировать версию Yarn, которая настолько новая, что еще не была выпущена в Release Candidate, или даже не слита:

```bash
# Клонировать, собрать и установить из ветки master
yarn set version from sources

# Тестировать конкретный PR
yarn set version from sources --branch 1211
```

**Примечание**: Команда `yarn set version from sources` не может использовать Corepack и должна хранить бинарный файл Yarn в папке `.yarn/releases` и ссылаться на него из файла `.yarnrc.yml` вашего проекта.

## Установка Yarn Classic (v1)

### Установка через npm (рекомендуется)

Рекомендуется устанавливать Yarn через менеджер пакетов npm, который поставляется вместе с Node.js:

```bash
# Установить или обновить Yarn Classic
npm install --global yarn
```

### Проверка установки

После установки проверьте, что Yarn правильно установлен, выполнив:

```bash
yarn --version
```

## Рекомендации по выбору версии

- **Новые проекты**: Рекомендуется использовать Yarn 4+ (современная версия), чтобы воспользоваться новейшими функциями и улучшениями
- **Существующие проекты**: 
  - Если вы уже используете Yarn Classic, вы можете продолжать его использовать
  - Рассмотрите возможность миграции на современную версию для получения лучшей производительности и функций
- **Корпоративные среды**: Современная версия обеспечивает лучшую поддержку рабочих пространств и гарантии стабильности

## Системные требования

- **Node.js**: Все версии требуют среды Node.js
- **npm**: Yarn Classic требует npm для глобальной установки
- **Corepack**: Современная версия рекомендует использовать Corepack для управления версиями

> **Примечание**: Этот документ основан на официальном контенте сайтов yarnpkg.com и classic.yarnpkg.com.
