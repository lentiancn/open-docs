# SearXNG Guide d'installation

Ce guide couvre plusieurs méthodes d'installation pour configurer votre propre instance de SearXNG.

## Méthodes d'Installation

### 1. Installation par Conteneur (Recommandé)

La méthode la plus simple et fiable est d'utiliser des conteneurs Docker ou Podman.

**Prérequis :**
- Docker ou Podman installé
- Connaissances de base en gestion de conteneurs

**Étapes :**
```bash
# Tirer l'image officielle de SearXNG
docker pull searxng/searxng

# Exécuter avec configuration de base
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. Script d'Installation

Un script d'installation automatisé est disponible qui gère automatiquement la plupart des configurations, y compris la configuration uWSGI.

**Étapes :**
```bash
# Télécharger le script d'installation
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# Rendre exécutable et exécuter
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. Installation Manuelle Étape par Étape

Pour les utilisateurs avancés qui souhaitent un contrôle total sur le processus d'installation.

**Prérequis :**
- Python 3.8 ou supérieur
- uWSGI
- Git
- Outils de compilation (gcc, make, etc.)
- Serveur web (NGINX ou Apache)

**Étapes d'Installation :**

1. **Installer les Paquets Requis :**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **Créer un Utilisateur Dédié :**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **Cloner le Dépôt :**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **Configurer les Paramètres :**
   ```bash
   # Copier les paramètres par défaut
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # Modifier la configuration si nécessaire
   sudo nano /etc/searxng/settings.yml
   ```

5. **Configurer le Serveur Web :**
   
   **Exemple de Configuration NGINX :**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## Après l'Installation

Après l'installation, accédez à votre instance SearXNG à `http://your-server:port` et vérifiez qu'elle fonctionne correctement. Vous pouvez personnaliser l'apparence, les moteurs et le comportement via le fichier de configuration `settings.yml`.

## Dépannage

- **Problèmes de Permissions** : Assurez-vous que l'utilisateur searxng a les permissions appropriées sur tous les fichiers
- **Conflits de Port** : Vérifiez que le port choisi n'est pas déjà utilisé
- **Configuration des Moteurs** : Certains moteurs de recherche peuvent nécessiter des clés API ou une configuration spécifique
- **Configuration SSL** : Pour une utilisation en production, configurez des certificats SSL en utilisant Let's Encrypt ou votre autorité de certification préférée
