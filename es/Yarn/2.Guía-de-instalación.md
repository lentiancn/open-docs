# Guía de Instalación de Yarn

## Instalación de Yarn 4+ (Versión Moderna)

### Método de Instalación Recomendado (Usando Corepack)

Corepack es una herramienta intermedia que permite configurar la versión de tu gestor de paquetes por proyecto:

```bash
# Instalar Corepack globalmente
npm install -g corepack

# Inicializar un nuevo proyecto (usando Yarn Berry)
yarn init -2
```

### Actualizando Yarn

Para actualizar a la última versión en cualquier momento, simplemente ejecuta:

```bash
yarn set version stable
yarn install
```

Yarn configurará tu proyecto para usar el binario estable más reciente.

### Usando Versiones Canary

Yarn frecuentemente publica compilaciones Release Candidate. Si necesitas una función que aún no se ha publicado en el canal estable:

```bash
yarn set version canary
```

Estas compilaciones son muy estables, con la única diferencia respecto al canal regular siendo una migración más escalonada entre versiones mayores a medida que implementamos nuevos cambios rotos.

### Instalando la Última Compilación desde Master

Si deseas probar una versión de Yarn tan reciente que aún no se ha publicado en un Release Candidate, o incluso no fusionada:

```bash
# Clonar, construir e instalar desde la rama master
yarn set version from sources

# Probar PR específico
yarn set version from sources --branch 1211
```

**Nota**: El comando `yarn set version from sources` no puede aprovechar Corepack y necesitará almacenar el binario de Yarn dentro de la carpeta `.yarn/releases` y hacer referencia a él desde el archivo `.yarnrc.yml` de tu proyecto.

## Instalación de Yarn Classic (v1)

### Instalación vía npm (Recomendado)

Se recomienda instalar Yarn a través del gestor de paquetes npm, que viene incluido con Node.js:

```bash
# Instalar o actualizar Yarn Classic
npm install --global yarn
```

### Verificar Instalación

Después de la instalación, verifica que Yarn esté correctamente instalado ejecutando:

```bash
yarn --version
```

## Recomendaciones de Selección de Versión

- **Nuevos Proyectos**: Se recomienda usar Yarn 4+ (versión moderna) para disfrutar de las últimas funciones y mejoras
- **Proyectos Existentes**: 
  - Si ya estás usando Yarn Classic, puedes continuar usándolo
  - Considera migrar a la versión moderna para obtener mejor rendimiento y funciones
- **Entornos Empresariales**: La versión moderna proporciona mejor soporte para workspaces y garantías de estabilidad

## Requisitos del Sistema

- **Node.js**: Todas las versiones requieren el entorno Node.js
- **npm**: Yarn Classic requiere npm para la instalación global
- **Corepack**: La versión moderna recomienda usar Corepack para la gestión de versiones

> **Nota**: Este documento se basa en el contenido oficial de los sitios web yarnpkg.com y classic.yarnpkg.com.
