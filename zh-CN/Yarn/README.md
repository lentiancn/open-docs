# Yarn 包管理器

Yarn 是一个专注于速度、正确性、安全性和开发者体验的开源包管理器，用于管理 JavaScript 项目中的依赖关系。

## 版本概览

- **Yarn 4+ (现代版本)**: 活跃开发和维护，提供工作区、插件系统等高级功能
- **Yarn v3**: 维护中，适用于大型单体仓库和企业用户  
- **Yarn Classic (v1)**: 维护中，传统的 Yarn 包管理器
