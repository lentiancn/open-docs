# SearXNG Руководство пользователя

Это руководство охватывает эффективное использование SearXNG для поиска и настройки.

## Синтаксис поиска

SearXNG поддерживает мощный синтаксис поиска для уточнения ваших запросов:

### Выбор движка
- **Префикс `!`**: Выбрать конкретный движок или категорию
  - `!wp paris` - Искать "paris" в Википедии
  - `!images Wau Holland` - Искать изображения "Wau Holland"
  - `!news climate change` - Искать в новостных движках "climate change"

### Выбор языка
- **Префикс `:`**: Выбрать язык поиска
  - `:fr !wp Wau Holland` - Искать "Wau Holland" во французской Википедии
  - `:de climate change` - Искать на немецком языке "climate change"

### Внешние банги
- **Префикс `!!`**: Прямое перенаправление на внешние сервисы
  - `!!youtube cats` - Направить прямо в поиск YouTube "cats"

### Специальные запросы
SearXNG поддерживает различные специальные функции запросов:
- `random uuid` - Генерировать случайный UUID
- `avg 123 548` - Вычислить среднее значение чисел
- `user-agent` - Показать ваш текущий user-agent
- Хэш-функции: `md5 text`, `sha1 text`, `sha256 text`
- Конвертация единиц: `100 USD in EUR`, `10 km in miles`

## Настроенные поисковые движки

SearXNG поставляется с **250 поисковыми движками**, из которых **96 включены по умолчанию**. Движки организованы по категориям:

### Категории
- **Общие**: Стандартные веб-поисковые движки
- **Изображения**: Сервисы поиска изображений
- **Видео**: Платформы поиска видео
- **Новости**: Сервисы агрегации новостей
- **Карты**: Сервисы картографирования и определения местоположения
- **Музыка**: Поиск музыки и стриминг
- **IT**: Технические и программные ресурсы
- **Наука**: Академические и научные базы данных
- **Файлы**: Обмен файлами и поиск документов
- **Социальные сети**: Поиск в социальных платформах

### Подгруппы
Каждая категория содержит подгруппы для более конкретного поиска:
- Книги, Валюта, Перевод, Веб, Викимедиа и другие

## Настройка интерфейса

### Предпочтения
Доступ к предпочтениям через иконку настроек для настройки:
- **Язык поиска по умолчанию**
- **Включенные поисковые движки**
- **Опции отображения результатов**
- **Настройки конфиденциальности**
- **Тема и внешний вид**

### Плагины
SearXNG включает полезные плагины:
- **Калькулятор**: Выполнение математических вычислений
- **Хэш**: Генерация различных хэш-значений
- **Информация о себе**: Отображение информации о клиенте
- **Часовые пояса**: Конвертация между часовыми поясами
- **Проверка Tor**: Проверка подключения Tor
- **Конвертер единиц**: Конвертация между единицами измерения

## Функции конфиденциальности

### Анонимный поиск
- Все поиски анонимны по умолчанию
- Без cookies и скриптов отслеживания
- IP-адрес не записывается (в правильно настроенных инстансах)

### Очистка результатов
- URL-адреса очищаются от параметров отслеживания
- Информация о реферере удаляется
- Скрипты третьих сторон блокируются

## Расширенное использование

### Доступ к API
SearXNG предоставляет простой API для программного доступа:
```
GET /search?q=your_query&format=json
```

### Пользовательские движки
Вы можете добавлять пользовательские поисковые движки, изменяя файл `settings.yml`:
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### Горячие клавиши
- **`/`**: Фокус на поле поиска
- **`Esc`**: Очистить поиск или закрыть диалоги
- **`Enter`**: Отправить поиск
- **`Ctrl+Enter`**: Открыть результаты в новой вкладке

Это комплексное руководство должно помочь вам максимально эффективно использовать SearXNG, сохраняя полную конфиденциальность и контроль над вашей поисковой активностью.
