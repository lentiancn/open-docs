# SQLite 安装指南

## 概述

SQLite 通常不需要单独安装，因为它内置于大多数操作系统中。本文档介绍各种平台和场景下的 SQLite 安装方法。

## 主要版本

本文档涵盖 SQLite 主版本 3.x（当前活跃版本）。

## Windows 系统安装

### 方法 1：预编译二进制文件（推荐）

1. 访问 [SQLite 下载页面](https://www.sqlite.org/download.html)
2. 下载 "sqlite-tools-win32-x86-*.zip"（命令行工具）
3. 下载 "sqlite-dll-win32-x86-*.zip"（DLL 文件，如果需要编程接口）
4. 解压到目录，例如 `C:\sqlite`
5. 将该目录添加到系统 PATH 环境变量

### 方法 2：使用 Chocolatey

```powershell
choco install sqlite
```

### 方法 3：使用 winget

```powershell
winget install SQLite.SQLite
```

## macOS 系统安装

### 方法 1：使用 Homebrew（推荐）

```bash
brew install sqlite
```

### 方法 2：系统预装

macOS 自带 SQLite，可以直接使用：

```bash
sqlite3 --version
```

### 方法 3：使用 MacPorts

```bash
sudo port install sqlite3
```

## Linux 系统安装

### Debian/Ubuntu 系列

```bash
sudo apt update
sudo apt install sqlite3 sqlite3-dev
```

### RHEL/CentOS/Fedora 系列

```bash
# RHEL/CentOS 7/8
sudo yum install sqlite sqlite-devel

# Fedora
sudo dnf install sqlite sqlite-devel
```

### openSUSE

```bash
sudo zypper install sqlite3 sqlite3-devel
```

### Arch Linux

```bash
sudo pacman -S sqlite
```

## 其他平台安装

### FreeBSD

```bash
sudo pkg install sqlite3
```

### NetBSD

```bash
pkgin install sqlite3
```

## 编程语言集成

### Python

Python 3.x 自带 sqlite3 模块，无需额外安装：

```python
import sqlite3
```

如果需要更新：

```bash
# Linux
sudo apt install python3-pip
pip install pysqlite3

# Windows/macOS
pip install pysqlite3
```

### JavaScript/Node.js

```bash
npm install sqlite3
# 或使用更好的性能版本
npm install better-sqlite3
```

### PHP

```bash
# Ubuntu/Debian
sudo apt install php-sqlite3

# CentOS/RHEL
sudo yum install php-pdo-sqlite
```

### Ruby

```bash
gem install sqlite3
```

### Java

使用 JDBC 驱动：

```xml
<!-- Maven -->
<dependency>
    <groupId>org.xerial</groupId>
    <artifactId>sqlite-jdbc</artifactId>
    <version>3.46.1.3</version>
</dependency>
```

### C/C++

SQLite 源代码包含在头文件 `sqlite3.h` 中。链接时需要：

```bash
gcc myprogram.c -lsqlite3
```

## Docker 安装

### 官方 SQLite 镜像

```bash
docker run -it --rm sqlite sqlite3
```

### 自定义镜像

```dockerfile
FROM alpine:latest
RUN apk add --no-cache sqlite
CMD ["sqlite3"]
```

## 源码编译安装

### 步骤 1：下载源码

```bash
wget https://www.sqlite.org/2026/sqlite-autoconf-3510300.tar.gz
tar xzf sqlite-autoconf-3510300.tar.gz
cd sqlite-autoconf-3510300
```

### 步骤 2：配置和编译

```bash
./configure
make
sudo make install
```

### 步骤 3：验证安装

```bash
sqlite3 --version
```

## 安装后验证

### 检查版本

```bash
sqlite3 --version
```

### 简单测试

```bash
# 创建测试数据库
sqlite3 test.db "CREATE TABLE test (id INTEGER, name TEXT);"
sqlite3 test.db "INSERT INTO test VALUES (1, 'Hello');"
sqlite3 test.db "SELECT * FROM test;"
sqlite3 test.db ".dump"

# 清理
rm test.db
```

## 常见问题

### 1. 权限问题

如果遇到权限问题，请使用 `sudo` 或以管理员身份运行。

### 2. 版本冲突

多个版本共存时，可以使用完整路径调用特定版本：

```bash
/usr/local/bin/sqlite3 --version
/usr/bin/sqlite3 --version
```

### 3. 动态库未找到（Linux）

```bash
# 更新动态链接器缓存
sudo ldconfig

# 或设置 LD_LIBRARY_PATH
export LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH
```

### 4. Windows 找不到 sqlite3.dll

将 sqlite3.dll 放在 System32 目录或添加到 PATH。

## 版本升级

### macOS（Homebrew）

```bash
brew update
brew upgrade sqlite
```

### Linux（APT）

```bash
sudo apt update
sudo apt upgrade sqlite3
```

1. 下载新版本源码
2. 重复"源码编译安装"步骤
3. 备份现有数据库
4. 测试新版本
