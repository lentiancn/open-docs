# SQLite — документация на русском языке

**Small. Fast. Reliable. Choose any three.**

SQLite — это библиотека на языке C, которая реализует самодостаточный, бессерверный, не требующий конфигурации, транзакционный SQL-движок базы данных. Код SQLite находится в общественном достоянии и может использоваться бесплатно для любых целей.

## Особенности SQLite

- **Встраиваемый**: Нет отдельного серверного процесса, работает напрямую с файлами
- **Кроссплатформенный**: Формат файла одинаков на всех платформах
- **Компактный**: Менее 900 КБ с полным функционалом
- **Надежный**: ACID-совместимые транзакции, даже при сбоях питания
- **Быстрый**: Часто быстрее прямого доступа к файловой системе
- **Бесплатный**: Полностью в общественном достоянии

## Быстрый старт

```bash
# Создание новой базы данных и таблицы
$ sqlite3 mydatabase.db
sqlite> CREATE TABLE users(id INTEGER PRIMARY KEY, name TEXT, email TEXT);
sqlite> INSERT INTO users(name, email) VALUES('Иван', 'ivan@example.com');
sqlite> SELECT * FROM users;
```
