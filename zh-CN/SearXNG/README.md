# SearXNG

SearXNG 是一个免费的互联网元搜索引擎，通过聚合来自 250+ 搜索服务的结果来保护您的隐私，不会跟踪或画像用户。

## 官方资源
- **网站**：https://searxng.org
- **文档**：https://docs.searxng.org  
- **源代码**：https://github.com/searxng/searxng
- **公共实例**：https://searx.space

## 主要特性
- 隐私优先的元搜索引擎
- 无用户跟踪或数据收集
- 支持 Tor 以增强匿名性
- 高度可定制和可配置
- 开源且社区驱动
