# Введение в Oracle Database

Oracle Database — это реляционная система управления базами данных (СУБД), разработанная корпорацией Oracle, и является одним из самых известных корпоративных решений для баз данных в мире.

## Основные версии

### Oracle Database 26ai
Oracle Database 26ai (полное название: Oracle AI Database 26ai) — это новейшая версия Oracle Database, выпущенная в 2026 году. Эта версия интегрирует передовые функции искусственного интеллекта, обеспечивая улучшенные возможности автоматизированного управления и оптимизации производительности.

**Примечание**: Oracle Database 26ai является последней выпущенной версией. Подробную техническую документацию следует смотреть на официальном сайте Oracle.

### Oracle Database 19c
Oracle Database 19c — это версия с долгосрочной поддержкой Oracle Database, предоставляющая стабильные и надежные корпоративные функции базы данных. Эта версия поддерживает множество платформ операционных систем, включая Windows x64, Linux x86-64, Linux ARM, Solaris, AIX, HP-UX и Linux on System z.

## Основные функции

- **Высокая доступность**: предоставляет решения высокой доступности, такие как Real Application Clusters (RAC) и Data Guard
- **Безопасность**: встроенные расширенные функции безопасности, включая прозрачное шифрование данных, аудит и контроль доступа
- **Масштабируемость**: поддерживает различные модели развертывания от одиночных экземпляров до крупномасштабных распределенных кластеров
- **Оптимизация производительности**: автоматическая настройка SQL, управление памятью и оптимизация хранилища
- **Поддержка мульти-моделей**: поддерживает несколько моделей данных, включая реляционную, JSON, XML и графовую
- **Облачная нативность**: поддерживает контейнеризированное развертывание и интеграцию с облачными средами
