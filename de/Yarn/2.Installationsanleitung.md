# Yarn Installationsanleitung

## Yarn 4+ (Moderne Version) Installation

### Empfohlene Installationsmethode (mit Corepack)

Corepack ist ein Zwischenwerkzeug, das es Ihnen ermöglicht, die Paketmanager-Version projektspezifisch zu konfigurieren:

```bash
# Corepack global installieren
npm install -g corepack

# Neues Projekt initialisieren (mit Yarn Berry)
yarn init -2
```

### Yarn aktualisieren

Um jederzeit auf die neueste Version zu aktualisieren, führen Sie einfach aus:

```bash
yarn set version stable
yarn install
```

Yarn konfiguriert dann Ihr Projekt so, dass es das aktuellste stabile Binärprogramm verwendet.

### Canary-Versionen verwenden

Yarn veröffentlicht häufig Release Candidate Builds. Wenn Sie eine Funktion benötigen, die noch nicht im stabilen Kanal veröffentlicht wurde:

```bash
yarn set version canary
```

Diese Builds sind sehr stabil, der einzige Unterschied zum regulären Kanal besteht in einer gestaffelteren Migration zwischen Hauptversionen, da wir neue Breaking Changes implementieren.

### Neuesten Build direkt aus dem Master installieren

Wenn Sie eine Yarn-Version testen möchten, die so neu ist, dass sie noch nicht als Release Candidate veröffentlicht wurde oder sogar noch nicht zusammengeführt wurde:

```bash
# Aus dem Master-Branch klonen, bauen und installieren
yarn set version from sources

# Spezifischen PR testen
yarn set version from sources --branch 1211
```

**Hinweis**: Der Befehl `yarn set version from sources` kann Corepack nicht nutzen und muss die Yarn-Binärdatei im Ordner `.yarn/releases` speichern und von der `.yarnrc.yml`-Datei Ihres Projekts darauf verweisen.

## Yarn Classic (v1) Installation

### Installation über npm (empfohlen)

Es wird empfohlen, Yarn über den npm-Paketmanager zu installieren, der mit Node.js mitgeliefert wird:

```bash
# Yarn Classic installieren oder aktualisieren
npm install --global yarn
```

### Installation überprüfen

Nach der Installation überprüfen Sie, ob Yarn korrekt installiert ist, indem Sie ausführen:

```bash
yarn --version
```

## Versionsauswahl-Empfehlungen

- **Neue Projekte**: Es wird empfohlen, Yarn 4+ (moderne Version) zu verwenden, um die neuesten Funktionen und Verbesserungen zu nutzen
- **Bestehende Projekte**: 
  - Wenn Sie bereits Yarn Classic verwenden, können Sie weiterhin damit arbeiten
  - Erwägen Sie eine Migration zur modernen Version für bessere Leistung und Funktionen
- **Unternehmensumgebungen**: Die moderne Version bietet bessere Workspace-Unterstützung und Stabilitätsgarantien

## Systemanforderungen

- **Node.js**: Alle Versionen erfordern eine Node.js-Umgebung
- **npm**: Yarn Classic benötigt npm für die globale Installation
- **Corepack**: Die moderne Version empfiehlt die Verwendung von Corepack für die Versionsverwaltung

> **Hinweis**: Dieses Dokument basiert auf offiziellen Inhalten der Websites yarnpkg.com und classic.yarnpkg.com.
