# Oracle Database

Oracle Database는 오라클 사가 개발한 엔터프라이즈급 관계형 데이터베이스 관리 시스템입니다.

## 문서 버전

- **Oracle Database 26ai** - 최신 버전 (2026년 출시)
- **Oracle Database 19c** - 장기 지원 버전

## 문서 구조

1. **소개** - Oracle Database 개요 및 주요 기능
2. **설치 가이드** - 자세한 설치 단계 및 시스템 요구사항
3. **사용 매뉴얼** - 완전한 SQL, PL/SQL 프로그래밍 및 관리 작업
4. **자주 묻는 질문** - 일반적인 질문 및 문제 해결
