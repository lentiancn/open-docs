# Webpack 模組打包器

Webpack 是一種用於現代 JavaScript 應用程式的靜態模組打包工具。在核心層面，Webpack 會處理您的應用程式，從一個或多個入口點開始，內部構建依賴關係圖，然後將專案所需的所有模組組合成一個或多個打包檔案，這些是用於服務您內容的靜態資源。

從 4.0.0 版本開始，Webpack 不再需要設定檔即可打包您的專案，但它具有極高的可配置性，可以更好地滿足您的需求。

## 主要版本對比

### Webpack v5（現代版本）
- **架構**: 現代 ES Module 支援、持久化快取、模組聯合
- **特性**: 內建程式碼分割、Tree Shaking、資源模組、效能提升
- **設定**: 支援 CommonJS 和 ES Module 語法
- **狀態**: 持續開發中

### Webpack v4（舊版本）
- **架構**: 傳統的基於 CommonJS 的設定
- **特性**: 基礎打包、程式碼分割、Tree Shaking
- **設定**: 僅 CommonJS 語法
- **狀態**: 已停止維護（EOL）

> 注意：Webpack 的核心概念在各版本之間保持一致，但 v5 引入了顯著的效能改進和新特性，例如用於微前端架構的模組聯合（Module Federation）。

## 核心概念

Webpack 的功能圍繞以下幾個核心概念構建：

- **入口（Entry）**: 指示 Webpack 應該使用哪個模組來開始構建內部依賴關係圖
- **輸出（Output）**: 告訴 Webpack 將打包檔案輸出到何處以及如何命名
- **載入器（Loaders）**: 允許 Webpack 處理非 JavaScript 檔案，並將其轉換為有效模組
- **外掛（Plugins）**: 執行更廣泛的任務，如打包檔案優化、資源管理和環境變數注入
- **模式（Mode）**: 為開發或生產環境啟用內建最佳化

Webpack 支援所有符合 ES5 規範的瀏覽器（不支援 IE8 及以下版本）。Webpack 5 要求 Node.js 版本為 10.13.0 或更高。
