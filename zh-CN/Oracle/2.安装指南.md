# Oracle Database 安装指南

## Oracle Database 19c 安装

### 系统要求

#### 操作系统支持
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### 硬件要求
- **内存**：至少 2GB RAM（推荐 4GB 或更多）
- **磁盘空间**：至少 6.5GB 可用空间（企业版）
- **处理器**：支持的操作系统对应的处理器架构

### 安装步骤

#### 1. 下载软件
从 Oracle 软件下载中心获取 Oracle Database 19c 安装包：
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. 准备系统环境
```bash
# Linux 系统示例
# 创建 oracle 用户和组
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# 设置内核参数
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# 设置用户限制
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. 运行安装程序
```bash
# 解压安装包并运行安装程序
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. 图形化安装向导
- 选择安装类型（桌面类、服务器类）
- 配置数据库标识（全局数据库名、SID）
- 设置管理密码
- 执行 root 脚本
- 完成安装

### 免费版本安装
Oracle Database Free (19c) 提供免费版本，可通过 Docker 快速部署：
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Oracle Database 26ai 安装

Oracle Database 26ai 为最新版本，安装指南请参考 Oracle 官方文档：
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### 容器化部署
Oracle Database 26ai 支持现代化的容器化部署方式：
```bash
# Docker 部署示例（具体镜像名称请参考官方文档）
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## 云服务部署

### Oracle Cloud Infrastructure (OCI)
- 在 OCI 控制台中选择 Database 服务
- 选择 Oracle Database 版本（19c 或 26ai）
- 配置计算实例和存储
- 自动完成安装和配置

### 其他云提供商
- AWS RDS for Oracle
- Azure Database for Oracle
- Google Cloud 的 Oracle 解决方案

## 故障排除

### 常见问题
- **权限问题**：确保 oracle 用户具有正确的文件和目录权限
- **端口冲突**：默认监听端口 1521，确保端口未被占用
- **内存不足**：调整 SGA 和 PGA 内存参数
- **字符集问题**：在安装时正确选择数据库字符集

### 日志位置
- 安装日志：`$ORACLE_BASE/cfgtoollogs/dbca/`
- 数据库警报日志：`$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
