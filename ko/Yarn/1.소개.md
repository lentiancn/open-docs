# Yarn 패키지 매니저

Yarn은 속도, 정확성, 보안 및 개발자 경험에 중점을 둔 오픈소스 패키지 매니저로, JavaScript 프로젝트의 의존성을 관리하는 데 사용됩니다.

## 버전 개요

### Yarn 4+ (모던 버전)
- **공식 문서**: https://yarnpkg.com/
- **상태**: 활발한 개발 및 유지보수 중
- **특징**: 
  - 워크스페이스 지원 (워크스페이스를 중심으로 특별히 구축된 최초의 패키지 매니저)
  - 안정성 보장 (오늘 작동하는 설치는 미래에도 동일한 방식으로 계속 작동함)
  - 플러그인 시스템 (다양한 문제를 해결하기 위한 도구 제공)
  - 혁신 (현상유지에 도전하고 워크플로우 개선)
  - 완전히 독립적인 오픈소스 프로젝트

### Yarn v3
- **공식 문서**: https://v3.yarnpkg.com/
- **상태**: 유지보수 중
- **특징**: Yarn Berry의 추가 진화, 대규모 모노레포 및 기업 사용자에게 적합

### Yarn Classic (v1)
- **공식 문서**: https://classic.yarnpkg.com/
- **상태**: 유지보수 중 (더 이상 주요 권장 버전은 아님)
- **특징**: 전통적인 Yarn 패키지 매니저, npm 메타데이터 형식과 호환

## 핵심 기능

- **속도**: 병렬 설치, 오프라인 캐싱
- **정확성**: 결정론적 설치, 잠금 파일
- **보안**: 강화 모드, 취약점 감사
- **개발자 경험**: 인터랙티브 명령어, 완전한 CLI 재구현

## 다른 패키지 매니저와의 차이점

대부분의 다른 패키지 매니저와 달리, Yarn은 설치와 관련되지 않은 명령어에 대해 npm에 의존하지 않고 모든 명령어를 재구현합니다. 이를 통해 Yarn은 개발자 경험과 안정성을 완전히 제어할 수 있습니다.

## 사용 사례

- 간단한 개인 프로젝트
- 대규모 기업용 모노레포
- 오픈소스 프로젝트 개발
- 안정적인 의존성 관리가 필요한 프로덕션 환경

> **참고**: 이 문서는 yarnpkg.com 공식 웹사이트의 콘텐츠를 기반으로 하며, Yarn 4+, v3 및 Classic 버전에 대한 공식 정보를 다룹니다.
