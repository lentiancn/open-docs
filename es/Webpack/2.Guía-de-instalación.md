# Guía de Instalación de Webpack

Webpack se usa para compilar módulos JavaScript. Una vez instalado, puede interactuar con webpack ya sea desde su CLI o API. Si es nuevo en webpack, lea los conceptos fundamentales y esta comparación para aprender por qué podría usarlo sobre otras herramientas que existen en la comunidad.

## Requisitos del Sistema

### Requisitos de Versión de Node.js

| Versión de Webpack | Versión de Node.js |
|--------------------|--------------------|
| Webpack 4.x | 6.x.x o posterior |
| Webpack 5.x | 10.13.0 o posterior |

Nota: Webpack 5 requiere una versión más reciente de Node.js que Webpack 4.

## Métodos de Instalación

Puede instalar webpack de dos maneras:

### Instalación Local (Recomendado)

Instalar webpack localmente le da más control sobre qué versión usa para un proyecto específico, y evita conflictos entre proyectos que pueden requerir diferentes versiones.

#### npm

```bash
mkdir webpack-demo
cd webpack-demo

# npm
npm init -y
npm install webpack webpack-cli --save-dev
```

#### yarn

```bash
mkdir webpack-demo
cd webpack-demo

# yarn
yarn init -y
yarn add webpack webpack-cli --dev
```

#### pnpm

```bash
mkdir webpack-demo
cd webpack-demo

# pnpm
pnpm init
pnpm add webpack webpack-cli -D
```

### Instalación Global

La instalación global no se recomienda porque le vincula a una sola versión de webpack en todos sus proyectos.

#### npm

```bash
npm install -g webpack
npm install -g webpack-cli
```

#### yarn

```bash
yarn global add webpack
yarn global add webpack-cli
```

#### pnpm

```bash
pnpm add -g webpack
pnpm add -g webpack-cli
```

## Webpack CLI

El paquete webpack-cli proporciona una interfaz consistente para interactuar con webpack a través de la línea de comandos. Es requerido para la mayoría de las funcionalidades de webpack.

### Compatibilidad de Versiones

| Versión de Webpack | Versión de webpack-cli |
|--------------------|------------------------|
| Webpack 4.x | webpack-cli 3.x o 4.x |
| Webpack 5.x | webpack-cli 4.x o 5.x |

### Instalación

```bash
# Para Webpack 4
npm install webpack@4 webpack-cli@4 --save-dev

# Para Webpack 5
npm install webpack@5 webpack-cli@5 --save-dev
```

## Inicio Rápido: Crear un Nuevo Proyecto

Webpack 5 introdujo una nueva herramienta llamada `create-webpack-app` para crear rápidamente un nuevo proyectowebpack.

### Usando create-webpack-app (Solo Webpack 5)

```bash
npx create-webpack-app webpack-demo
cd webpack-demo
```

Esto le preguntará varias cuestiones para configurar su proyecto:
- ¿Qué solución JS desea usar? (TypeScript, JavaScript)
- ¿Desea usar webpack-dev-server? (Sí/No)
- ¿Desea simplificar la creación de archivos HTML? (Sí/No)
- ¿Desea añadir soporte PWA? (Sí/No)
- ¿Qué solución CSS desea usar? (Solo CSS, CSS-in-JS, etc.)
- ¿Desea extraer CSS para cada archivo? (Solo para Producción/No)
- ¿Qué gestor de paquetes desea usar? (npm, yarn, pnpm)

### Configuración Manual del Proyecto

Si prefiere configurar su proyecto manualmente, siga estos pasos:

```bash
mkdir webpack-demo
cd webpack-demo

# Inicializar npm
npm init -y

# Instalar webpack
npm install webpack webpack-cli --save-dev

# Crear estructura de directorios
mkdir src dist

# Crear archivo de entrada
echo 'console.log("Hola webpack");' > src/index.js

# Crear archivo HTML
cat > dist/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Webpack Demo</title>
</head>
<body>
    <script src="main.js"></script>
</body>
</html>
EOF
```

## Archivo de Configuración

A partir de la versión 4, webpack no requiere un archivo de configuración para agrupar su proyecto. Sin embargo, la mayoría de los proyectos necesitarán una configuración más compleja, por lo que webpack soporta un archivo de configuración.

### Configuración Básica (Webpack 5 con ES Modules)

```javascript
// webpack.config.js
import path from "node:path";
import { fileURLToPath } from "node:url";

// En versiones de Node.js anteriores al soporte nativo para import.meta.dirname,
// derive __dirname de import.meta.url.
// (Node 20.11+ soporta import.meta.dirname y import.meta.filename.)
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

export default {
  entry: "./src/index.js",
  output: {
    filename: "main.js",
    path: path.resolve(__dirname, "dist"),
  },
};
```

### Configuración Básica (Webpack 4 / Webpack 5 con CommonJS)

```javascript
// webpack.config.js
const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'main.js',
    path: path.resolve(__dirname, 'dist')
  }
};
```

##Comparación de Versiones: Archivos de Configuración

| Característica | Webpack 4 | Webpack 5 |
|----------------|-----------|-----------|
| **Formato por Defecto** | CommonJS | ES Modules (también soporta CommonJS) |
| **Módulos ECMAScript** | Soporte limitado | Soporte completo |
| **import.meta.dirname** | No soportado | Soportado (Node 20.11+) |
| **Type Default** | `module` | `module` (si type en package.json) |

## Verificación de Instalación

Después de la instalación, puede verificar que webpack está instalado correctamente comprobando la versión:

```bash
# Verificar versión de webpack
npx webpack --version

# Verificar versión de webpack-cli
npx webpack-cli --version
```

Salida esperada:
```
 webpack 5.x.x
webpack-cli 4.x.x
```

## Comandos de Webpack CLI

Una vez instalado, puede usar varios comandos CLI de webpack:

| Comando | Descripción |
|---------|-------------|
| `webpack` | Ejecutar webpack (comando por defecto) |
| `webpack build` | Ejecutar build de webpack |
| `webpack watch` | Monitoring cambios en archivos |
| `webpack serve` | Ejecutar webpack-dev-server |
| `webpack info` | Output información del sistema |
| `webpack configtest` | Validar configuración de webpack |
| `webpack help` | Output ayuda |

### Uso Básico

```bash
# Sin archivo de configuración
npx webpack --entry ./src/index.js --output-path ./dist

# Con archivo de configuración
npx webpack --config webpack.config.js

# En modo watch
npx webpack --watch

# Con modo específico
npx webpack --mode development
npx webpack --mode production
```

## Scripts de Package.json

Para hacer trabajar con webpack más conveniente, añada scripts npm a su `package.json`:

### Configuración de Webpack 4

```json
{
  "name": "webpack-demo",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "build": "webpack",
    "watch": "webpack --watch"
  },
  "devDependencies": {
    "webpack": "^4.46.0",
    "webpack-cli": "^3.3.12"
  }
}
```

### Configuración de Webpack 5

```json
{
  "name": "webpack-demo",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "scripts": {
    "build": "webpack",
    "watch": "webpack --watch"
  },
  "devDependencies": {
    "webpack": "^5.88.0",
    "webpack-cli": "^5.1.4"
  }
}
```

## Características Específicas de CLI por Versión

### CLI de Webpack 4

- Comandos básicos de build y watch
- Opciones básicas de configuración
- Soporte limitado de plugins desde CLI

### CLI de Webpack 5

- Schema de configuración mejorada del núcleo de webpack
- Más opciones disponibles desde línea de comandos
- Mejores mensajes de error y diagnóstico
- Soporte para `create-webpack-app` scaffolding

## Solución de Problemas

### Problemas Comunes de Instalación

#### 1. Versión de Node.js Demasiado Vieja

Error: `Webpack 5 requires Node.js version 10.13.0 or later`

Solución: Actualizar Node.js a una versión soportada

#### 2. webpack-cli Faltante

Error: `Could not find webpack-cli. Did you mean to install it?`

Solución: Instalar webpack-cli como dev dependency:
```bash
npm install webpack-cli --save-dev
```

#### 3. Errores de Permiso

Error: `EACCES: permission denied`

Solución: Usar `sudo` o solucionar permisos npm:
```bash
# Opción 1: Usar sudo (no recomendado)
sudo npm install -g webpack

# Opción 2: Solucionar permisos npm
sudo chown -R $(whoami) ~/.npm
```

#### 4. Pacote No Encontrado

Error: `Cannot find module 'webpack'`

Solución: Asegurarse de que webpack esté instalado localmente:
```bash
npm install webpack --save-dev
```

### Conflictos de Versión

Si tiene múltiples versiones de webpack instaladas globalmente, puede encontrar conflictos:

```bash
# Ver paquetes globales
npm list -g webpack webpack-cli

# Desinstalar versiones conflictivas
npm uninstall -g webpack
npm uninstall -g webpack-cli

# Instalar versión específica
npm install -g webpack@5
npm install -g webpack-cli@4
```
