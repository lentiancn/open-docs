# Oracle Database

Oracle Database 是甲骨文公司開發的企業級關聯式資料庫管理系統。

## 文件版本

- **Oracle Database 26ai** - 最新版本（2026年發布）
- **Oracle Database 19c** - 長期支援版本

## 文件結構

1. **簡介** - Oracle Database 概述和主要特性
2. **安裝指南** - 詳細安裝步驟和系統需求
3. **使用手冊** - SQL、PL/SQL 編程和管理操作
4. **常見問題** - 常見問題解答和故障排除
