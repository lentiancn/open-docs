# Oracle Database 설치 가이드

## Oracle Database 19c 설치

### 시스템 요구사항

#### 운영체제 지원
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### 하드웨어 요구사항
- **메모리**: 최소 2GB RAM (4GB 이상 권장)
- **디스크 공간**: 최소 6.5GB 여유 공간 (엔터프라이즈 에디션)
- **프로세서**: 운영체제에서 지원하는 프로세서 아키텍처

### 설치 단계

#### 1. 소프트웨어 다운로드
Oracle Software Delivery Cloud에서 Oracle Database 19c 설치 패키지를 가져오세요:
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. 시스템 환경 준비
```bash
# Linux 시스템 예시
# oracle 사용자 및 그룹 생성
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# 커널 파라미터 설정
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# 사용자 제한 설정
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. 설치 프로그램 실행
```bash
# 설치 패키지 압축 해제 및 설치 프로그램 실행
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. 그래픽 설치 마법사
- 설치 유형 선택 (데스크톱 클래스, 서버 클래스)
- 데이터베이스 식별 구성 (글로벌 데이터베이스 이름, SID)
- 관리 비밀번호 설정
- root 스크립트 실행
- 설치 완료

### 무료 버전 설치
Oracle Database Free (19c)는 무료 버전을 제공하며 Docker를 통해 빠르게 배포할 수 있습니다:
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Oracle Database 26ai 설치

Oracle Database 26ai는 최신 버전입니다. 설치 가이드는 오라클 공식 문서를 참조하십시오:
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### 컨테이너화 배포
Oracle Database 26ai는 현대적인 컨테이너화 배포 방법을 지원합니다:
```bash
# Docker 배포 예시 (구체적인 이미지 이름은 공식 문서 참조)
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## 문제 해결

### 일반적인 문제
- **권한 문제**: oracle 사용자가 올바른 파일 및 디렉토리 권한을 가지고 있는지 확인
- **포트 충돌**: 기본 리스닝 포트 1521, 포트가 사용 중인지 확인
- **메모리 부족**: SGA 및 PGA 메모리 파라미터 조정
- **문자 집합 문제**: 설치 시 데이터베이스 문자 집합을 올바르게 선택

### 로그 위치
- 설치 로그: `$ORACLE_BASE/cfgtoollogs/dbca/`
- 데이터베이스 경고 로그: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
