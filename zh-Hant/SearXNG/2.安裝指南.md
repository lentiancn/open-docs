# SearXNG 安裝指南

本指南涵蓋設定您自己的 SearXNG 實例的多種安裝方法。

## 安裝方法

### 1. 容器安裝（推薦）

最簡單和最可靠的 方法是使用 Docker 或 Podman 容器。

**先決條件：**
- 已安裝 Docker 或 Podman
- 基本的容器管理知識

**步驟：**
```bash
# 拉取官方 SearXNG 映像
docker pull searxng/searxng

# 使用基本設定執行
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. 安裝指令碼

提供了一個自動化安裝指令碼，可以自動處理大部分設定，包括 uWSGI 設定。

**步驟：**
```bash
# 下載安裝指令碼
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# 賦予執行權限並執行
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. 逐步手動安裝

適用於希望完全控制安裝過程的進階使用者。

**先決條件：**
- Python 3.8 或更高版本
- uWSGI
- Git
- 建置工具（gcc、make 等）
- Web 伺服器（NGINX 或 Apache）

**安裝步驟：**

1. **安裝所需套件：**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **建立專用使用者：**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **複製儲存庫：**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **設定設定：**
   ```bash
   # 複製預設設定
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # 根據需要編輯設定
   sudo nano /etc/searxng/settings.yml
   ```

5. **設定 Web 伺服器：**
   
   **NGINX 設定範例：**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## 安裝後操作

安裝完成後，在 `http://your-server:port` 存取您的 SearXNG 實例並驗證其是否正常運作。您可以透過 `settings.yml` 設定檔自訂外觀、引擎和行為。

## 故障排除

- **權限問題**：確保 searxng 使用者對所有檔案具有適當的權限
- **連接埠衝突**：驗證所選連接埠未被佔用
- **引擎設定**：某些搜尋引擎可能需要 API 金鑰或特定設定
- **SSL 設定**：用於生產環境時，使用 Let's Encrypt 或您首選的 CA 設定 SSL 憑證
