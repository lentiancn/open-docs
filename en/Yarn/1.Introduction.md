# Yarn Package Manager

Yarn is an open-source package manager focused on speed, correctness, security, and developer experience, used to manage dependencies in JavaScript projects.

## Version Overview

### Yarn 4+ (Modern Version)
- **Official Documentation**: https://yarnpkg.com/
- **Status**: Actively developed and maintained
- **Features**: 
  - Workspace support (first package manager built specifically around workspaces)
  - Stability guarantee (installs that work today will keep working the same way in the future)
  - Plugin system (provides tools to solve various problems)
  - Innovation (challenges the status quo, improves workflows)
  - Fully independent open-source project

### Yarn v3
- **Official Documentation**: https://v3.yarnpkg.com/
- **Status**: Maintained
- **Features**: Further evolution of Yarn Berry, suitable for large monorepos and enterprise users

### Yarn Classic (v1)
- **Official Documentation**: https://classic.yarnpkg.com/
- **Status**: Maintained (but not the primary recommended version)
- **Features**: Traditional Yarn package manager, compatible with npm metadata format

## Core Features

- **Speed**: Parallel installs, offline caching
- **Correctness**: Deterministic installs, lock files
- **Security**: Hardened mode, vulnerability auditing
- **Developer Experience**: Interactive commands, complete CLI reimplementation

## Differences from Other Package Managers

Unlike most other package managers, Yarn reimplements all commands instead of relying on npm for non-install-related commands. This allows Yarn to have full control over developer experience and stability.

## Use Cases

- Simple personal projects
- Large enterprise monorepos
- Open-source project development
- Production environments requiring stable dependency management
