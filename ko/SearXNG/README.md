# SearXNG

SearXNG는 사용자를 추적하거나 프로파일링하지 않고 250개 이상의 검색 서비스에서 결과를 집계하여 개인정보를 보호하는 무료 인터넷 메타검색 엔진입니다.

## 공식 리소스
- **웹사이트**: https://searxng.org
- **문서**: https://docs.searxng.org  
- **소스 코드**: https://github.com/searxng/searxng
- **공개 인스턴스**: https://searx.space

## 주요 기능
- 개인정보 보호 중심의 메타검색 엔진
- 사용자 추적 또는 데이터 수집 없음
- 향상된 익명성을 위한 Tor 지원
- 고도로 맞춤 설정 가능하고 구성 가능
- 오픈 소스 및 커뮤니티 주도

## 버전 정보
- **최신 버전**: 2026.3.29+7ac4ff39f
- **릴리스 모델**: 롤링 릴리스 (마스터 브랜치에서 일일 업데이트)
