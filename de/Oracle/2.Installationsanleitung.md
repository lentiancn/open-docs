# Installationsanleitung für Oracle Database

## Installation von Oracle Database 19c

### Systemanforderungen

#### Unterstützte Betriebssysteme
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### Hardwareanforderungen
- **Arbeitsspeicher**: Mindestens 2GB RAM (4GB oder mehr empfohlen)
- **Festplattenspeicher**: Mindestens 6,5GB freier Speicherplatz (Enterprise Edition)
- **Prozessor**: Prozessorarchitektur, die vom Betriebssystem unterstützt wird

### Installationsschritte

#### 1. Software herunterladen
Laden Sie die Oracle Database 19c Installationspakete von Oracle Software Delivery Cloud herunter:
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. Systemumgebung vorbereiten
```bash
# Beispiel für Linux-Systeme
# Oracle-Benutzer und -Gruppen erstellen
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# Kernel-Parameter festlegen
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# Benutzerbeschränkungen festlegen
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. Installer ausführen
```bash
# Installationspaket entpacken und Installer ausführen
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. Grafischer Installationsassistent
- Installationstyp auswählen (Desktop-Klasse, Server-Klasse)
- Datenbankidentifikation konfigurieren (Globaler Datenbankname, SID)
- Verwaltungspasswörter festlegen
- Root-Skripte ausführen
- Installation abschließen

### Installation der kostenlosen Version
Oracle Database Free (19c) bietet eine kostenlose Version, die schnell über Docker bereitgestellt werden kann:
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Installation von Oracle Database 26ai

Oracle Database 26ai ist die neueste Version. Die Installationsanleitung finden Sie in der offiziellen Oracle-Dokumentation:
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### Container-basierte Bereitstellung
Oracle Database 26ai unterstützt moderne containerbasierte Bereitstellungsmethoden:
```bash
# Docker-Bereitstellungsbeispiel (spezifischer Imagename gemäß offizieller Dokumentation)
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## Cloud-Service-Bereitstellung

### Oracle Cloud Infrastructure (OCI)
- Datenbank-Service in OCI-Konsole auswählen
- Oracle Database-Version wählen (19c oder 26ai)
- Compute-Instanz und Speicher konfigurieren
- Automatischer Abschluss der Installation und Konfiguration

### Andere Cloud-Anbieter
- AWS RDS for Oracle
- Azure Database for Oracle
- Google Cloud Oracle-Lösungen

## Fehlerbehebung

### Häufige Probleme
- **Berechtigungsprobleme**: Stellen Sie sicher, dass der Oracle-Benutzer über die richtigen Datei- und Verzeichnisberechtigungen verfügt
- **Portkonflikte**: Standard-Überwachungsport 1521, stellen Sie sicher, dass der Port nicht belegt ist
- **Unzureichender Speicher**: Passen Sie SGA- und PGA-Speicherparameter an
- **Zeichensatzprobleme**: Wählen Sie während der Installation den richtigen Datenbankzeichensatz aus

### Protokollspeicherorte
- Installationsprotokolle: `$ORACLE_BASE/cfgtoollogs/dbca/`
- Datenbank-Alarmprotokolle: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
