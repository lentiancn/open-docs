# Oracle Database インストールガイド

## Oracle Database 19c インストール

### システム要件

#### オペレーティングシステムサポート
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### ハードウェア要件
- **メモリ**：最低 2GB RAM（4GB 以上推奨）
- **ディスクスペース**：最低 6.5GB の空き容量（エンタープライズエディション）
- **プロセッサ**：対応オペレーティングシステムのプロセッサアーキテクチャ

### インストール手順

#### 1. ソフトウェアのダウンロード
Oracle Software Delivery Cloud から Oracle Database 19c インストールパッケージを取得します：
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. システム環境の準備
```bash
# Linux システムの例
# oracle ユーザーとグループの作成
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# カーネルパラメータの設定
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# ユーザー制限の設定
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. インストーラーの実行
```bash
# インストールパッケージの展開とインストーラーの実行
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. グラフィカルインストールウィザード
- インストールタイプの選択（デスクトップクラス、サーバークラス）
- データベース識別情報の設定（グローバルデータベース名、SID）
- 管理パスワードの設定
- root スクリプトの実行
- インストールの完了

### 無料版のインストール
Oracle Database Free (19c) は無料版を提供しており、Docker で迅速にデプロイできます：
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Oracle Database 26ai インストール

Oracle Database 26ai は最新バージョンです。インストールガイドについては Oracle 公式ドキュメントを参照してください：
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### コンテナ化デプロイメント
Oracle Database 26ai は、最新のコンテナ化デプロイメント方法をサポートしています：
```bash
# Docker デプロイメントの例（具体的なイメージ名は公式ドキュメントを参照）
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## クラウドサービスデプロイメント

### Oracle Cloud Infrastructure (OCI)
- OCI コンソールで Database サービスを選択
- Oracle Database バージョンを選択（19c または 26ai）
- コンピュートインスタンスとストレージを設定
- 自動的にインストールと設定が完了

### 他のクラウドプロバイダー
- AWS RDS for Oracle
- Azure Database for Oracle
- Google Cloud Oracle ソリューション

## トラブルシューティング

### よくある問題
- **権限の問題**：oracle ユーザーが正しいファイルおよびディレクトリ権限を持っていることを確認
- **ポートの競合**：デフォルトのリスニングポート 1521 が使用されていないことを確認
- **メモリ不足**：SGA および PGA メモリパラメータを調整
- **文字セットの問題**：インストール時にデータベース文字セットを正しく選択

### ログの場所
- インストールログ：`$ORACLE_BASE/cfgtoollogs/dbca/`
- データベースアラートログ：`$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
