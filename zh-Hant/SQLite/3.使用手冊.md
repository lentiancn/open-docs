# SQLite 使用手冊

本手冊介紹 SQLite 的基本使用方法，包括命令行工具和 SQL 語法。

## 命令行界面 (CLI)

### 啟動 SQLite

```bash
# 創建或打開數據庫文件
sqlite3 database.db

# 以只讀模式打開
sqlite3 -readonly database.db

# 執行單個命令後退出
sqlite3 database.db "SELECT * FROM table;"
```

### CLI 命令

SQLite CLI 提供多種點命令（以點開頭）：

- `.help` - 顯示幫助信息
- `.tables` - 列出所有表
- `.schema [table]` - 顯示表結構
- `.dump [table]` - 導出數據庫內容為 SQL
- `.mode [mode]` - 設置輸出格式（csv、json、line、list 等）
- `.headers on|off` - 開啟/關閉列名顯示
- `.output filename` - 將輸出重定向到文件
- `.read filename` - 執行 SQL 腳本文件
- `.quit` 或 `.exit` - 退出 CLI

### 示例會話

```sql
-- 連接到數據庫
$ sqlite3 test.db

-- 創建表
sqlite> CREATE TABLE users (
   ...> id INTEGER PRIMARY KEY,
   ...> name TEXT NOT NULL,
   ...> email TEXT UNIQUE
   ...> );

-- 插入數據
sqlite> INSERT INTO users (name, email) VALUES ('張三', 'zhang@example.com');
sqlite> INSERT INTO users (name, email) VALUES ('李四', 'li@example.com');

-- 查詢數據
sqlite> SELECT * FROM users;
1|張三|zhang@example.com
2|李四|li@example.com

-- 退出
sqlite> .quit
```

## SQL 語法基礎

### 數據類型

SQLite 使用動態類型系統，但支持以下存儲類別：

- **NULL** - 空值
- **INTEGER** - 有符號整數
- **REAL** - 浮點數
- **TEXT** - 字符串文本
- **BLOB** - 二進制大對象

### 常用語句

#### CREATE TABLE
```sql
CREATE TABLE table_name (
    column1 datatype PRIMARY KEY,
    column2 datatype NOT NULL,
    column3 datatype DEFAULT value,
    FOREIGN KEY (column1) REFERENCES other_table(column)
);
```

#### INSERT
```sql
-- 插入完整行
INSERT INTO table_name VALUES (value1, value2, ...);

-- 插入指定列
INSERT INTO table_name (column1, column2) VALUES (value1, value2);
```

#### SELECT
```sql
-- 基本查詢
SELECT column1, column2 FROM table_name WHERE condition;

-- 排序
SELECT * FROM table_name ORDER BY column1 ASC/DESC;

-- 限制結果數量
SELECT * FROM table_name LIMIT 10 OFFSET 5;
```

#### UPDATE
```sql
UPDATE table_name SET column1 = value1 WHERE condition;
```

#### DELETE
```sql
DELETE FROM table_name WHERE condition;
```

## 事務處理

SQLite 支持 ACID 事務：

```sql
BEGIN TRANSACTION;
-- SQL 語句
COMMIT; -- 或 ROLLBACK;
```

## 性能提示

- 使用事務批量操作以提高性能
- 為經常查詢的列創建索引
- 避免在 WHERE 子句中對列進行函數操作
- 使用 PRAGMA 語句優化數據庫設置

## 常見 PRAGMA 語句

- `PRAGMA journal_mode = WAL;` - 啟用 Write-Ahead Logging
- `PRAGMA synchronous = NORMAL;` - 平衡安全性和性能
- `PRAGMA cache_size = 10000;` - 設置頁面緩存大小
- `PRAGMA foreign_keys = ON;` - 啟用外鍵約束

這些只是 SQLite 功能的基礎。詳細信息請參考官方文檔。
