# Yarn 套件管理器

Yarn 是一個專注於速度、正確性、安全性和開發者體驗的開源套件管理器，用於管理 JavaScript 專案中的相依性關係。

## 版本概覽

### Yarn 4+ (現代版本)
- **官方文件**: https://yarnpkg.com/
- **狀態**: 活躍開發和維護中
- **特點**: 
  - 工作區支援（首個專門為工作區構建的套件管理器）
  - 穩定性保證（今天能正常運作的安裝在未來也會以相同方式運作）
  - 外掛系統（提供解決各種問題的工具）
  - 創新性（挑戰現狀，改進工作流程）
  - 完全獨立的開源專案

### Yarn v3
- **官方文件**: https://v3.yarnpkg.com/
- **狀態**: 維護中
- **特點**: Yarn Berry 的進一步演進，適用於大型單體倉儲和企業用戶

### Yarn Classic (v1)
- **官方文件**: https://classic.yarnpkg.com/
- **狀態**: 維護中（但已不是主要推薦版本）
- **特點**: 傳統的 Yarn 套件管理器，與 npm 元資料格式相容

## 核心功能

- **速度**: 平行安裝、離線快取
- **正確性**: 確定性安裝、鎖定檔案
- **安全性**: 強化模式、漏洞稽核
- **開發者體驗**: 互動式指令、完整的 CLI 重新實作

## 與其他套件管理器的差異

與大多數其他套件管理器不同，Yarn 重新實作了所有指令，而不是依賴 npm 來處理非安裝相關的指令。這使得 Yarn 能夠完全控制開發者體驗和穩定性。

## 適用場景

- 簡單的個人專案
- 大型企業級單體倉儲
- 開源專案開發
- 需要穩定相依性管理的生產環境

> **注意**: 本文檔基於官方 yarnpkg.com 網站內容整理，涵蓋 Yarn 4+、v3 和 Classic 版本的官方資訊。
