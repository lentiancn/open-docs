# SearXNG 常见问题（FAQ）

## 一般问题

### 什么是 SearXNG？
SearXNG 是一个免费的互联网元搜索引擎，能够聚合来自多达 250 个不同搜索服务的结果。它旨在通过不跟踪或画像用户来保护用户隐私，确保搜索期间的完全匿名性。

### 为什么我应该使用 SearXNG 而不是常规搜索引擎？
- **隐私保护**：无用户跟踪、画像或数据收集
- **无过滤气泡**：结果不会根据您的历史记录进行个性化
- **多个来源**：聚合许多搜索引擎的结果
- **开源**：透明的代码可以被任何人审计
- **可定制**：高度可配置以满足个人偏好
- **免费使用**：无费用且无广告

### SearXNG 是如何工作的？
SearXNG 充当元搜索引擎，同时将您的查询发送到多个搜索服务，然后聚合结果并在统一界面中呈现。它从请求中删除识别信息并清理结果以保护您的隐私。

## 使用问题

### 如何将 SearXNG 设置为我的默认搜索引擎？
SearXNG 支持 OpenSearch，允许您轻松将其添加到浏览器的搜索提供商：
1. 访问任何 SearXNG 实例
2. 查找 "添加到浏览器" 或设置选项
3. 按照浏览器的说明将其添加为搜索提供商
4. 在浏览器设置中将其设为默认

### 我可以在 Tor 上使用 SearXNG 吗？
可以！SearXNG 可以通过 Tor 使用以增强在线匿名性。许多公共实例支持 Tor 连接，您也可以设置自己的实例与 Tor 配合使用。

### SearXNG 支持什么搜索语法？
SearXNG 支持强大的搜索语法，包括：
- `!engine_name query` - 搜索特定引擎
- `:language query` - 用特定语言搜索  
- `!!external_service query` - 直接重定向到外部服务
- 特殊功能如 `random uuid`、`avg numbers`、哈希函数等

## 技术问题

### 公共实例和私有实例有什么区别？
- **公共实例**：由志愿者托管，方便但需要信任操作员
- **私有实例**：自托管，让您完全控制隐私设置和配置

### SearXNG 支持多少个搜索引擎？
SearXNG 配置了 **250 个搜索引擎**，默认启用了 **96 个**。您可以根据偏好通过设置启用/禁用引擎。

### SearXNG 是否存储任何用户数据？
正确配置的 SearXNG 实例**不存储任何用户数据**。它们实施三个级别的数据删除：
1. 向搜索引擎发送请求时
2. 第三方服务  
3. 结果页面

### 我可以为 SearXNG 开发做贡献吗？
可以！SearXNG 是开源的，欢迎贡献。您可以：
- 在 GitHub 上报告错误或建议功能
- 贡献代码改进
- 帮助编写文档
- 将界面翻译成其他语言
- 运行和维护公共实例

## 安装问题

### 自托管的系统要求是什么？
- Python 3.8 或更高版本
- 基本的 Web 服务器知识
- 大约 500MB 磁盘空间
- 任何现代 Linux 发行版（Ubuntu、Debian、CentOS 等）

### 是否推荐 Docker 安装？
是的，Docker/Podman 容器安装是**推荐的方法**，因为它提供最简单的设置、自动更新和适当的隔离。

### 如何更新我的 SearXNG 实例？
- **Docker**：拉取最新镜像并重启容器
- **脚本安装**：再次运行安装脚本
- **手动安装**：从 git 拉取最新更改并重启服务

## 隐私和安全

### SearXNG 有多安全？
SearXNG 的设计将安全和隐私作为首要任务：
- 无用户跟踪或画像
- HTTPS 支持加密连接
- 定期安全审计和更新
- 开源代码以保证透明度

### SearXNG 可以信任吗？
由于 SearXNG 是开源的，您可以：
- 自己审查代码
- 运行自己的私有实例以获得完全控制
- 从 searx.space 选择信誉良好的公共实例
- 验证安装的完整性

为了获得最大的隐私和信任，运行您自己的实例始终是最好的选择。
