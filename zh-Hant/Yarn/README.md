# Yarn 套件管理器

Yarn 是一個專注於速度、正確性、安全性和開發者體驗的開源套件管理器，用於管理 JavaScript 專案中的相依性關係。

## 版本概覽

- **Yarn 4+ (現代版本)**: 活躍開發和維護中，提供工作區、外掛系統等進階功能
- **Yarn v3**: 維護中，適用於大型單體倉儲和企業用戶  
- **Yarn Classic (v1)**: 維護中，傳統的 Yarn 套件管理器
