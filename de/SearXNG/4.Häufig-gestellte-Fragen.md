# SearXNG Häufig gestellte Fragen (FAQ)

## Allgemeine Fragen

### Was ist SearXNG?
SearXNG ist eine kostenlose Internet-Metasuchmaschine, die Ergebnisse aus bis zu 250 verschiedenen Suchdiensten aggregiert. Sie wurde entwickelt, um Benutzerdaten durch fehlende Verfolgung oder Profilierung zu schützen und so vollständige Anonymität während der Suche zu gewährleisten.

### Warum sollte ich SearXNG anstelle regulärer Suchmaschinen verwenden?
- **Datenschutz**: Keine Benutzerverfolgung, Profilierung oder Datensammlung
- **Keine Filterblasen**: Ergebnisse werden nicht basierend auf Ihrem Verlauf personalisiert
- **Mehrere Quellen**: Aggregiert Ergebnisse aus vielen Suchmaschinen
- **Open Source**: Transparenter Code, der von jedem überprüft werden kann
- **Anpassbar**: Hochgradig konfigurierbar für persönliche Vorlieben
- **Kostenlos**: Keine Kosten und keine Werbung

### Wie funktioniert SearXNG?
SearXNG fungiert als Metasuchmaschine, die Ihre Abfrage gleichzeitig an mehrere Suchdienste sendet, dann die Ergebnisse aggregiert und in einer einheitlichen Oberfläche präsentiert. Es entfernt Identifikationsinformationen aus Anfragen und bereinigt Ergebnisse, um Ihre Privatsphäre zu schützen.

## Nutzungsfragen

### Wie stelle ich SearXNG als meine Standardsuchmaschine ein?
SearXNG unterstützt OpenSearch, was es Ihnen ermöglicht, es einfach zu den Suchanbietern Ihres Browsers hinzuzufügen:
1. Besuchen Sie eine beliebige SearXNG-Instanz
2. Suchen Sie nach der Option "Zum Browser hinzufügen" oder Einstellungen
3. Folgen Sie den Anweisungen Ihres Browsers, um es als Suchanbieter hinzuzufügen
4. Stellen Sie es in Ihren Browsereinstellungen als Standard ein

### Kann ich SearXNG mit Tor verwenden?
Ja! SearXNG kann über Tor verwendet werden, um die Online-Anonymität zu verbessern. Viele öffentliche Instanzen unterstützen Tor-Verbindungen, und Sie können auch Ihre eigene Instanz so einrichten, dass sie mit Tor funktioniert.

### Welche Suchsyntax unterstützt SearXNG?
SearXNG unterstützt eine leistungsstarke Suchsyntax, einschließlich:
- `!engine_name query` - Durchsuchen einer bestimmten Suchmaschine
- `:language query` - Suche in einer bestimmten Sprache  
- `!!external_service query` - Direkte Weiterleitung zu einem externen Dienst
- Spezielle Funktionen wie `random uuid`, `avg numbers`, Hash-Funktionen usw.

## Technische Fragen

### Was ist der Unterschied zwischen öffentlichen und privaten Instanzen?
- **Öffentliche Instanzen**: Von Freiwilligen gehostet, bequem, erfordern aber Vertrauen in den Betreiber
- **Private Instanzen**: Selbstgehostet, geben Ihnen vollständige Kontrolle über Datenschutzeinstellungen und Konfiguration

### Wie viele Suchmaschinen unterstützt SearXNG?
SearXNG ist mit **250 Suchmaschinen** konfiguriert, wobei standardmäßig **96 aktiviert** sind. Sie können Suchmaschinen basierend auf Ihren Vorlieben über die Einstellungen aktivieren/deaktivieren.

### Speichert SearXNG Benutzerdaten?
Ordentlich konfigurierte SearXNG-Instanzen speichern **keine Benutzerdaten**. Sie implementieren drei Ebenen der Datenentfernung:
1. Von Anfragen an Suchdienste
2. Von Diensten Dritter  
3. Von Ergebnisseiten

### Kann ich zur SearXNG-Entwicklung beitragen?
Ja! SearXNG ist Open Source und freut sich über Beiträge. Sie können:
- Fehler melden oder Funktionen auf GitHub vorschlagen
- Code-Verbesserungen beitragen
- Bei der Dokumentation helfen
- Die Oberfläche in andere Sprachen übersetzen
- Öffentliche Instanzen betreiben und pflegen

## Installationsfragen

### Was sind die Systemanforderungen für das Self-Hosting?
- Python 3.8 oder höher
- Grundlegende Webserver-Kenntnisse
- Etwa 500 MB Festplattenspeicher
- Jede moderne Linux-Distribution (Ubuntu, Debian, CentOS usw.)

### Wird die Docker-Installation empfohlen?
Ja, die Docker/Podman-Container-Installation ist die **empfohlene Methode**, da sie die einfachste Einrichtung, automatische Updates und ordnungsgemäße Isolation bietet.

### Wie aktualisiere ich meine SearXNG-Instanz?
- **Docker**: Ziehen Sie das neueste Image und starten Sie den Container neu
- **Skript-Installation**: Führen Sie das Installationsskript erneut aus
- **Manuelle Installation**: Ziehen Sie die neuesten Änderungen aus Git und starten Sie die Dienste neu

## Datenschutz und Sicherheit

### Wie sicher ist SearXNG?
SearXNG wurde mit Sicherheit und Datenschutz als höchste Prioritäten entwickelt:
- Keine Benutzerverfolgung oder Profilierung
- HTTPS-Unterstützung für verschlüsselte Verbindungen
- Regelmäßige Sicherheitsüberprüfungen und Updates
- Open-Source-Code für Transparenz

### Kann SearXNG vertraut werden?
Da SearXNG Open Source ist, können Sie:
- Den Code selbst überprüfen
- Ihre eigene private Instanz für vollständige Kontrolle betreiben
- Seriöse öffentliche Instanzen von searx.space wählen
- Die Integrität der Installation überprüfen

Für maximalen Datenschutz und Vertrauen ist das Betreiben Ihrer eigenen Instanz immer die beste Option.
