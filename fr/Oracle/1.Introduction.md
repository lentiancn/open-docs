# Introduction à Oracle Database

Oracle Database est un système de gestion de bases de données relationnelles (SGBDR) développé par Oracle Corporation, et fait partie des solutions de base de données d'entreprise les plus reconnues au monde.

## Versions Principales

### Oracle Database 26ai
Oracle Database 26ai (nom complet : Oracle AI Database 26ai) est la version la plus récente d'Oracle Database, publiée en 2026. Cette version intègre des capacités avancées d'intelligence artificielle, offrant des fonctionnalités améliorées de gestion automatisée et d'optimisation des performances.

**Remarque** : Oracle Database 26ai est la version la plus récente. La documentation technique détaillée doit être consultée sur le site officiel d'Oracle.

### Oracle Database 19c
Oracle Database 19c est la version à support à long terme d'Oracle Database, fournissant des fonctionnalités de base de données d'entreprise stables et fiables. Cette version prend en charge plusieurs plateformes de systèmes d'exploitation, notamment Windows x64, Linux x86-64, Linux ARM, Solaris, AIX, HP-UX et Linux on System z.

## Fonctionnalités Principales

- **Haute Disponibilité** : Fournit des solutions de haute disponibilité telles que Real Application Clusters (RAC) et Data Guard
- **Sécurité** : Fonctionnalités de sécurité avancées intégrées, incluant le chiffrement transparent des données, l'audit et le contrôle d'accès
- **Évolutivité** : Prend en charge divers modèles de déploiement, des instances individuelles aux clusters distribués à grande échelle
- **Optimisation des Performances** : Réglage automatique SQL, gestion de la mémoire et optimisation du stockage
- **Prise en charge Multi-modèle** : Prend en charge plusieurs modèles de données incluant relationnel, JSON, XML et graphe
- **Natif Cloud** : Prend en charge le déploiement conteneurisé et l'intégration avec les environnements cloud
