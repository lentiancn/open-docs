# Менеджер пакетов Yarn

Yarn — это менеджер пакетов с открытым исходным кодом, ориентированный на скорость, корректность, безопасность и удобство разработчика, используемый для управления зависимостями в JavaScript-проектах.

## Обзор версий

- **Yarn 4+ (Современная версия)**: Активная разработка и поддержка, предоставляет расширенные функции, такие как рабочие пространства и система плагинов
- **Yarn v3**: Поддерживается, подходит для крупных монорепозиториев и корпоративных пользователей  
- **Yarn Classic (v1)**: Поддерживается, традиционный менеджер пакетов Yarn
