# Oracle Database 簡介

Oracle Database 是甲骨文公司（Oracle Corporation）開發的關聯式資料庫管理系統（RDBMS），是全球最知名的企業級資料庫解決方案之一。

## 主要版本

### Oracle Database 26ai
Oracle Database 26ai（全稱：Oracle AI Database 26ai）是 Oracle Database 的最新版本，於 2026 年發布。該版本整合了先進的人工智慧功能，提供增強的自動化管理和效能優化能力。

**注意**：Oracle Database 26ai 為最新發布版本，詳細技術文件請參考 Oracle 官方網站。

### Oracle Database 19c
Oracle Database 19c 是 Oracle Database 的長期支援版本，提供穩定可靠的企業級資料庫功能。該版本支援多種作業系統平台，包括 Windows x64、Linux x86-64、Linux ARM、Solaris、AIX、HP-UX 和 Linux on System z。

## 核心特性

- **高可用性**：提供 Real Application Clusters (RAC)、Data Guard 等高可用性解決方案
- **安全性**：內建進階安全功能，包括透明資料加密、稽核和存取控制
- **可擴充性**：支援從單機部署到大規模分散式叢集的各種部署模式
- **效能優化**：自動 SQL 調校、記憶體管理和儲存優化
- **多模型支援**：支援關聯式、JSON、XML、圖形等多種資料模型
- **雲原生**：支援容器化部署和雲環境整合
