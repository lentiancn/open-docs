# Yarn 설치 가이드

## Yarn 4+ (모던 버전) 설치

### 권장 설치 방법 (Corepack 사용)

Corepack은 프로젝트별로 패키지 매니저 버전을 구성할 수 있는 중간 도구입니다:

```bash
# Corepack을 전역적으로 설치
npm install -g corepack

# 새 프로젝트 초기화 (Yarn Berry 사용)
yarn init -2
```

### Yarn 업데이트

언제든지 최신 버전으로 업데이트하려면 다음을 실행하세요:

```bash
yarn set version stable
yarn install
```

Yarn은 프로젝트를 최신 안정 바이너리를 사용하도록 구성합니다.

### Canary 버전 사용

Yarn은 자주 릴리스 후보 빌드를 제공합니다. 아직 안정 채널에 출시되지 않은 기능이 필요한 경우:

```bash
yarn set version canary
```

이러한 빌드는 매우 안정적이며, 일반 채널과의 유일한 차이점은 새로운 중단 변경사항을 구현함에 따라 주요 버전 간에 더 계단식 마이그레이션을 수행한다는 것입니다.

### master에서 최신 빌드 설치

릴리스 후보에도 포함되지 않은 매우 최신의 Yarn 버전을 테스트하고 싶은 경우:

```bash
# master 브랜치에서 복제, 빌드 및 설치
yarn set version from sources

# 특정 PR 테스트
yarn set version from sources --branch 1211
```

**참고**: `yarn set version from sources` 명령어는 Corepack을 활용할 수 없으며, Yarn 바이너리를 `.yarn/releases` 폴더 내에 저장하고 프로젝트의 `.yarnrc.yml` 파일에서 참조해야 합니다.

## Yarn Classic (v1) 설치

### npm을 통한 설치 (권장)

Node.js와 함께 번들로 제공되는 npm 패키지 매니저를 통해 Yarn을 설치하는 것이 권장됩니다:

```bash
# Yarn Classic 설치 또는 업그레이드
npm install --global yarn
```

### 설치 확인

설치 후 다음 명령어를 실행하여 Yarn이 올바르게 설치되었는지 확인하세요:

```bash
yarn --version
```

## 버전 선택 권장사항

- **새 프로젝트**: 최신 기능과 개선 사항을 누리기 위해 Yarn 4+ (모던 버전) 사용 권장
- **기존 프로젝트**: 
  - 이미 Yarn Classic을 사용 중이라면 계속 사용 가능
  - 더 나은 성능과 기능을 위해 모던 버전으로 마이그레이션 고려
- **기업 환경**: 모던 버전은 워크스페이스 지원과 안정성 보장을 더 잘 제공

## 시스템 요구사항

- **Node.js**: 모든 버전은 Node.js 환경이 필요함
- **npm**: Yarn Classic은 전역 설치를 위해 npm이 필요함
- **Corepack**: 모던 버전은 버전 관리를 위해 Corepack 사용을 권장함

> **참고**: 이 문서는 yarnpkg.com 및 classic.yarnpkg.com 공식 웹사이트의 콘텐츠를 기반으로 합니다.
