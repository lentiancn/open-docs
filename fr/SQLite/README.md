## À propos de SQLite

SQLite est une bibliothèque en langage C qui implémente un moteur de base de données SQL **petit**, **rapide**, **autonome**, **haute fiabilité** et **complet**. C'est le moteur de base de données le plus utilisé au monde, intégré dans tous les téléphones mobiles, la plupart des ordinateurs, et d'innombrables applications.
