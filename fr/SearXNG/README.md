# SearXNG

SearXNG est un moteur de méta-recherche internet gratuit qui protège votre vie privée en agrégant les résultats de 250+ services de recherche sans suivre ni profiler les utilisateurs.

## Ressources Officielles
- **Site web** : https://searxng.org
- **Documentation** : https://docs.searxng.org  
- **Code source** : https://github.com/searxng/searxng
- **Instances publiques** : https://searx.space

## Caractéristiques Principales
- Moteur de méta-recherche centré sur la vie privée
- Aucun suivi ou collecte de données des utilisateurs
- Prise en charge de Tor pour un anonymat amélioré
- Hautement personnalisable et configurable
- Open source et piloté par la communauté
