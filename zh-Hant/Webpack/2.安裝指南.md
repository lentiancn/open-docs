# Webpack 安裝指南

## Webpack v5（現代版本）安裝

### 本機安裝（推薦）

對於大多數專案，建議將 Webpack 作為開發相依進行本機安裝：

```bash
# npm
npm init -y
npm install webpack webpack-cli --save-dev

# yarn
yarn init -y
yarn add webpack webpack-cli --dev

# pnpm
pnpm init
pnpm add webpack webpack-cli -D
```

### 全域安裝（不推薦）

雖然可以全域安裝，但不推薦，因為這可能導致專案間的版本衝突：

```bash
# npm
npm install --global webpack webpack-cli

# yarn
yarn global add webpack webpack-cli
```

### 基本專案設定

建立以下目錄結構：

```
project/
├── package.json
├── dist/
│   └── index.html
└── src/
    └── index.js
```

安裝需要打包的相依：

```bash
# npm
npm install --save lodash

# yarn
yarn add lodash

# pnpm
pnpm add lodash
```

### 執行 Webpack

本機安裝後，可以使用以下命令執行 Webpack：

```bash
# npm
npx webpack

# yarn
yarn webpack

# pnpm
pnpm exec webpack
```

## Webpack v4 安裝

### 本機安裝

```bash
# npm
npm init -y
npm install webpack@4.x webpack-cli@3.x --save-dev

# yarn
yarn init -y
yarn add webpack@4.x webpack-cli@3.x --dev
```

### 執行 Webpack v4

```bash
npx webpack
```

注意：Webpack v4 會顯示警告，提示未設定 'mode' 選項。您可以透過新增 `--mode=production` 或 `--mode=development` 標誌來解決此問題。

## NPM 指令碼設定

在 `package.json` 中新增建置指令碼，以更方便地使用：

```json
{
  "scripts": {
    "build": "webpack"
  }
}
```

然後執行：

```bash
# npm
npm run build

# yarn
yarn build

# pnpm
pnpm run build
```

## 從 v4 遷移到 v5

Webpack 提供了平滑的遷移路徑：

1. 更新相依：`npm install webpack@latest webpack-cli@latest`
2. 查閱官方遷移指南，了解破壞性變更
3. 如果使用 ES Module，更新設定語法
4. 彻底測試以確保相容性

官方遷移指南提供了處理特定破壞性變更和已棄用特性的詳細說明。
