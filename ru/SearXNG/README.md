# SearXNG

SearXNG — это бесплатная интернет-метапоисковая система, которая защищает вашу конфиденциальность, агрегируя результаты из 250+ поисковых сервисов без отслеживания или профилирования пользователей.

## Официальные ресурсы
- **Веб-сайт**: https://searxng.org
- **Документация**: https://docs.searxng.org  
- **Исходный код**: https://github.com/searxng/searxng
- **Публичные инстансы**: https://searx.space

## Основные характеристики
- Метапоисковая система с фокусом на конфиденциальности
- Без отслеживания или сбора данных пользователей
- Поддержка Tor для улучшенной анонимности
- Высоко настраиваемый и конфигурируемый
- Открытый исходный код и управление сообществом
