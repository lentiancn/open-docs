# SQLite 소개

SQLite는 C 언어 라이브러리로 구현된 **작고**, **빠르며**, **자체 완비적**이고, **높은 신뢰성**을 가진 **기능이 풍부한** SQL 데이터베이스 엔진입니다. SQLite는 전 세계에서 가장 많이 사용되는 데이터베이스 엔진으로, 모든 모바일 폰과 대부분의 컴퓨터에 내장되어 있으며 수많은 애플리케이션에 번들로 제공됩니다.

## 주요 특징

### 자체 완비적(Self-contained)
SQLite는 외부 의존성이 없는 단일 라이브러리입니다. 표준 C 라이브러리 이외의 다른 라이브러리나 시스템에 의존하지 않습니다.

### 서버리스(Serverless)
SQLite는 별도의 서버 프로세스가 없습니다. 대부분의 다른 SQL 데이터베이스와 달리, SQLite는 직접 디스크 파일을 읽고 씁니다. 완전한 SQL 데이터베이스(여러 테이블, 인덱스, 트리거, 뷰 포함)가 단일 디스크 파일에 포함됩니다.

### 제로 설정(Zero-configuration)
SQLite는 설치나 관리가 필요 없습니다. 데이터베이스 파일을 생성하거나 열기만 하면 즉시 사용할 수 있습니다.

### 트랜잭션 지원
SQLite는 ACID(원자성, 일관성, 고립성, 지속성) 속성을 지원하는 트랜잭션을 제공합니다. 시스템 충돌이나 전원 장애가 발생하더라도 트랜잭션이 안전하게 유지됩니다.

### 크로스 플랫폼
SQLite 데이터베이스 파일 형식은 크로스 플랫폼입니다. 32비트와 64비트 시스템 간, 또는 빅엔디안과 리틀엔디안 아키텍처 간에 자유롭게 데이터베이스를 복사할 수 있습니다.

### 컴팩트한 라이브러리
모든 기능을 활성화한 상태에서도 라이브러리 크기는 대상 플랫폼과 컴파일러 최적화 설정에 따라 900KiB 미만일 수 있습니다.

### 철저한 테스트
SQLite는 모든 릴리스 전에 매우 철저하게 테스트됩니다. 자동화된 테스트 스위트는 수백만 개의 테스트 케이스를 실행하며 100% 브랜치 테스트 커버리지를 달성합니다.

### 공개 도메인
SQLite 소스 코드는 공개 도메인에 있으며 상업적 또는 개인적 목적을 위해 무료로 사용할 수 있습니다.

## 적절한 사용 사례

SQLite는 Oracle과 같은 클라이언트/서버 데이터베이스 엔진의 대체품이 아니라 `fopen()` 함수의 대체품으로 생각해야 합니다. 다음 상황에서 SQLite가 적합합니다:

- 애플리케이션 파일 포맷으로 사용
- 내장 장치 또는 IoT 애플리케이션
- 웹사이트 백엔드
- 데이터 분석
- 캐싱 계층
- 서버 애플리케이션의 내부 또는 임시 데이터베이스
- 교육용 데이터베이스

## 역사

SQLite 프로젝트는 2000년 5월 9일에 시작되었습니다. 개발자들은 2050년까지 SQLite를 지원할 계획이며, 이러한 목표를 염두에 두고 설계 결정을 내립니다.
