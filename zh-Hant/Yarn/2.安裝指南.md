# Yarn 安裝指南

## Yarn 4+ (現代版本) 安裝

### 推薦安裝方式（使用 Corepack）

Corepack 是一個中介工具，允許您按專案配置套件管理器版本：

```bash
# 全域安裝 Corepack
npm install -g corepack

# 初始化新專案（使用 Yarn Berry）
yarn init -2
```

### 更新 Yarn

任何時候想要更新到最新版本，只需執行：

```bash
yarn set version stable
yarn install
```

Yarn 將配置您的專案使用最新的穩定二進位檔。

### 使用 Canary 版本

Yarn 經常發布 Release Candidate 組建。如果您需要尚未在穩定頻道發布的功能：

```bash
yarn set version canary
```

這些組建非常穩定，與常規頻道的唯一區別是在主要版本之間採用更漸進的遷移方式。

### 從原始碼安裝最新版本

如果您想測試尚未發布甚至未合併的 Yarn 版本：

```bash
# 從主分支複製、建置並安裝
yarn set version from sources

# 測試特定 PR
yarn set version from sources --branch 1211
```

**注意**: `yarn set version from sources` 指令無法利用 Corepack，需要將 Yarn 二進位檔儲存在 `.yarn/releases` 資料夾中，並從專案的 `.yarnrc.yml` 檔案中引用它。

## Yarn Classic (v1) 安裝

### 透過 npm 安裝（推薦）

建議透過 npm 套件管理器安裝 Yarn，npm 隨 Node.js 一起安裝：

```bash
# 安裝或升級 Yarn Classic
npm install --global yarn
```

### 驗證安裝

安裝完成後，透過以下指令檢查 Yarn 是否正確安裝：

```bash
yarn --version
```

## 版本選擇建議

- **新專案**: 推薦使用 Yarn 4+ (現代版本)，享受最新的功能和改進
- **現有專案**: 
  - 如果已經在使用 Yarn Classic，可以繼續使用
  - 考慮遷移到現代版本以獲得更好的效能和功能
- **企業環境**: 現代版本提供更好的工作區支援和穩定性保證

## 系統需求

- **Node.js**: 所有版本都需要 Node.js 環境
- **npm**: Yarn Classic 需要 npm 進行全域安裝
- **Corepack**: 現代版本推薦使用 Corepack 進行版本管理

> **注意**: 本文檔基於官方 yarnpkg.com 和 classic.yarnpkg.com 網站內容整理。
