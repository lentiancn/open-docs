# SearXNG 安装指南

本指南涵盖设置您自己的 SearXNG 实例的多种安装方法。

## 安装方法

### 1. 容器安装（推荐）

最简单和最可靠的方法是使用 Docker 或 Podman 容器。

**先决条件：**
- 已安装 Docker 或 Podman
- 基本的容器管理知识

**步骤：**
```bash
# 拉取官方 SearXNG 镜像
docker pull searxng/searxng

# 使用基本配置运行
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. 安装脚本

提供了一个自动化安装脚本，可以自动处理大部分配置，包括 uWSGI 设置。

**步骤：**
```bash
# 下载安装脚本
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# 赋予执行权限并运行
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. 逐步手动安装

适用于希望完全控制安装过程的高级用户。

**先决条件：**
- Python 3.8 或更高版本
- uWSGI
- Git
- 构建工具（gcc、make 等）
- Web 服务器（NGINX 或 Apache）

**安装步骤：**

1. **安装所需软件包：**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **创建专用用户：**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **克隆仓库：**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **配置设置：**
   ```bash
   # 复制默认设置
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # 根据需要编辑配置
   sudo nano /etc/searxng/settings.yml
   ```

5. **设置 Web 服务器：**
   
   **NGINX 配置示例：**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## 安装后操作

安装完成后，在 `http://your-server:port` 访问您的 SearXNG 实例并验证其是否正常工作。您可以通过 `settings.yml` 配置文件自定义外观、引擎和行为。

## 故障排除

- **权限问题**：确保 searxng 用户对所有文件具有适当的权限
- **端口冲突**：验证所选端口未被占用
- **引擎配置**：某些搜索引擎可能需要 API 密钥或特定配置
- **SSL 设置**：用于生产环境时，使用 Let's Encrypt 或您首选的 CA 配置 SSL 证书
