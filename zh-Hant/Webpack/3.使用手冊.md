# Webpack 使用手冊

## 核心概念

### 入口點

入口點指示 webpack 應使用哪個模組來開始構建其內部依賴關係圖。預設值為 `./src/index.js`，但您可以指定不同的（或多個）入口點。

**單一入口：**
```javascript
// webpack.config.js
export default {
  entry: './path/to/my/entry/file.js',
};
```

**多個入口：**
```javascript
export default {
  entry: {
    app: './src/app.js',
    admin: './src/admin.js'
  }
};
```

### 輸出配置

output 屬性告訴 webpack 將捆綁包發送到哪裡以及如何命名它們。主輸出檔案的預設值為 `./dist/main.js`。

```javascript
import path from "node:path";

export default {
  entry: './path/to/my/entry/file.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'my-first-webpack.bundle.js',
  },
};
```

### Loaders（載入器）

Loaders 允許 webpack 處理非 JavaScript 檔案，並將它們轉換為有效模組。

**基本 Loader 配置：**
```javascript
export default {
  module: {
    rules: [
      { test: /\.txt$/, use: 'raw-loader' },
      { test: /\.css$/, use: ['style-loader', 'css-loader'] },
      { test: /\.(png|svg|jpg|jpeg|gif)$/i, type: 'asset/resource' }
    ],
  },
};
```

### Plugins（外掛程式）

Plugins 執行更廣泛的任務，例如捆綁最佳化、資產管理和環境變數注入。

**常見 Plugins：**
```javascript
import HtmlWebpackPlugin from "html-webpack-plugin";
import MiniCssExtractPlugin from "mini-css-extract-plugin";
import webpack from "webpack";

export default {
  plugins: [
    new HtmlWebpackPlugin({ template: './src/index.html' }),
    new MiniCssExtractPlugin(),
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production')
    })
  ],
};
```

### Mode（模式）

mode 參數啟用內建最佳化：

- **development**：啟用有用的錯誤訊息和快速重構
- **production**：啟用壓縮、範圍提升和其他最佳化
- **none**：禁用所有預設最佳化

```javascript
export default {
  mode: 'production',
};
```

## 高級特性

### 程式碼分割

Webpack 提供多種方式來分割您的程式碼：

**入口點：**
透過建立多個入口點手動分割程式碼。

**防止重複：**
使用 `SplitChunksPlugin` 移除重複的依賴。

**動態匯入：**
使用動態匯入按需分割程式碼：
```javascript
// 之前
import _ from 'lodash';

// 之後
const _ = await import('lodash');
```

### 快取

Webpack 提供了多種快取策略：

- **輸出檔名**：使用 `[contenthash]` 建立唯一檔名
- **SplitChunks**：分離vendor和應用程式碼
- **Runtime Chunk**：將 webpack runtime 提取到單獨的塊中

### 開發工具

**Source Maps：**
啟用 source maps 以實現更便捷的除錯：
```javascript
export default {
  devtool: 'inline-source-map',
};
```

**開發伺服器：**
使用 webpack-dev-server 實現即時重新載入：
```bash
npm install --save-dev webpack-dev-server
```

```javascript
// package.json
{
  "scripts": {
    "start": "webpack serve --open"
  }
}
```

## 配置檔案

### 基本配置

```javascript
// webpack.config.js
import path from "node:path";

export default {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader']
      }
    ]
  },
  plugins: [],
  mode: 'development'
};
```

### 環境特定配置

為不同環境建立單獨的配置：

- `webpack.common.js`：共享配置
- `webpack.dev.js`：開發專用設定
- `webpack.prod.js`：生產專用設定

使用 webpack-merge 結合配置：
```javascript
import { merge } from 'webpack-merge';
import common from './webpack.common.js';

export default merge(common, {
  mode: 'development',
  devtool: 'inline-source-map',
});
```

## 版本差異

### Webpack v5 與 Webpack v4 對比

| 功能 | Webpack v5 | Webpack v4 |
|------|------------|------------|
| **模組系統** | ES 模組 + CommonJS | 僅 CommonJS |
| **快取** | 持久化快取 | 記憶體快取 |
| **資產處理** | 內建資產模組 | 需要 file-loader/url-loader |
| **效能** | 使用持久化快取的更快建構 | 標準效能 |
| **模組聯合** | 內建支援 | 不可用 |
| **Node.js 支援** | Node.js 10.13.0+ | Node.js 6.11.5+ |

### 遷移注意事項

- 更新 loader 配置，使用 asset 模組代替 file-loader/url-loader
- 查閱外掛程式與 Webpack v5 的相容性
- 如果迁移到 ES 模組，更新配置語法
- 進行全面測試，因為某些外掛程式可能存在破壞性變更
