# SearXNG Benutzerhandbuch

Dieses Handbuch behandelt, wie Sie SearXNG effektiv für die Suche und Anpassung nutzen können.

## Suchsyntax

SearXNG unterstützt eine leistungsstarke Suchsyntax, um Ihre Abfragen zu optimieren:

### Suchmaschinen-Auswahl
- **`!` Präfix**: Wählen Sie eine bestimmte Suchmaschine oder Kategorie aus
  - `!wp paris` - Durchsuchen Sie Wikipedia nach "paris"
  - `!images Wau Holland` - Suchen Sie nach Bildern von "Wau Holland"
  - `!news climate change` - Durchsuchen Sie Nachrichten-Suchmaschinen nach "climate change"

### Sprachauswahl
- **`:` Präfix**: Wählen Sie die Suchsprache aus
  - `:fr !wp Wau Holland` - Durchsuchen Sie die französische Wikipedia nach "Wau Holland"
  - `:de climate change` - Suchen Sie auf Deutsch nach "climate change"

### Externe Bangs
- **`!!` Präfix**: Direkte Weiterleitung zu externen Diensten
  - `!!youtube cats` - Leiten Sie direkt zur YouTube-Suche nach "cats" weiter

### Spezielle Abfragen
SearXNG unterstützt verschiedene spezielle Abfragefunktionen:
- `random uuid` - Generieren Sie eine zufällige UUID
- `avg 123 548` - Berechnen Sie den Durchschnitt von Zahlen
- `user-agent` - Zeigen Sie Ihren aktuellen User-Agent an
- Hash-Funktionen: `md5 text`, `sha1 text`, `sha256 text`
- Einheitenumrechnungen: `100 USD in EUR`, `10 km in miles`

## Konfigurierte Suchmaschinen

SearXNG verfügt über **250 Suchmaschinen**, wobei standardmäßig **96 aktiviert** sind. Die Suchmaschinen sind in Kategorien organisiert:

### Kategorien
- **Allgemein**: Standard-Websuchmaschinen
- **Bilder**: Bildersuchdienste
- **Videos**: Videosuchplattformen
- **Nachrichten**: Nachrichtenaggregatoren
- **Karten**: Kartierungs- und Standortdienste
- **Musik**: Musiksuche und Streaming
- **IT**: Technische und Programmierressourcen
- **Wissenschaft**: Akademische und wissenschaftliche Datenbanken
- **Dateien**: Filesharing und Dokumentsuche
- **Soziale Medien**: Soziale Plattformsuche

### Untergruppen
Jede Kategorie enthält Untergruppen für spezifischere Suchen:
- Bücher, Währung, Übersetzung, Web, Wikimedia und mehr

## Oberflächenanpassung

### Einstellungen
Greifen Sie über das Einstellungssymbol auf die Einstellungen zu, um anzupassen:
- **Standard-Suchsprache**
- **Aktivierte Suchmaschinen**
- **Ergebnisanzeigeoptionen**
- **Datenschutzeinstellungen**
- **Design und Erscheinungsbild**

### Plugins
SearXNG enthält nützliche Plugins:
- **Taschenrechner**: Führen Sie mathematische Berechnungen durch
- **Hash**: Generieren Sie verschiedene Hash-Werte
- **Eigene Informationen**: Zeigen Sie Client-Informationen an
- **Zeitzonen**: Konvertieren Sie zwischen Zeitzonen
- **Tor-Prüfung**: Überprüfen Sie die Tor-Konnektivität
- **Einheitenumrechner**: Konvertieren Sie zwischen Maßeinheiten

## Datenschutzfunktionen

### Anonyme Suche
- Alle Suchen sind standardmäßig anonym
- Keine Cookies oder Tracking-Skripte
- IP-Adresse wird nicht protokolliert (in ordnungsgemäß konfigurierten Instanzen)

### Ergebnisbereinigung
- URLs werden von Tracking-Parametern bereinigt
- Referrer-Informationen werden entfernt
- Skripte von Drittanbietern werden blockiert

## Erweiterte Nutzung

### API-Zugriff
SearXNG bietet eine einfache API für programmatischen Zugriff:
```
GET /search?q=your_query&format=json
```

### Benutzerdefinierte Suchmaschinen
Sie können benutzerdefinierte Suchmaschinen hinzufügen, indem Sie die Datei `settings.yml` bearbeiten:
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### Tastaturkürzel
- **`/`**: Fokus auf Sucheingabe
- **`Esc`**: Suche löschen oder Dialoge schließen
- **`Enter`**: Suche absenden
- **`Ctrl+Enter`**: Ergebnisse in neuem Tab öffnen
