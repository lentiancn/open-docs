# Guía de Instalación de Yarn

## Instalación de Yarn v4+ (Versión Moderna)

### Método Recomendado: Usando Corepack

Corepack es una herramienta intermedia que le permitirá configurar la versión del gestor de paquetes por proyecto.

```bash
# 1. Instalar Corepack
npm install -g corepack

# 2. Inicializar un nuevo proyecto
yarn init -2
```

### Actualizar Yarn

Cada vez que desee actualizar Yarn a la versión más reciente, simplemente ejecute:

```bash
yarn set version stable
yarn install
```

Yarn configurará luego su proyecto para usar el binario estable más reciente.

### Usarversiones Canary

Yarn también envía frecuentemente versiones Release Candidate. Use el siguiente comando si necesita una característica que aún no está disponible en el canal estable:

```bash
yarn set version canary
```

Estas versiones son muy estables, la única diferencia con el canal regular es una migración más escalonada entre versiones mayores a medida que implementamos nuevos cambios rupturantes.

### Instalar la Versión más Reciente desde Master

Puede que desee probar una versión de Yarn tan reciente que aún no haya sido lanzada como Release Candidate, o incluso no haya sido fusionada. El siguiente comando clonará, construirá e instalará Yarn en su proyecto directamente desde nuestro repositorio:

```bash
yarn set version from sources
```

Acepta una bandera `--branch` que puede usar para probar PRs específicos:

```bash
yarn set version from sources --branch 1211
```

Advertencia: A diferencia de los canales stable y canary, el comando `yarn set version from sources` no puede aprovechar Corepack y necesitará almacenar el binario de Yarn dentro de la carpeta `.yarn/releases` y hacer referencia a él desde el archivo `.yarnrc.yml` de su proyecto.

## Instalación de Yarn v1 (Clásica)

### A través de npm (Recomendado)

Se recomienda instalar Yarn a través del gestor de paquetes [npm](http://npmjs.org/), que viene incluido con [Node.js](https://nodejs.org/) cuando lo instala en su sistema.

Una vez que tenga npm instalado, puede ejecutar lo siguiente tanto para instalar como para actualizar Yarn:

```bash
npm install --global yarn
```

### Verificar la Instalación

Verifique que Yarn esté instalado ejecutando:

```bash
yarn --version
```

## Recomendaciones de Selección de Versión

- **Nuevos Proyectos**: Se recomienda usar Yarn v4+ para disfrutar de características modernas y mejor rendimiento
- **Proyectos Existentes**: Si ya usa Yarn v1, puede continuar usándolo o considerar migrar a la versión moderna
- **Entornos Empresariales**: Yarn v1 proporciona un soporte a largo plazo más estable, mientras que v4+ ofrece características más innovadoras
