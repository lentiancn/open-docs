# Yarn パッケージマネージャー

Yarn は、速度、正確性、セキュリティ、開発者体験に焦点を当てたオープンソースのパッケージマネージャーで、JavaScript プロジェクトの依存関係を管理するために使用されます。

## バージョン概要

### Yarn 4+ (モダンバージョン)
- **公式ドキュメント**: https://yarnpkg.com/
- **ステータス**: アクティブに開発・メンテナンス中
- **特徴**: 
  - ワークスペースサポート（ワークスペースを中心に構築された初のパッケージマネージャー）
  - 安定性保証（今日動作するインストールは将来も同じように動作し続ける）
  - プラグインシステム（さまざまな問題を解決するためのツールを提供）
  - イノベーション（現状に挑戦し、ワークフローを改善）
  - 完全に独立したオープンソースプロジェクト

### Yarn v3
- **公式ドキュメント**: https://v3.yarnpkg.com/
- **ステータス**: メンテナンス中
- **特徴**: Yarn Berry のさらなる進化、大規模モノレポやエンタープライズユーザー向け

### Yarn Classic (v1)
- **公式ドキュメント**: https://classic.yarnpkg.com/
- **ステータス**: メンテナンス中（ただし主要推奨バージョンではない）
- **特徴**: 従来の Yarn パッケージマネージャー、npm メタデータ形式と互換性あり

## コア機能

- **速度**: 並列インストール、オフラインキャッシング
- **正確性**: 決定論的インストール、ロックファイル
- **セキュリティ**: 強化モード、脆弱性監査
- **開発者体験**: インタラクティブコマンド、完全な CLI 再実装

## 他のパッケージマネージャーとの違い

他のほとんどのパッケージマネージャーとは異なり、Yarn は非インストール関連のコマンドを npm に依存せず、すべてのコマンドを再実装しています。これにより、Yarn は開発者体験と安定性を完全に制御できます。

## 使用ケース

- シンプルな個人プロジェクト
- 大規模エンタープライズモノレポ
- オープンソースプロジェクト開発
- 安定した依存関係管理が必要な本番環境

> **注記**: このドキュメントは yarnpkg.com 公式サイトの内容に基づいており、Yarn 4+、v3、Classic バージョンの公式情報をカバーしています。
