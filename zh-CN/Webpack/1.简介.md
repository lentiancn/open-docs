# Webpack 模块打包器

Webpack 是一种用于现代 JavaScript 应用程序的静态模块打包工具。在核心层面，Webpack 会处理您的应用程序，从一个或多个入口点开始，内部构建依赖关系图，然后将项目所需的所有模块组合成一个或多个打包文件，这些是用于服务您内容的静态资源。

从 4.0.0 版本开始，Webpack 不再需要配置文件即可打包您的项目，但它具有极高的可配置性，可以更好地满足您的需求。

## 主要版本对比

### Webpack v5（现代版本）
- **架构**: 现代 ES Module 支持、持久化缓存、模块联合
- **特性**: 内置代码分割、Tree Shaking、资源模块、性能提升
- **配置**: 支持 CommonJS 和 ES Module 语法
- **状态**: 持续开发中

### Webpack v4（旧版本）
- **架构**: 传统的基于 CommonJS 的配置
- **特性**: 基础打包、代码分割、Tree Shaking
- **配置**: 仅 CommonJS 语法
- **状态**: 维护中（长期支持）

> 注意：Webpack 的核心概念在各版本之间保持一致，但 v5 引入了显著的性能改进和新特性，例如用于微前端架构的模块联合（Module Federation）。

## 核心概念

Webpack 的功能围绕以下几个核心概念构建：

- **入口（Entry）**: 指示 Webpack 应该使用哪个模块来开始构建内部依赖关系图
- **输出（Output）**: 告诉 Webpack 将打包文件输出到何处以及如何命名
- **加载器（Loaders）**: 允许 Webpack 处理非 JavaScript 文件，并将其转换为有效模块
- **插件（Plugins）**: 执行更广泛的任务，如打包文件优化、资源管理和环境变量注入
- **模式（Mode）**: 为开发或生产环境启用内置优化

Webpack 支持所有符合 ES5 规范的浏览器（不支持 IE8 及以下版本）。Webpack 5 要求 Node.js 版本为 10.13.0 或更高。
