# Oracle Database 简介

Oracle Database 是甲骨文公司（Oracle Corporation）开发的关系型数据库管理系统（RDBMS），是全球最知名的企业级数据库解决方案之一。

## 主要版本

### Oracle Database 26ai
Oracle Database 26ai（全称：Oracle AI Database 26ai）是 Oracle Database 的最新版本，于 2026 年发布。该版本集成了先进的人工智能功能，提供增强的自动化管理和性能优化能力。

**注意**：Oracle Database 26ai 为最新发布版本，详细技术文档请参考 Oracle 官方网站。

### Oracle Database 19c
Oracle Database 19c 是 Oracle Database 的长期支持版本，提供稳定可靠的企业级数据库功能。该版本支持多种操作系统平台，包括 Windows x64、Linux x86-64、Linux ARM、Solaris、AIX、HP-UX 和 Linux on System z。

## 核心特性

- **高可用性**：提供 Real Application Clusters (RAC)、Data Guard 等高可用性解决方案
- **安全性**：内置高级安全功能，包括透明数据加密、审计和访问控制
- **可扩展性**：支持从单机部署到大规模分布式集群的各种部署模式
- **性能优化**：自动 SQL 调优、内存管理和存储优化
- **多模型支持**：支持关系型、JSON、XML、图形等多种数据模型
- **云原生**：支持容器化部署和云环境集成
