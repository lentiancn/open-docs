# Manual del Usuario de Oracle Database

## Conexión a la Base de Datos

### Conexión con SQL*Plus
```sql
-- Conexión local
sqlplus username/password@localhost:1521/SID

-- Conexión remota
sqlplus username/password@hostname:1521/service_name

-- Conexión como administrador del sistema
sqlplus / as sysdba
```

### Cadena de Conexión JDBC

## Operaciones Básicas de SQL

### Lenguaje de Definición de Datos (DDL)
```sql
-- Crear tabla
CREATE TABLE employees (
    employee_id NUMBER PRIMARY KEY,
    first_name VARCHAR2(50),
    last_name VARCHAR2(50) NOT NULL,
    email VARCHAR2(100) UNIQUE,
    hire_date DATE DEFAULT SYSDATE,
    salary NUMBER(8,2)
);

-- Modificar estructura de tabla
ALTER TABLE employees ADD department_id NUMBER;
ALTER TABLE employees MODIFY salary NUMBER(10,2);
ALTER TABLE employees DROP COLUMN department_id;

-- Eliminar tabla
DROP TABLE employees;
```

### Lenguaje de Manipulación de Datos (DML)
```sql
-- Insertar datos
INSERT INTO employees (employee_id, first_name, last_name, email, salary)
VALUES (101, 'John', 'Doe', 'john.doe@example.com', 5000.00);

-- Consultar datos
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > 4000
ORDER BY last_name;

-- Actualizar datos
UPDATE employees
SET salary = salary * 1.1
WHERE department_id = 10;

-- Eliminar datos
DELETE FROM employees
WHERE employee_id = 101;
```

## Programación PL/SQL

### Procedimientos Almacenados
```sql
CREATE OR REPLACE PROCEDURE update_employee_salary(
    p_employee_id IN NUMBER,
    p_new_salary IN NUMBER
)
IS
BEGIN
    UPDATE employees
    SET salary = p_new_salary
    WHERE employee_id = p_employee_id;
    
    IF SQL%ROWCOUNT = 0 THEN
        RAISE_APPLICATION_ERROR(-20001, 'Employee not found');
    END IF;
    
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END;
/
```

### Funciones
```sql
CREATE OR REPLACE FUNCTION get_employee_name(
    p_employee_id IN NUMBER
) RETURN VARCHAR2
IS
    v_full_name VARCHAR2(101);
BEGIN
    SELECT first_name || ' ' || last_name
    INTO v_full_name
    FROM employees
    WHERE employee_id = p_employee_id;
    
    RETURN v_full_name;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RETURN NULL;
END;
/
```

### Disparadores (Triggers)
```sql
CREATE OR REPLACE TRIGGER employees_audit_trigger
    BEFORE INSERT OR UPDATE OR DELETE ON employees
    FOR EACH ROW
DECLARE
    v_action VARCHAR2(10);
BEGIN
    IF INSERTING THEN
        v_action := 'INSERT';
    ELSIF UPDATING THEN
        v_action := 'UPDATE';
    ELSE
        v_action := 'DELETE';
    END IF;
    
    INSERT INTO employees_audit (
        employee_id, action, action_date, user_name
    ) VALUES (
        NVL(:OLD.employee_id, :NEW.employee_id),
        v_action,
        SYSDATE,
        USER
    );
END;
/
```

## Optimización de Rendimiento

### Gestión de Índices
```sql
-- Crear índice B-tree
CREATE INDEX idx_employees_last_name ON employees(last_name);

-- Crear índice bitmap (apropiado para columnas de baja cardinalidad)
CREATE BITMAP INDEX idx_employees_department ON employees(department_id);

-- Crear índice basado en funciones
CREATE INDEX idx_employees_upper_name ON employees(UPPER(last_name));
```

### Análisis del Plan de Ejecución
```sql
-- Ver plan de ejecución
```


## Copia de Seguridad y Recuperación

### Copia de Seguridad con RMAN
```bash
# Conectarse a RMAN
rman target /

# Copia de seguridad completa de la base de datos
BACKUP DATABASE;

# Copia de seguridad incremental
BACKUP INCREMENTAL LEVEL 1 DATABASE;

# Copia de seguridad de logs de archivo
BACKUP ARCHIVELOG ALL;
```

### Exportación/Importación con Data Pump
```bash
# Exportar toda la base de datos
expdp system/password FULL=Y DIRECTORY=DATA_PUMP_DIR DUMPFILE=full_db.dmp

# Exportar esquema específico
expdp hr/hr SCHEMAS=HR DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp

# Importar datos
impdp system/password DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp
```

```sql
SELECT sid, serial#, username, status, machine, program
FROM v$session
WHERE username IS NOT NULL;

-- Ver información de bloqueos
SELECT session_id, lock_type, mode_held, mode_requested
FROM dba_locks;

-- Ver uso de tablespace
SELECT tablespace_name, 
       ROUND(SUM(bytes)/1024/1024, 2) AS size_mb,
       ROUND(SUM(maxbytes)/1024/1024, 2) AS max_size_mb
FROM dba_data_files
GROUP BY tablespace_name;
```

## Nuevas Características de Oracle Database 26ai

Oracle Database 26ai introduce funciones de automatización impulsadas por IA:
- **Ajuste Automático de SQL**: La IA analiza patrones de consultas y optimiza automáticamente
- **Mantenimiento Predictivo**: Predice problemas potenciales y proporciona alertas tempranas
- **Gestión Inteligente de Recursos**: Ajusta dinámicamente la asignación de memoria y CPU
- **Monitoreo de Seguridad Mejorado**: Detección de anomalías impulsada por IA

La documentación detallada de nuevas características debe consultarse en el sitio web oficial de Oracle.

## Mejores Prácticas

### Configuración de Seguridad
- Usar políticas de contraseñas fuertes
- Habilitar Cifrado Transparente de Datos (TDE)
- Configurar control de acceso granular
- Auditar actividades de la base de datos regularmente

### Optimización de Rendimiento
- Diseñar estructuras de tablas e índices apropiadamente
- Usar variables de enlace para evitar análisis duro
- Recoger estadísticas regularmente
- Monitorear y optimizar consultas lentas

### Alta Disponibilidad
- Implementar estrategias de copia de seguridad apropiadas
- Configurar Data Guard o RAC
- Probar procedimientos de recuperación regularmente
- Monitorear el estado de salud del sistema
