# Gestor de Paquetes Yarn

Yarn es un gestor de paquetes de código abierto centrado en la velocidad, corrección, seguridad y experiencia del desarrollador, utilizado para gestionar dependencias en proyectos JavaScript.

## Resumen de Versiones

### Yarn 4+ (Versión Moderna)
- **Documentación Oficial**: https://yarnpkg.com/
- **Estado**: Desarrollo y mantenimiento activos
- **Características**: 
  - Soporte para workspaces (primer gestor de paquetes construido específicamente alrededor de workspaces)
  - Garantía de estabilidad (las instalaciones que funcionan hoy seguirán funcionando de la misma manera en el futuro)
  - Sistema de plugins (proporciona herramientas para resolver diversos problemas)
  - Innovación (desafía el status quo, mejora los flujos de trabajo)
  - Proyecto de código abierto completamente independiente

### Yarn v3
- **Documentación Oficial**: https://v3.yarnpkg.com/
- **Estado**: En mantenimiento
- **Características**: Evolución adicional de Yarn Berry, adecuado para monorepos grandes y usuarios empresariales

### Yarn Classic (v1)
- **Documentación Oficial**: https://classic.yarnpkg.com/
- **Estado**: En mantenimiento (pero ya no es la versión principal recomendada)
- **Características**: Gestor de paquetes Yarn tradicional, compatible con el formato de metadatos de npm

## Funciones Principales

- **Velocidad**: Instalaciones paralelas, caché offline
- **Corrección**: Instalaciones deterministas, archivos de bloqueo
- **Seguridad**: Modo reforzado, auditoría de vulnerabilidades
- **Experiencia del Desarrollador**: Comandos interactivos, reimplementación completa de CLI

## Diferencias con Otros Gestores de Paquetes

A diferencia de la mayoría de otros gestores de paquetes, Yarn reimplementa todos los comandos en lugar de depender de npm para comandos no relacionados con la instalación. Esto permite a Yarn tener control total sobre la experiencia del desarrollador y la estabilidad.

## Casos de Uso

- Proyectos personales simples
- Monorepos empresariales grandes
- Desarrollo de proyectos de código abierto
- Entornos de producción que requieren gestión estable de dependencias

> **Nota**: Este documento se basa en el contenido oficial del sitio web yarnpkg.com, cubriendo información oficial para las versiones Yarn 4+, v3 y Classic.
