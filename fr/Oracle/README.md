# Oracle Database

Oracle Database est un système de gestion de bases de données relationnelles d'entreprise développé par Oracle Corporation.

## Versions de Documentation

- **Oracle Database 26ai** - Version la plus récente (publiée en 2026)
- **Oracle Database 19c** - Version à support à long terme

## Structure de la Documentation

1. **Introduction** - Aperçu général et fonctionnalités principales d'Oracle Database
2. **Guide d'installation** - Étapes détaillées d'installation et configuration système requise
3. **Manuel d'utilisation** - Opérations complètes de programmation SQL, PL/SQL et administration
4. **FAQ** - Questions fréquentes et dépannage

## Ressources Officielles

- Documentation Officielle : https://docs.oracle.com/
- Téléchargements de Logiciels : https://www.oracle.com/downloads/
