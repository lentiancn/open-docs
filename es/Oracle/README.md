# Oracle Database

Oracle Database es un sistema de gestión de bases de datos relacionales empresarial desarrollado por Oracle Corporation.

## Versiones de Documentación

- **Oracle Database 26ai** - Versión más reciente (lanzada en 2026)
- **Oracle Database 19c** - Versión de soporte a largo plazo

## Estructura de la Documentación

1. **Introducción** - Descripción general y características principales de Oracle Database
2. **Guía de Instalación** - Pasos detallados de instalación y requisitos del sistema
3. **Manual del Usuario** - Operaciones completas de programación SQL, PL/SQL y administración
4. **Preguntas Frecuentes** - Preguntas frecuentes y solución de problemas
