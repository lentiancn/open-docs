# Häufig gestellte Fragen zu Oracle Database

## Installationsbezogene Fragen

### F1: Was tun, wenn während der Installation Berechtigungsfehler auftreten?
**A**: Stellen Sie sicher, dass die Installation mit dem Oracle-Benutzer ausgeführt wird und dieser Benutzer den Gruppen oinstall und dba angehört. Überprüfen Sie die Benutzer- und Gruppenkonfiguration in den Dateien `/etc/passwd` und `/etc/group`.

### F2: Wie löst man Fehler aufgrund unzureichenden Speichers während der Installation?
**A**: Oracle Database benötigt ausreichend Speicher. Lösungen umfassen:
- Erhöhung des physischen Systemspeichers
- Anpassung der Kernel-Parameter: `kernel.shmmax` und `kernel.shmall`
- Auswahl kleinerer Konfigurationsoptionen während der Installation (z.B. Desktop-Klassen-Installation)

### F3: Wie führt man Oracle Database in Docker aus?
**A**: Oracle stellt offizielle Docker-Images bereit:
```bash
# Oracle Database Free (19c)
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0

# Hinweis: Der erste Start kann beträchtliche Zeit für die Initialisierung benötigen
```

## Verbindungsprobleme

### F4: Wie löst man den Fehler ORA-12541: TNS:no listener?
**A**: Dieser Fehler zeigt an, dass der Listener nicht ausgeführt wird. Lösungen:
```bash
# Listener starten
lsnrctl start

# Listener-Status überprüfen
lsnrctl status

# Sicherstellen, dass die Listener-Konfiguration korrekt ist (listener.ora-Datei)
```

### F5: ORA-12170: TNS:Connect timeout occurred Fehler?
**A**: Netzwerkverbindungs-Timeout. Überprüfen Sie:
- Datenbankserver-Erreichbarkeit (Ping-Test)
- Firewall blockiert Port 1521
- Listener lauscht auf der richtigen IP-Adresse
- Korrektheit der tnsnames.ora-Konfiguration

### F6: Wie setzt man sys/system-Passwörter zurück?
**A**: Verwenden Sie das orapwd-Tool, um die Passwortdatei zurückzusetzen:
```bash
# Datenbank stoppen
sqlplus / as sysdba
SHUTDOWN IMMEDIATE;

# Passwortdatei neu erstellen
orapwd file=$ORACLE_HOME/dbs/orapw$ORACLE_SID password=new_password force=y

# Datenbank starten
STARTUP;
```

## Leistungsprobleme

### F7: Wie optimiert man langsame Abfragen?
**A**: Schritte zur Leistungsoptimierung:
1. **Ausführungsplan analysieren**: Verwenden Sie `EXPLAIN PLAN`, um den Abfrageausführungspfad anzuzeigen
2. **Indizes überprüfen**: Stellen Sie sicher, dass Spalten in der WHERE-Klausel geeignete Indizes haben
3. **Statistiken sammeln**: `EXEC DBMS_STATS.GATHER_TABLE_STATS`
4. **SQL-Tuning-Berater**: Verwenden Sie Oracle SQL Tuning Advisor
5. **Warteereignisse überprüfen**: Abfrage der `v$session_wait`-Ansicht

### F8: Wie zeigt man aktuell ausgeführte langsame Abfragen an?
**A**: Abfrage der v$session- und v$sql-Ansichten:
```sql
SELECT s.sid, s.serial#, s.username, s.status, 
       q.sql_text, q.elapsed_time, q.cpu_time
FROM v$session s, v$sql q
WHERE s.sql_id = q.sql_id
  AND s.status = 'ACTIVE'
  AND q.elapsed_time > 1000000; -- Ausführungszeit über 1 Sekunde
```

### F9: Was tun, wenn die Speichernutzung zu hoch ist?
**A**: Speicherparameter anpassen:
- **SGA_TARGET**: Gesamtgröße des System Global Area
- **PGA_AGGREGATE_TARGET**: Gesamtgröße des Program Global Area
- **MEMORY_TARGET**: Automatische Speicherverwaltung (11g und höher)

```sql
-- Aktuelle Speichernutzung anzeigen
SHOW PARAMETER memory;
SHOW PARAMETER sga;
SHOW PARAMETER pga;

-- Dynamische Anpassung (erfordert sysdba-Berechtigungen)
ALTER SYSTEM SET MEMORY_TARGET = 4G SCOPE=BOTH;
```

## Sicherungs- und Wiederherstellungsprobleme

### F10: Wie geht man mit RMAN-Sicherungsfehlern um?
**A**: Häufige RMAN-Fehlerbehebung:
- **Unzureichender Speicherplatz**: Überprüfen Sie den freien Speicherplatz im Sicherungszielverzeichnis
- **Berechtigungsprobleme**: Stellen Sie sicher, dass der Oracle-Benutzer Schreibberechtigungen für das Sicherungsverzeichnis hat
- **Fehlende Archivprotokolle**: Stellen Sie sicher, dass alle Archivprotokolle verfügbar sind
- **Kanal-Konfiguration**: Überprüfen Sie, ob die RMAN-Kanal-Konfiguration korrekt ist

### F11: Wie stellt man eine versehentlich gelöschte Tabelle wieder her?
**A**: Wiederherstellungsmethoden hängen von der Sicherungsstrategie ab:
1. **Flashback-Tabelle** (falls aktiviert):
   ```sql
   FLASHBACK TABLE table_name TO BEFORE DROP;
   ```
2. **RMAN Point-in-Time-Wiederherstellung**:
   ```rman
   RUN {
       SET UNTIL TIME "TO_DATE('2026-03-30 08:00:00', 'YYYY-MM-DD HH24:MI:SS')";
       RESTORE DATABASE;
       RECOVER DATABASE;
   }
   ```
3. **Data Pump Import**: Wiederherstellung aus der letzten Exportdatei

## Versionsunterschiede

### F12: Was sind die Hauptunterschiede zwischen Oracle Database 19c und 26ai?
**A**: Hauptunterschiede umfassen:
- **KI-Funktionen**: 26ai integriert KI-gesteuerte automatisierte Verwaltungsfunktionen
- **Leistungsoptimierung**: 26ai bietet intelligentere Ressourcenverwaltung und Abfrageoptimierung
- **Sicherheit**: 26ai verbessert Sicherheitsüberwachungs- und Bedrohungserkennungsfunktionen
- **Cloud-native Unterstützung**: 26ai bietet bessere Unterstützung für Containerisierung und Cloud-Umgebungen

### F13: Was ist bei einem Upgrade von 19c auf 26ai zu beachten?
**A**: Upgrade-Überlegungen:
- **Kompatibilitätsprüfung**: Verwenden Sie Database Upgrade Assistant (DBUA) für Vorabprüfungen
- **Sicherung**: Vollständige Datenbanksicherung muss vor dem Upgrade durchgeführt werden
- **Testumgebung**: Validieren Sie den Upgrade-Prozess zuerst in einer Testumgebung
- **Anwendungskompatibilität**: Stellen Sie sicher, dass Anwendungen mit der neuen Version kompatibel sind
- **Lizenzierung**: Bestätigen Sie die Lizenzanforderungen für die neue Version

## Tägliche Wartung

### F14: Wie bereinigt man Archivprotokolle?
**A**: Methoden zur Archivprotokoll-Bereinigung:
```bash
# Verwenden Sie RMAN, um gesicherte Archivprotokolle zu löschen
rman target /
DELETE ARCHIVELOG ALL COMPLETED BEFORE 'SYSDATE-7';

# Manuelles Löschen (nicht empfohlen, es sei denn, Sie sind sicher, dass sie gesichert sind)
rm $ORACLE_BASE/fast_recovery_area/*/archivelog/*.arc
```

### F15: Was tun, wenn der Tablespace voll ist?
**A**: Methoden zur Tablespace-Erweiterung:
```sql
-- Datendatei hinzufügen
ALTER TABLESPACE users ADD DATAFILE '/u01/app/oracle/oradata/ORCL/users02.dbf' SIZE 1G;

-- Größe vorhandener Datendatei ändern
ALTER DATABASE DATAFILE '/u01/app/oracle/oradata/ORCL/users01.dbf' RESIZE 2G;

-- Autoextend aktivieren
ALTER DATABASE DATAFILE '/u01/app/oracle/oradata/ORCL/users01.dbf' AUTOEXTEND ON NEXT 100M MAXSIZE UNLIMITED;
```

### F16: Wie überwacht man den Datenbank-Gesundheitsstatus?
**A**: Methoden zur Gesundheitsüberwachung:
- **AWR-Berichte**: Regelmäßige Generierung und Analyse von AWR-Berichten
- **ADDM-Berichte**: Automatischer Datenbank-Diagnose-Monitor
- **OEM**: Oracle Enterprise Manager
- **Benutzerdefinierte Skripte**: Überwachung wichtiger Metriken (Sitzungsanzahl, Sperren, Tablespace-Nutzung usw.)

## Fehlerbehebung

### F17: Was tun, wenn die Datenbank nicht gestartet werden kann?
**A**: Schritte zur Start-Fehlerbehebung:
1. **Alert-Log überprüfen**: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
2. **Kontrolldateien überprüfen**: Stellen Sie sicher, dass Kontrolldateien existieren und zugänglich sind
3. **Datendateien überprüfen**: Stellen Sie sicher, dass alle Datendateien existieren
4. **Parameterdatei überprüfen**: Überprüfen Sie, ob die spfile- oder pfile-Konfiguration korrekt ist
5. **Mount-Modus versuchen**: `STARTUP MOUNT` und dann schrittweise Fehlerbehebung durchführen

### F18: Wie geht man mit Deadlocks um?
**A**: Methoden zum Umgang mit Deadlocks:
- **Automatische Behandlung**: Oracle erkennt automatisch und beendet eine der Transaktionen
- **Manuelle Intervention**: Abfrage von `v$lock` und `v$session`, um blockierende Sitzungen zu finden und zu beenden
  ```sql
  ALTER SYSTEM KILL SESSION 'sid,serial#' IMMEDIATE;
  ```
- **Präventive Maßnahmen**: Sicherstellen einer konsistenten Zugriffsreihenfolge auf Anwendungsebene

## Lizenzierung und Kosten

### F19: Welche Einschränkungen hat die kostenlose Version von Oracle Database?
**A**: Einschränkungen von Oracle Database Free (19c/26ai):
- **CPU-Begrenzung**: Maximal 2 CPUs
- **Speicherbegrenzung**: Maximal 2GB RAM
- **Speicherbegrenzung**: Maximal 12GB Benutzerdaten
- **Funktionsbegrenzung**: Enthält keine erweiterten Enterprise-Edition-Funktionen (wie RAC, Data Guard usw.)

### F20: Wie reduziert man Oracle-Lizenzkosten?
**A**: Strategien zur Kostenoptimierung:
- **Kostenlose Versionen verwenden**: Für Entwicklungs- und kleine Produktionsumgebungen
- **CPU-Lizenzierung angemessen planen**: Kauf basierend auf tatsächlichem Verbrauch
- **Cloud-Services in Betracht ziehen**: OCI, AWS RDS usw. nutzungsbasierte Modelle
- **Regelmäßige Audits**: Sicherstellen der Lizenzkonformität und Vermeidung von Übernutzung
