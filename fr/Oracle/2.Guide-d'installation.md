# Guide d'Installation d'Oracle Database

## Installation d'Oracle Database 19c

### Configuration Système Requise

#### Systèmes d'Exploitation Pris en Charge
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### Configuration Matérielle Requise
- **Mémoire** : Minimum 2 Go de RAM (4 Go ou plus recommandé)
- **Espace Disque** : Minimum 6,5 Go d'espace disponible (Édition Enterprise)
- **Processeur** : Architecture de processeur prise en charge par le système d'exploitation

### Étapes d'Installation

#### 1. Télécharger le Logiciel
Obtenez les packages d'installation d'Oracle Database 19c depuis Oracle Software Delivery Cloud :
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. Préparer l'Environnement Système
```bash
# Exemple pour les systèmes Linux
# Créer l'utilisateur et les groupes oracle
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# Définir les paramètres du noyau
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# Définir les limites utilisateur
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. Exécuter l'Installateur
```bash
# Extraire le package d'installation et exécuter l'installateur
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. Assistant d'Installation Graphique
- Sélectionner le type d'installation (classe bureau, classe serveur)
- Configurer l'identification de la base de données (nom global de la base de données, SID)
- Définir les mots de passe d'administration
- Exécuter les scripts root
- Finaliser l'installation

### Installation de la Version Gratuite
Oracle Database Free (19c) fournit une version gratuite qui peut être déployée rapidement via Docker :
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Installation d'Oracle Database 26ai

Oracle Database 26ai est la version la plus récente. Le guide d'installation doit être consulté dans la documentation officielle d'Oracle :
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### Déploiement Conteneurisé
Oracle Database 26ai prend en charge les méthodes modernes de déploiement conteneurisé :
```bash
# Exemple de déploiement Docker (le nom d'image spécifique doit être consulté dans la documentation officielle)
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## Déploiement sur Services Cloud

### Oracle Cloud Infrastructure (OCI)
- Sélectionner le service Database dans la console OCI
- Choisir la version d'Oracle Database (19c ou 26ai)
- Configurer l'instance de calcul et le stockage
- Finalisation automatique de l'installation et de la configuration

### Autres Fournisseurs Cloud
- AWS RDS for Oracle
- Azure Database for Oracle
- Solutions Oracle de Google Cloud

## Dépannage

### Problèmes Courants
- **Problèmes de Permissions** : Assurez-vous que l'utilisateur oracle dispose des permissions correctes sur les fichiers et répertoires
- **Conflits de Port** : Port d'écoute par défaut 1521, assurez-vous que le port n'est pas occupé
- **Mémoire Insuffisante** : Ajustez les paramètres de mémoire SGA et PGA
- **Problèmes de Jeu de Caractères** : Sélectionnez correctement le jeu de caractères de la base de données pendant l'installation

### Emplacements des Journaux
- Journaux d'installation : `$ORACLE_BASE/cfgtoollogs/dbca/`
- Journaux d'alerte de la base de données : `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
