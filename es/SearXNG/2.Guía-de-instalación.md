# SearXNG Guía de instalación

Esta guía cubre varios métodos de instalación para configurar su propia instancia de SearXNG.

## Métodos de Instalación

### 1. Instalación por Contenedor (Recomendado)

El método más fácil y confiable es usar contenedores Docker o Podman.

**Requisitos previos:**
- Docker o Podman instalado
- Conocimientos básicos de gestión de contenedores

**Pasos:**
```bash
# Extraer la imagen oficial de SearXNG
docker pull searxng/searxng

# Ejecutar con configuración básica
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. Script de Instalación

Está disponible un script de instalación automatizado que maneja la mayoría de la configuración automáticamente, incluyendo la configuración de uWSGI.

**Pasos:**
```bash
# Descargar el script de instalación
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# Dar permisos de ejecución y ejecutar
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. Instalación Manual Paso a Paso

Para usuarios avanzados que desean control total sobre el proceso de instalación.

**Requisitos previos:**
- Python 3.8 o superior
- uWSGI
- Git
- Herramientas de compilación (gcc, make, etc.)
- Servidor web (NGINX o Apache)

**Pasos de Instalación:**

1. **Instalar Paquetes Requeridos:**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **Crear Usuario Dedicado:**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **Clonar Repositorio:**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **Configurar Ajustes:**
   ```bash
   # Copiar ajustes predeterminados
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # Editar configuración según sea necesario
   sudo nano /etc/searxng/settings.yml
   ```

5. **Configurar Servidor Web:**
   
   **Ejemplo de Configuración de NGINX:**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## Después de la Instalación

Después de la instalación, acceda a su instancia de SearXNG en `http://your-server:port` y verifique que funcione correctamente. Puede personalizar la apariencia, motores y comportamiento a través del archivo de configuración `settings.yml`.

## Solución de Problemas

- **Problemas de Permisos**: Asegúrese de que el usuario searxng tenga los permisos adecuados en todos los archivos
- **Conflictos de Puerto**: Verifique que el puerto elegido no esté ya en uso
- **Configuración de Motores**: Algunos motores de búsqueda pueden requerir claves API o configuración específica
- **Configuración SSL**: Para uso en producción, configure certificados SSL usando Let's Encrypt o su CA preferida
