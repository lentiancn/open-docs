# SearXNG 자주 묻는 질문 (FAQ)

## 일반 질문

### SearXNG란 무엇인가요?
SearXNG는 최대 250개의 다양한 검색 서비스에서 결과를 집계하는 무료 인터넷 메타검색 엔진입니다. 사용자를 추적하거나 프로파일링하지 않아 검색 중 완전한 익명성을 보장하도록 설계되었습니다.

### 왜 일반 검색 엔진 대신 SearXNG를 사용해야 하나요?
- **개인정보 보호**: 사용자 추적, 프로파일링 또는 데이터 수집 없음
- **필터 버블 없음**: 결과가 기록에 따라 개인화되지 않음
- **다중 소스**: 많은 검색 엔진의 결과 집계
- **오픈 소스**: 누구나 감사할 수 있는 투명한 코드
- **맞춤 설정 가능**: 개인 취향에 따라 고도로 구성 가능
- **무료 사용**: 비용 및 광고 없음

### SearXNG는 어떻게 작동하나요?
SearXNG는 쿼리를 여러 검색 서비스에 동시에 보내고, 결과를 집계하여 통합된 인터페이스로 표시하는 메타검색 엔진으로 작동합니다. 요청에서 식별 정보를 제거하고 결과를 정화하여 개인정보를 보호합니다.

## 사용 관련 질문

### SearXNG를 기본 검색 엔진으로 설정하려면 어떻게 해야 하나요?
SearXNG는 OpenSearch를 지원하므로 브라우저의 검색 제공업체에 쉽게 추가할 수 있습니다:
1. 임의의 SearXNG 인스턴스 방문
2. "브라우저에 추가" 또는 설정 옵션 찾기
3. 브라우저 지침에 따라 검색 제공업체로 추가
4. 브라우저 설정에서 기본값으로 설정

### Tor와 함께 SearXNG를 사용할 수 있나요?
네! SearXNG는 Tor를 통해 사용하여 온라인 익명성을 향상시킬 수 있습니다. 많은 공개 인스턴스가 Tor 연결을 지원하며, 자체 인스턴스를 Tor와 함께 작동하도록 설정할 수도 있습니다.

### SearXNG는 어떤 검색 구문을 지원하나요?
SearXNG는 다음을 포함한 강력한 검색 구문을 지원합니다:
- `!engine_name query` - 특정 엔진에서 검색
- `:language query` - 특정 언어로 검색  
- `!!external_service query` - 외부 서비스로 직접 리디렉션
- `random uuid`, `avg numbers`, 해시 함수 등의 특수 기능

## 기술적 질문

### 공개 인스턴스와 개인 인스턴스의 차이점은 무엇인가요?
- **공개 인스턴스**: 자원봉사자가 호스팅, 편리하지만 운영자에 대한 신뢰 필요
- **개인 인스턴스**: 자체 호스팅, 개인정보 보호 설정 및 구성에 대한 완전한 제어 제공

### SearXNG는 몇 개의 검색 엔진을 지원하나요?
SearXNG는 **250개의 검색 엔진**으로 구성되어 있으며, 기본적으로 **96개가 활성화**되어 있습니다. 설정을 통해 취향에 따라 엔진을 활성화/비활성화할 수 있습니다.

### SearXNG는 사용자 데이터를 저장하나요?
제대로 구성된 SearXNG 인스턴스는 **사용자 데이터를 전혀 저장하지 않습니다**. 세 가지 수준의 데이터 제거를 구현합니다:
1. 검색 서비스로의 요청 시
2. 제3자 서비스  
3. 결과 페이지

### SearXNG 개발에 기여할 수 있나요?
네! SearXNG는 오픈 소스이며 기여를 환영합니다. 다음을 할 수 있습니다:
- GitHub에서 버그 보고 또는 기능 제안
- 코드 개선 기여
- 문서 작성 지원
- 인터페이스를 다른 언어로 번역
- 공개 인스턴스 실행 및 유지

## 설치 관련 질문

### 자체 호스팅을 위한 시스템 요구 사항은 무엇인가요?
- Python 3.8 이상
- 기본적인 웹 서버 지식
- 약 500MB 디스크 공간
- 최신 Linux 배포판 (Ubuntu, Debian, CentOS 등)

### Docker 설치를 권장하나요?
네, Docker/Podman 컨테이너 설치는 **권장 방법**입니다. 가장 쉬운 설정, 자동 업데이트 및 적절한 격리를 제공하기 때문입니다.

### SearXNG 인스턴스를 어떻게 업데이트 하나요?
- **Docker**: 최신 이미지 가져오기 및 컨테이너 재시작
- **스크립트 설치**: 설치 스크립트 다시 실행
- **수동 설치**: git에서 최신 변경 사항 가져오기 및 서비스 재시작

## 개인정보 보호 및 보안

### SearXNG는 얼마나 안전한가요?
SearXNG는 보안과 개인정보 보호를 최우선 과제로 설계되었습니다:
- 사용자 추적 또는 프로파일링 없음
- 암호화된 연결을 위한 HTTPS 지원
- 정기적인 보안 감사 및 업데이트
- 투명성을 위한 오픈 소스 코드

### SearXNG를 신뢰할 수 있나요?
SearXNG는 오픈 소스이므로 다음을 할 수 있습니다:
- 코드 직접 검토
- 완전한 제어를 위해 자체 개인 인스턴스 실행
- searx.space에서 평판 좋은 공개 인스턴스 선택
- 설치 무결성 확인

최대한의 개인정보 보호와 신뢰를 위해 자체 인스턴스를 실행하는 것이 항상 최선의 선택입니다.
