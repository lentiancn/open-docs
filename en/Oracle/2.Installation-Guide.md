# Oracle Database Installation Guide

## Oracle Database 19c Installation

### System Requirements

#### Operating System Support
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### Hardware Requirements
- **Memory**: Minimum 2GB RAM (4GB or more recommended)
- **Disk Space**: Minimum 6.5GB available space (Enterprise Edition)
- **Processor**: Processor architecture supported by the operating system

### Installation Steps

#### 1. Download Software
Obtain Oracle Database 19c installation packages from Oracle Software Delivery Cloud:
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. Prepare System Environment
```bash
# Linux system example
# Create oracle user and groups
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# Set kernel parameters
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# Set user limits
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. Run Installer
```bash
# Extract installation package and run installer
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. Graphical Installation Wizard
- Select installation type (Desktop class, Server class)
- Configure database identification (Global Database Name, SID)
- Set management passwords
- Execute root scripts
- Complete installation

### Free Version Installation
Oracle Database Free (19c) provides a free version that can be quickly deployed via Docker:
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Cloud Service Deployment

### Oracle Cloud Infrastructure (OCI)
- Select Database service in OCI Console
- Choose Oracle Database version (19c or 26ai)
- Configure compute instance and storage
- Automatic installation and configuration completion

### Other Cloud Providers
- AWS RDS for Oracle
- Azure Database for Oracle
- Google Cloud Oracle solutions

## Troubleshooting

### Common Issues
- **Permission Issues**: Ensure oracle user has correct file and directory permissions
- **Port Conflicts**: Default listening port 1521, ensure port is not occupied
- **Insufficient Memory**: Adjust SGA and PGA memory parameters
- **Character Set Issues**: Correctly select database character set during installation

### Log Locations
- Installation logs: `$ORACLE_BASE/cfgtoollogs/dbca/`
- Database alert logs: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
