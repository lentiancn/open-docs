# SQLite Benutzerhandbuch

## Erste Schritte

### SQLite-Befehlszeilenprogramm vs. SQLite-Bibliothek

Es ist wichtig zu verstehen, dass es zwei verschiedene Dinge gibt:
- **SQLite-Bibliothek**: Implementiert die SQL-Datenbank-Engine
- **sqlite3-Befehlszeilenprogramm (CLI)**: Eine Anwendung, die Benutzereingaben entgegennimmt und an die SQLite-Bibliothek weiterleitet

Dieses Handbuch befasst sich mit dem CLI, nicht mit der zugrundeliegenden SQLite-Bibliothek.

### Starten der CLI

Starten Sie das sqlite3-Programm, indem Sie "sqlite3" an der Kommandozeile eingeben, optional gefolgt vom Namen der Datei, die die SQLite-Datenbank enthält:

```bash
$ sqlite3 ex1
SQLite version 3.51.3 2024-11-26 17:36:39
Enter ".help" for usage hints.
sqlite>
```

Wenn die angegebene Datei nicht existiert, wird automatisch eine neue Datenbankdatei mit dem angegebenen Namen erstellt. Wenn keine Datenbankdatei angegeben wird, wird eine temporäre In-Memory-Datenbank verwendet.

### Einfaches Beispiel

```sql
sqlite> create table tbl1(one text, two int);
sqlite> insert into tbl1 values('hello!',10);
sqlite> insert into tbl1 values('goodbye', 20);
sqlite> select * from tbl1;
hello!|10
goodbye|20
sqlite>
```

Beenden Sie das Programm mit Strg+D (Unix/Linux/macOS) oder Strg+Z+Enter (Windows).

## Spezielle Befehle (Dot-Befehle)

Eingabezeilen, die mit einem Punkt (".") beginnen, werden vom sqlite3-Programm selbst interpretiert. Diese "Dot-Befehle" werden typischerweise verwendet, um das Ausgabeformat von Abfragen zu ändern oder vordefinierte Abfragen auszuführen.

Wichtige Dot-Befehle:

- `.help` - Zeigt alle verfügbaren Dot-Befehle an
- `.databases` - Listet alle geöffneten Datenbanken auf
- `.tables` - Zeigt alle Tabellen in der Datenbank an
- `.schema` - Zeigt das vollständige Schema der Datenbank an
- `.mode` - Ändert das Ausgabeformat
- `.output` - Leitet die Ausgabe in eine Datei um
- `.quit` oder `.exit` - Beendet das Programm

## Ausgabeformate

SQLite unterstützt 14 verschiedene Ausgabeformate:

- **list** (Standard): Jede Zeile in einer Zeile, Spalten durch Pipe-Symbol getrennt
- **column**: Tabellarische Ausgabe mit ausgerichteten Spalten
- **box**: Rahmen um die Tabelle mit Unicode-Zeichen
- **table**: Rahmen um die Tabelle mit ASCII-Zeichen
- **markdown**: Markdown-Tabellenformat
- **csv**: Komma-getrennte Werte
- **json**: JSON-Format
- **html**: HTML-Tabellen
- **insert**: SQL INSERT-Anweisungen
- **line**: Jede Spalte in separater Zeile
- **quote**: SQL-Literal-Format

Beispiel für Formatwechsel:
```sql
sqlite> .mode box
sqlite> select * from tbl1;
┌─────────┬─────┐
│ one     │ two │
├─────────┼─────┤
│ hello!  │ 10  │
│ goodbye │ 20  │
└─────────┴─────┘
```

## Datenbankschema abfragen

### Tabellen auflisten
```sql
sqlite> .tables
```

### Indizes anzeigen
```sql
sqlite> .indexes
-- Oder für eine bestimmte Tabelle:
sqlite> .indexes tbl1
```

### Vollständiges Schema anzeigen
```sql
sqlite> .schema
-- Oder für eine bestimmte Tabelle:
sqlite> .schema tbl1
```

### Geöffnete Datenbanken anzeigen
```sql
sqlite> .databases
```

## Datei-E/A-Operationen

### Ergebnisse in eine Datei schreiben
```sql
sqlite> .output test_file.txt
sqlite> select * from tbl1;
sqlite> .output  -- Zurück zur Konsole
```

### SQL aus einer Datei lesen
```sql
sqlite> .read myscript.sql
```

### Dateien importieren
```sql
-- CSV-Datei importieren
sqlite> .import --csv data.csv mytable
```

### Daten exportieren
```sql
-- Als CSV exportieren
sqlite> .headers on
sqlite> .mode csv
sqlite> .once output.csv
sqlite> select * from mytable;
```

## ZIP-Archive als Datenbanken

SQLite kann ZIP-Archive direkt öffnen und wie Datenbanken behandeln:

```bash
$ sqlite3 document.docx
```

Ein ZIP-Archiv erscheint als Datenbank mit einer einzigen Tabelle namens "zip":

```sql
CREATE TABLE zip(
 name,      -- Name der Datei
 mode,      -- Unix-Dateiberechtigungen
 mtime,     -- Zeitstempel (Sekunden seit 1970)
 sz,        -- Dateigröße nach Dekomprimierung
 rawdata,   -- Roh komprimierte Dateidaten
 data,      -- Dekomprimierter Dateiinhalt
 method     -- ZIP-Komprimierungsmethode
);
```

## Datenbank-Wiederherstellung

### Vollständige Datenbank in Text konvertieren
```sql
sqlite> .dump
```

### Daten aus beschädigter Datenbank wiederherstellen
```sql
sqlite> .recover
```

Der `.recover`-Befehl versucht, Daten aus allen unbeschädigten Teilen der Datenbank wiederherzustellen, während `.dump` beim ersten Anzeichen einer Beschädigung stoppt.

## Erweiterungen laden

Benutzerdefinierte Erweiterungen können zur Laufzeit geladen werden:

```sql
sqlite> .load /path/to/my_extension
```

## Kryptografische Hashes

Berechnen Sie einen SHA3-Hash des Datenbankinhalts:

```sql
sqlite> .sha3sum
-- Mit verschiedenen Varianten:
sqlite> .sha3sum --sha3-256
```

## Selbsttests

Führen Sie Integritätstests durch:

```sql
sqlite> .selftest
```

Ohne spezielle Testtabelle führt dies `PRAGMA integrity_check` aus.

## SQLite-Archiv-Unterstützung

Integrierte Unterstützung für das SQLite-Archivformat (ähnlich wie tar):

```sql
-- Archiv erstellen
sqlite> .archive --create --file archive.db file1 file2

-- Dateien extrahieren
sqlite> .archive --extract --file archive.db

-- Dateien auflisten
sqlite> .archive --list --file archive.db
```
