# Oracle Database 소개

Oracle Database는 오라클 사(Oracle Corporation)가 개발한 관계형 데이터베이스 관리 시스템(RDBMS)으로, 전 세계적으로 가장 유명한 엔터프라이즈급 데이터베이스 솔루션 중 하나입니다.

## 주요 버전

### Oracle Database 26ai
Oracle Database 26ai(정식 명칭: Oracle AI Database 26ai)는 2026년에 출시된 Oracle Database의 최신 버전입니다. 이 버전은 고급 인공지능 기능을 통합하여 향상된 자동화 관리 및 성능 최적화 기능을 제공합니다.

**참고**: Oracle Database 26ai는 최신 출시 버전입니다. 자세한 기술 문서는 오라클 공식 웹사이트를 참조하십시오.

### Oracle Database 19c
Oracle Database 19c는 Oracle Database의 장기 지원 버전으로, 안정적이고 신뢰할 수 있는 엔터프라이즈급 데이터베이스 기능을 제공합니다. 이 버전은 Windows x64, Linux x86-64, Linux ARM, Solaris, AIX, HP-UX 및 Linux on System z를 포함한 다양한 운영체제 플랫폼을 지원합니다.

## 핵심 기능

- **고가용성**: Real Application Clusters(RAC), Data Guard와 같은 고가용성 솔루션 제공
- **보안**: 투명한 데이터 암호화, 감사, 접근 제어를 포함한 고급 보안 기능 내장
- **확장성**: 단일 인스턴스에서 대규모 분산 클러스터에 이르기까지 다양한 배포 모델 지원
- **성능 최적화**: 자동 SQL 튜닝, 메모리 관리 및 스토리지 최적화
- **멀티모델 지원**: 관계형, JSON, XML, 그래프 등 다양한 데이터 모델 지원
- **클라우드 네이티브**: 컨테이너화 배포 및 클라우드 환경 통합 지원
