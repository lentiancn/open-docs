# SearXNG 常見問題（FAQ）

## 一般問題

### 什麼是 SearXNG？
SearXNG 是一個免費的網際網路元搜尋引擎，能夠聚合來自多達 250 個不同搜尋服務的結果。它旨在透過不追蹤或畫像使用者來保護使用者隱私，確保搜尋期間的完全匿名性。

### 為什麼我應該使用 SearXNG 而不是常規搜尋引擎？
- **隱私保護**：無使用者追蹤、畫像或資料收集
- **無過濾氣泡**：結果不會根據您的歷史記錄進行個人化
- **多個來源**：聚合許多搜尋引擎的結果
- **開源**：透明的程式碼可以被任何人稽核
- **可自訂**：高度可設定以滿足個人偏好
- **免費使用**：無費用且無廣告

### SearXNG 是如何運作的？
SearXNG 充當元搜尋引擎，同時將您的查詢傳送到多個搜尋服務，然後聚合結果並在統一介面中呈現。它從請求中刪除識別資訊並清理結果以保護您的隱私。

## 使用問題

### 如何將 SearXNG 設定為我的預設搜尋引擎？
SearXNG 支援 OpenSearch，允許您輕鬆將其新增到瀏覽器的搜尋提供者：
1. 存取任何 SearXNG 實例
2. 尋找 "新增到瀏覽器" 或設定選項
3. 按照瀏覽器的說明將其新增為搜尋提供者
4. 在瀏覽器設定中將其設為預設

### 我可以在 Tor 上使用 SearXNG 嗎？
可以！SearXNG 可以透過 Tor 使用以增強線上匿名性。許多公共實例支援 Tor 連線，您也可以設定自己的實例與 Tor 配合使用。

### SearXNG 支援什麼搜尋語法？
SearXNG 支援強大的搜尋語法，包括：
- `!engine_name query` - 搜尋特定引擎
- `:language query` - 用特定語言搜尋  
- `!!external_service query` - 直接重新導向到外部服務
- 特殊功能如 `random uuid`、`avg numbers`、雜湊函數等

## 技術問題

### 公共實例和私人實例有什麼區別？
- **公共實例**：由志願者託管，方便但需要信任操作員
- **私人實例**：自託管，讓您完全控制隱私設定和設定

### SearXNG 支援多少個搜尋引擎？
SearXNG 設定了 **250 個搜尋引擎**，預設啟用了 **96 個**。您可以根據偏好透過設定啟用/停用引擎。

### SearXNG 是否儲存任何使用者資料？
正確設定的 SearXNG 實例**不儲存任何使用者資料**。它們實施三個級別的資料刪除：
1. 向搜尋引擎傳送請求時
2. 第三方服務  
3. 結果頁面

### 我可以為 SearXNG 開發做貢獻嗎？
可以！SearXNG 是開源的，歡迎貢獻。您可以：
- 在 GitHub 上回報錯誤或建議功能
- 貢獻程式碼改進
- 幫助編寫文件
- 將介面翻譯成其他語言
- 執行和維護公共實例

## 安裝問題

### 自託管的系統要求是什麼？
- Python 3.8 或更高版本
- 基本的 Web 伺服器知識
- 大約 500MB 磁碟空間
- 任何現代 Linux 發行版（Ubuntu、Debian、CentOS 等）

### 是否推薦 Docker 安裝？
是的，Docker/Podman 容器安裝是**推薦的方法**，因為它提供最簡單的設定、自動更新和適當的隔離。

### 如何更新我的 SearXNG 實例？
- **Docker**：拉取最新映像並重新啟動容器
- **指令碼安裝**：再次執行安裝指令碼
- **手動安裝**：從 git 拉取最新變更並重新啟動服務

## 隱私和安全

### SearXNG 有多安全？
SearXNG 的設計將安全和隱私作為首要任務：
- 無使用者追蹤或畫像
- HTTPS 支援加密連線
- 定期安全稽核和更新
- 開源程式碼以保證透明度

### SearXNG 可以信任嗎？
由於 SearXNG 是開源的，您可以：
- 自己審查程式碼
- 執行自己的私人實例以獲得完全控制
- 從 searx.space 選擇信譽良好的公共實例
- 驗證安裝的完整性

為了獲得最大的隱私和信任，執行您自己的實例始終是最好的選擇。
