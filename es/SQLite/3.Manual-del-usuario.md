# Manual del Usuario de SQLite

## Conceptos básicos

### Comandos SQL fundamentales

#### Creación de tablas
```sql
CREATE TABLE nombre_tabla (
    columna1 TIPO_DATO [RESTRICCIONES],
    columna2 TIPO_DATO [RESTRICCIONES],
    ...
);
```

Ejemplo:
```sql
CREATE TABLE empleados (
    id INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    salario REAL,
    fecha_contratacion DATE
);
```

#### Inserción de datos
```sql
INSERT INTO nombre_tabla (columna1, columna2, ...) 
VALUES (valor1, valor2, ...);
```

Ejemplo:
```sql
INSERT INTO empleados (nombre, salario, fecha_contratacion)
VALUES ('Ana García', 2500.00, '2023-01-15');
```

#### Consulta de datos
```sql
SELECT columnas FROM nombre_tabla WHERE condiciones;
```

Ejemplos:
```sql
-- Seleccionar todos los empleados
SELECT * FROM empleados;

-- Seleccionar empleados con salario mayor a 2000
SELECT nombre, salario FROM empleados WHERE salario > 2000;

-- Ordenar resultados
SELECT * FROM empleados ORDER BY salario DESC;
```

#### Actualización de datos
```sql
UPDATE nombre_tabla SET columna = valor WHERE condicion;
```

Ejemplo:
```sql
UPDATE empleados SET salario = 2700.00 WHERE nombre = 'Ana García';
```

#### Eliminación de datos
```sql
DELETE FROM nombre_tabla WHERE condicion;
```

Ejemplo:
```sql
DELETE FROM empleados WHERE salario < 2000;
```

## Tipos de datos en SQLite

SQLite utiliza un sistema de tipado dinámico con las siguientes afinidades de tipo:

- **INTEGER**: Números enteros con signo
- **REAL**: Números de punto flotante
- **TEXT**: Cadenas de texto
- **BLOB**: Datos binarios sin interpretación
- **NUMERIC**: Usado para fechas y otros valores numéricos especiales

## Funciones integradas

### Funciones de agregación
- `COUNT()`: Cuenta filas
- `SUM()`: Suma valores
- `AVG()`: Calcula promedio
- `MIN()`: Valor mínimo
- `MAX()`: Valor máximo

### Funciones de fecha y hora
- `date()`: Devuelve la fecha actual
- `time()`: Devuelve la hora actual
- `datetime()`: Devuelve fecha y hora actuales
- `strftime()`: Formatea fechas y horas

Ejemplo:
```sql
SELECT strftime('%Y-%m-%d', 'now') AS fecha_actual;
```

### Funciones de cadena
- `length()`: Longitud de cadena
- `upper()`: Convierte a mayúsculas
- `lower()`: Convierte a minúsculas
- `substr()`: Extrae subcadena
- `replace()`: Reemplaza texto

## Índices

Crear índices para mejorar el rendimiento de consultas:

```sql
-- Índice simple
CREATE INDEX idx_nombre ON empleados(nombre);

-- Índice compuesto
CREATE INDEX idx_salario_fecha ON empleados(salario, fecha_contratacion);
```

## Transacciones

SQLite soporta transacciones ACID:

```sql
BEGIN TRANSACTION;
-- Operaciones SQL aquí
INSERT INTO empleados VALUES (1, 'Carlos', 3000, '2023-02-01');
UPDATE empleados SET salario = 3200 WHERE id = 1;
COMMIT; -- o ROLLBACK para deshacer
```

## Modo de línea de comandos

### Comandos dot (.)

El shell de SQLite incluye comandos especiales que comienzan con punto:

- `.help`: Muestra ayuda
- `.tables`: Lista todas las tablas
- `.schema [tabla]`: Muestra el esquema
- `.dump [tabla]`: Exporta datos como SQL
- `.output archivo`: Redirige salida a archivo
- `.mode csv|json|table`: Cambia formato de salida
- `.quit`: Sale del shell

### Ejemplo de sesión interactiva
```bash
$ sqlite3 mi_empresa.db
SQLite version 3.39.4
Enter ".help" for usage hints.
sqlite> .tables
empleados
sqlite> .schema empleados
CREATE TABLE empleados (
    id INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    salario REAL,
    fecha_contratacion DATE
);
sqlite> SELECT * FROM empleados;
1|Ana García|2500.0|2023-01-15
sqlite> .quit
```

## Restricciones y claves

### Clave primaria (PRIMARY KEY)
```sql
CREATE TABLE tabla (id INTEGER PRIMARY KEY, ...);
```

### Clave foránea (FOREIGN KEY)
```sql
CREATE TABLE pedidos (
    id INTEGER PRIMARY KEY,
    cliente_id INTEGER,
    FOREIGN KEY(cliente_id) REFERENCES clientes(id)
);
```

Nota: Las claves foráneas están deshabilitadas por defecto. Habilítelas con:
```sql
PRAGMA foreign_keys = ON;
```

## Optimización de consultas

### Uso de EXPLAIN QUERY PLAN
```sql
EXPLAIN QUERY PLAN SELECT * FROM empleados WHERE nombre = 'Ana';
```

### Consideraciones de rendimiento
- Use índices en columnas frecuentemente consultadas
- Evite funciones en columnas indexadas en cláusulas WHERE
- Use transacciones para múltiples operaciones
- Considere VACUUM después de grandes eliminaciones

## Copias de seguridad

### Método 1: Usando .dump
```bash
sqlite3 base_original.db .dump > backup.sql
sqlite3 base_nueva.db < backup.sql
```

### Método 2: Copia de archivo directa
Cuando la base de datos no está en uso:
```bash
cp base_original.db base_copia.db
```

### Método 3: Backup en línea
```sql
-- En una conexión activa
.backup 'copia_de_seguridad.db'
```
