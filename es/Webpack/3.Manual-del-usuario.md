# Manual de Usuario de Webpack

Este manual cubre la funcionalidad fundamental de webpack, incluyendo opciones de configuración, uso de CLI y mejores prácticas tanto para Webpack 4 como Webpack 5.

## Configuración

Webpack se configura mediante un archivo JavaScript llamado `webpack.config.js` por defecto. Este archivo exporta un objeto de configuración que le dice a webpack cómo construir su proyecto.

### Configuración Básica

```javascript
// Webpack 4 / Webpack 5 (CommonJS)
const path = require('path');

module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

```javascript
// Webpack 5 (ES Modules)
import path from 'node:path';

export default {
  mode: 'production',
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(import.meta.dirname, 'dist'),
  },
};
```

### Tipos de Configuración

Webpack soporta múltiples tipos de archivos de configuración:

| Tipo | Webpack 4 | Webpack 5 | Descripción |
|------|-----------|-----------|-------------|
| CommonJS | ✅ | ✅ | `module.exports = {}` |
| ES Modules | ⚠️ Limitado | ✅ Completo | `export default {}` |
| TypeScript | ⚠️ Con ts-node | ✅ Nativo | Archivos `.ts` |
| Múltiples Configs | ✅ | ✅ | Array de configuraciones |

## Puntos de Entrada (Entry Points)

El punto de entrada le dice a webpack dónde comenzar a construir el gráfico de dependencias.

### Entrada Única

```javascript
// Webpack 4 & 5
module.exports = {
  entry: './src/index.js',
};
```

### Múltiples Entradas

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    main: './src/index.js',
    vendor: './src/vendor.js',
  },
};
```

### Entradas Dinámicas

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    page1: './src/page1.js',
    page2: './src/page2.js',
  },
};
```

### Objeto de Entrada con Arrays

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    app: ['./src/index.js', './src/another.js'],
  },
};
```

## Output

La configuración de output le dice a webpack dónde emitir los bundles que crea.

### Output Básico

```javascript
// Webpack 4 & 5
module.exports = {
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

### Output Nombrado con [name]

```javascript
// Webpack 4 & 5
module.exports = {
  entry: {
    main: './src/index.js',
    another: './src/another.js',
  },
  output: {
    filename: '[name].bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

### Output con [hash] y [chunkhash]

```javascript
// Webpack 4 & 5
module.exports = {
  output: {
    filename: '[name].[contenthash].js',
    path: path.resolve(__dirname, 'dist'),
    clean: true, // Solo Webpack 5 - limpia la carpeta dist
  },
};
```

### Comparación de Configuración

| Característica | Webpack 4 | Webpack 5 |
|----------------|-----------|-----------|
| **Output.clean** | ❌ No disponible | ✅ Limpia carpeta dist automáticamente |
| **Output.pathinfo** | ✅ Default true | ✅ Default false (producción) |
| **Output.hashFunction** | MD4 | MD4 (default), md4, xxHash64, bubblehash |
| **Output.module** | ❌ No disponible | ✅ Output como ES module |
| **Output.environment** | ❌ No disponible | ✅ Settings de soporte ES module |

## Loaders

Los loaders permiten a webpack procesar más que solo archivos JavaScript.

### Configuración Básica de Loaders

```javascript
// Webpack 4 & 5
module.exports = {
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: 'babel-loader',
      },
    ],
  },
};
```

### Opciones de Loaders

```javascript
// Webpack 4 & 5
module.exports = {
  module: {
    rules: [
      {
        test: /\.js$/,
        use: {
          loader: 'babel-loader',
          options: {
            presets: ['@babel/preset-env'],
            plugins: ['@babel/plugin-transform-runtime'],
          },
        },
      },
    ],
  },
};
```

### Módulos de Activos (Solo Webpack 5)

Webpack 5 introdujo Módulos de Activos como un reemplazo para file-loader, url-loader y raw-loader.

```javascript
// Webpack 5
module.exports = {
  module: {
    rules: [
      // reemplazado file-loader
      {
        test: /\.(png|jpg|gif)$/,
        type: 'asset/resource',
      },
      // reemplazado url-loader
      {
        test: /\.svg$/,
        type: 'asset',
        parser: {
          dataUrlCondition: {
            maxSize: 8 * 1024, // 8kb
          },
        },
      },
      // reemplazado raw-loader
      {
        test: /\.txt$/,
        type: 'asset/source',
      },
    ],
  },
};
```

### Comparación de Loaders

| Tipo de Loader | Webpack 4 | Webpack 5 | Módulo de reemplazo |
|----------------|-----------|-----------|-------------------|
| **file-loader** | Requerido | ✅ Alternativa | `asset/resource` |
| **url-loader** | Requerido | ✅ Alternativa | `asset` |
| **raw-loader** | Requerido | ✅ Alternativa | `asset/source` |
| **svg-url-loader** | Requerido | ✅ Alternativa | Procesamiento personalizado |

## Plugins

Los plugins realizan una gama más amplia de tareas que los loaders, desde optimización de bundles hasta inyección de variables de entorno.

### Configuración Básica de Plugins

```javascript
// Webpack 4 & 5
const HtmlWebpackPlugin = require('html-webpack-plugin');
const webpack = require('webpack');

module.exports = {
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html',
    }),
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production'),
    }),
  ],
};
```

### Plugins Comunes

| Plugin | Descripción | Webpack 4 | Webpack 5 |
|--------|-------------|-----------|-----------|
| **html-webpack-plugin** | Genera archivos HTML | ✅ | ✅ |
| **mini-css-extract-plugin** | Extrae CSS a archivos separados | ✅ | ✅ |
| **clean-webpack-plugin** | Limpia directorio de output | ✅ | ✅ |
| **terser-webpack-plugin** | Minifica JavaScript | ✅ | ✅ |
| **filemanager-webpack-plugin** | Operaciones del sistema de archivos | ✅ | ✅ |
| **module-federation-plugin** | Module Federation | ❌ | ✅ |

### Plugins Integrados en Webpack 5

Webpack 5 incluye varios plugins que eran externos en Webpack 4:

| Plugin | Webpack 4 | Webpack 5 |
|--------|-----------|-----------|
| **asset-plugins** | Requerido | ✅ Integrado |
| **module-federation** | Requerido | ✅ Integrado |
| **persistent-cache** | Requerido | ✅ Integrado |

## Mode

Webpack proporciona tres opciones de mode integradas: `development`, `production` y `none`.

```javascript
// Webpack 4 & 5
module.exports = {
  mode: 'development', // o 'production' o 'none'
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```
