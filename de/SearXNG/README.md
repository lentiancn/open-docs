# SearXNG

SearXNG ist eine kostenlose Internet-Metasuchmaschine, die Ihre Privatsphäre schützt, indem sie Ergebnisse aus 250+ Suchdiensten aggregiert, ohne Benutzer zu verfolgen oder zu profilieren.

## Offizielle Ressourcen
- **Website**: https://searxng.org
- **Dokumentation**: https://docs.searxng.org  
- **Quellcode**: https://github.com/searxng/searxng
- **Öffentliche Instanzen**: https://searx.space

## Hauptmerkmale
- Datenschutzorientierte Metasuchmaschine
- Keine Benutzerverfolgung oder Datensammlung
- Unterstützung für Tor zur verbesserten Anonymität
- Hochgradig anpassbar und konfigurierbar
- Open Source und community-getrieben

## Versionsinformationen
- **Neueste Version**: 2026.3.29+7ac4ff39f
- **Veröffentlichungsmodell**: Rolling Release (tägliche Updates aus dem Master-Branch)

## Erste Schritte
Besuchen Sie eine beliebige öffentliche Instanz unter searx.space oder richten Sie Ihre eigene private Instanz für maximale Datenschutzkontrolle ein.
