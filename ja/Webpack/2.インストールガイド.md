# インストールガイド

Webpack は JavaScript モジュールをコンパイルするために使用されます。インストール後、Webpack は CLI または API を介して操作できます。Webpack が初めての場合は、なぜ他のツールよりも Webpack を使用する必要があるかを学ぶために、コアコンセプトとこの比較を読んでください。

## システム要件

### Node.js のバージョン要件

| Webpack バージョン | Node.js バージョン |
|------------------|------------------|
| Webpack 4.x | 6.x.x 以降 |
| Webpack 5.x | 10.13.0 以降 |

注：Webpack 5 は Webpack 4 よりも最新の Node.js バージョンを必要とします。

## インストール方法

Webpack は2つの方法でインストールできます：

### ローカルインストール（推奨）

Webpack をローカルにインストールすると、特定のプロジェクトで使用するバージョンをより細かく制御でき、異なるバージョンが必要なプロジェクト間の競合を回避できます。

#### npm

```bash
mkdir webpack-demo
cd webpack-demo

# npm
npm init -y
npm install webpack webpack-cli --save-dev
```

#### yarn

```bash
mkdir webpack-demo
cd webpack-demo

# yarn
yarn init -y
yarn add webpack webpack-cli --dev
```

#### pnpm

```bash
mkdir webpack-demo
cd webpack-demo

# pnpm
pnpm init
pnpm add webpack webpack-cli -D
```

### グローバルインストール

グローバルインストールは推奨されません。なぜなら、すべてのプロジェクトで単一の Webpack バージョンに固定されてしまうからです。

#### npm

```bash
npm install -g webpack
npm install -g webpack-cli
```

#### yarn

```bash
yarn global add webpack
yarn global add webpack-cli
```

#### pnpm

```bash
pnpm add -g webpack
pnpm add -g webpack-cli
```

## Webpack CLI

webpack-cli パッケージは、コマンドラインを介して Webpack と対話するための一貫したインターフェースを提供します。ほとんどの Webpack 機能に必要です。

### バージョン互換性

| Webpack バージョン | webpack-cli バージョン |
|------------------|----------------------|
| Webpack 4.x | webpack-cli 3.x または 4.x |
| Webpack 5.x | webpack-cli 4.x または 5.x |

### インストール

```bash
# Webpack 4 用
npm install webpack@4 webpack-cli@4 --save-dev

# Webpack 5 用
npm install webpack@5 webpack-cli@5 --save-dev
```

## クイックスタート：新規プロジェクトの作成

Webpack 5 は `create-webpack-app` という新しいツールを導入し、新しい Webpack プロジェクトをすばやくスキャフォールディングできます。

### create-webpack-app の使用（Webpack 5 のみ）

```bash
npx create-webpack-app webpack-demo
cd webpack-demo
```

これにより、プロジェクトを設定するためいくつかの質問が表示されます：
- 使用する JS ソリューションは？（TypeScript、JavaScript）
- webpack-dev-server を使用しますか？（はい／いいえ）
- HTML ファイルの作成を簡略化しますか？（はい／いいえ）
- PWA サポートを追加しますか？（はい／いいえ）
- 使用する CSS ソリューションは？（CSS のみ、CSS-in-JS など）
- すべてのファイルの CSS を抽出しますか？（.production のみ／いいえ）
- 使用するパッケージマネージャーは？（npm、yarn、pnpm）

### 手動プロジェクト設定

プロジェクトを手動で設定したい場合は、次の手順を follow してください：

```bash
mkdir webpack-demo
cd webpack-demo

# npm を初期化
npm init -y

# Webpack をインストール
npm install webpack webpack-cli --save-dev

# ディレクトリ構造を作成
mkdir src dist

# エントリーファイルを作成
echo 'console.log("Hello webpack");' > src/index.js

# HTML ファイルを作成
cat > dist/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Webpack デモ</title>
</head>
<body>
    <script src="main.js"></script>
</body>
</html>
EOF
```

## 設定ファイル

バージョン 4 から、Webpack はプロジェクトをバンドルするために設定ファイルが不要になりました。ただし、ほとんどのプロジェクトではより複雑な設定が必要となるため、Webpack は設定ファイルをサポートしています。

### 基本的な設定（Webpack 5 で ES モジュール）

```javascript
// webpack.config.js
import path from "node:path";
import { fileURLToPath } from "node:url";

// import.meta.dirname をネイティブにサポートしない Node.js のバージョンでは、
// import.meta.url から __dirname を導出します。
// （Node 20.11+ は import.meta.dirname と import.meta.filename をサポート）
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

export default {
  entry: "./src/index.js",
  output: {
    filename: "main.js",
    path: path.resolve(__dirname, "dist"),
  },
};
```

### 基本的な設定（Webpack 4 / Webpack 5 で CommonJS）

```javascript
// webpack.config.js
const path = require('path');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'main.js',
    path: path.resolve(__dirname, 'dist')
  }
};
```

## 設定ファイルの比较

| 機能 | Webpack 4 | Webpack 5 |
|------|-----------|-----------|
| **デフォルトフォーマット** | CommonJS | ES モジュール（CommonJS もサポート） |
| **ECMAScript モジュール** | 制限付きサポート | 完全なサポート |
| **import.meta.dirname** | サポートされません | サポート（Node 20.11+） |
| **Type デフォルト** | `module` | `module`（package.json に type があれば） |

## インストールの確認

インストール後、バージョンを確認して Webpack が正しくインストールされたことを検証できます：

```bash
# Webpack バージョンを確認
npx webpack --version

# webpack-cli バージョンを確認
npx webpack-cli --version
```

期待される出力：
```
 webpack 5.x.x
webpack-cli 4.x.x
```

## Webpack CLI コマンド

インストール後、さまざまな Webpack CLI コマンドを使用できます：

| コマンド | 説明 |
|--------|------|
| `webpack` | Webpack を実行（デフォルトコマンド） |
| `webpack build` | Webpack ビルドを実行 |
| `webpack watch` | ファイルの変更を監視 |
| `webpack serve` | webpack-dev-server を実行 |
| `webpack info` | システム情報を出力 |
| `webpack configtest` | Webpack 設定を検証 |
| `webpack help` | ヘルプを表示 |

### 基本的な使用方法

```bash
# 設定ファイルなし
npx webpack --entry ./src/index.js --output-path ./dist

# 設定ファイルあり
npx webpack --config webpack.config.js

# 監視モード
npx webpack --watch

# 特定のモードで
npx webpack --mode development
npx webpack --mode production
```

## package.json スクリプト

Webpack の使用を便利にするために、`package.json` に npm スクリプトを追加します：

### Webpack 4 の設定

```json
{
  "name": "webpack-demo",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "build": "webpack",
    "watch": "webpack --watch"
  },
  "devDependencies": {
    "webpack": "^4.46.0",
    "webpack-cli": "^3.3.12"
  }
}
```

### Webpack 5 の設定

```json
{
  "name": "webpack-demo",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "scripts": {
    "build": "webpack",
    "watch": "webpack --watch"
  },
  "devDependencies": {
    "webpack": "^5.88.0",
    "webpack-cli": "^5.1.4"
  }
}
```

## バージョン固有の CLI 機能

### Webpack 4 CLI

- 基本的なビルドと監視コマンド
- 基本的な設定オプション
- CLI からの制限されたプラグインサポート

### Webpack 5 CLI

- webpack コアからの改善された設定スキーマ

- より良いエラーメッセージと診断
- `create-webpack-app` スキャフォールディングのサポート

## トラブルシューティング

### 一般的なインストールの問題

#### 1. Node.js のバージョンが古すぎる

エラー：`Webpack 5 requires Node.js version 10.13.0 or later`

解決策：サポートされているバージョンに Node.js を更新

#### 2. webpack-cli が見つからない

エラー：`Could not find webpack-cli. Did you mean to install it?`

解決策：開発依存関係として webpack-cli をインストール：
```bash
npm install webpack-cli --save-dev
```

#### 3. 権限エラー

エラー：`EACCES: permission denied`

解決策：`sudo` を使用または npm 権限を修正：
```bash
# オプション1：sudo を使用（推奨されません）
sudo npm install -g webpack

# オプション2：npm 権限を修正
sudo chown -R $(whoami) ~/.npm
```

#### 4. パッケージが見つからない

エラー：`Cannot find module 'webpack'`

解決策：Webpack がローカルにインストールされていることを確認：
```bash
npm install webpack --save-dev
```

### バージョンの競合

グローバルに複数の Webpack バージョンをインストールしている場合、競合が発生する可能性があります：

```bash
# グローバルパッケージを確認
npm list -g webpack webpack-cli

# 競合するバージョンをアンインストール
npm uninstall -g webpack
npm uninstall -g webpack-cli

# 特定のバージョンをインストール
npm install -g webpack@5
npm install -g webpack-cli@4
```
