# SQLite 概要

## SQLite とは

SQLite は軽量で自己完結型の SQL データベースエンジンです。サーバーを必要とせず、設定不要で、単一のファイルにデータベース全体を格納します。SQLite はパブリックドメインであり、商用および非商用の両方の用途で自由に使用できます。

## 主な特徴

- **サーバーレス**: SQLite は伝統的なクライアント-サーバーモデルではなく、アプリケーションに直接組み込まれるライブラリです。
- **ゼロ設定**: インストールや管理が不要で、すぐに使用できます。
- **トランザクション安全**: ACID（原子性、一貫性、分離性、耐久性）準拠のトランザクションをサポートしています。
- **クロスプラットフォーム**: Windows、Linux、macOS、Android、iOS など、さまざまなオペレーティングシステムで動作します。
- **自己完結型**: 外部依存関係がなく、単一のライブラリファイルで構成されています。
- **信頼性と安定性**: 広範なテストと実績により、非常に信頼性の高いデータベースエンジンです。

## 使用例

SQLite は以下のような幅広いアプリケーションで使用されています：

- 組み込みデバイスおよび IoT デバイス
- モバイルアプリケーション（Android、iOS）
- デスクトップアプリケーション
- ウェブブラウザ（Google Chrome、Mozilla Firefox など）
- オペレーティングシステム（Apple macOS、Microsoft Windows）
- サーバーアプリケーション（小規模から中規模のWebサイト）

## 技術仕様

- データベースは単一のディスクファイルとして保存されます
- 最大データベースサイズ：140TB
- 最大テーブル数：制限なし
- 最大カラム数：2000（デフォルトは2000、コンパイル時に変更可能）
- 最大行数：制限なし（64ビット符号付き整数の範囲内）

## ライセンス

SQLite はパブリッドドメインにあり、著作権表示や保証の放棄を含む献呈文が付属しています。商用および非商用の両方のプロジェクトで自由に使用、修正、配布できます。
