## SQLite란?

SQLite는 C 언어로 구현된 작고, 빠르며, 자체 완비적이고, 높은 신뢰성을 가진 SQL 데이터베이스 엔진입니다. 서버 프로세스가 필요 없으며, 단일 디스크 파일에 전체 데이터베이스를 저장합니다.

- **서버리스**: 별도의 서버 프로세스 불필요
- **제로 설정**: 설치나 관리가 필요 없음  
- **크로스 플랫폼**: 다양한 운영체제와 아키텍처 지원
- **공개 도메인**: 상업적/개인적 사용 모두 무료
- **철저한 테스트**: 모든 릴리스 전 자동화된 테스트 수행
