# Webpack 模組打包器

Webpack 是一種用於現代 JavaScript 應用程式的靜態模組打包工具。它會處理您的應用程式，構建依賴關係圖，並建立最佳化的打包檔案。

## 主要版本資訊

### Webpack v5（現代版本）
- **官方網站**: https://webpack.js.org/
- **狀態**: 持續開發中
- **特性**: 支援 ES Module、持久化快取、模組聯合（Module Federation）、內建資源模組、效能提升

### Webpack v4（舊版本）
- **官方網站**: https://v4.webpack.js.org/
- **狀態**: 已停止維護（EOL）
- **特性**: CommonJS 設定、基礎打包、程式碼分割、Tree Shaking

## 功能對比

| 功能 | Webpack v5 | Webpack v4 |
|------|------------|------------|
| **模組系統** | ES Module + CommonJS | 僅 CommonJS |
| **快取** | 持久化快取 | 記憶體快取 |
| **資源處理** | 內建資源模組 | 需要 file-loader/url-loader |
| **效能** | 使用持久化快取，建置更快 | 標準效能 |
| **模組聯合** | 內建支援 | 不可用 |
| **Node.js 支援** | Node.js 10.13.0+ | Node.js 6.11.5+ |

## 遷移路徑

Webpack 提供了從 v4 到 v5 的平滑遷移路徑：
1. 將相依更新到最新版本
2. 用資源模組替換 file-loader/url-loader
3. 檢查外掛相容性並更新設定
4. 利用持久化快取和模組聯合等新功能
