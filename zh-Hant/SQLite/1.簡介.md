# SQLite 簡介

SQLite 是一個 C 語言庫，實現了小型、快速、自包含、高可靠性、全功能的 SQL 數據庫引擎。SQLite 是世界上最廣泛部署的數據庫引擎，它被內置於幾乎所有手機、大多數計算機中，並被用於許多流行的應用程序中。

## 主要特點

- **零配置**：無需安裝或管理。
- **自包含**：整個數據庫存儲在單個跨平台磁盤文件中。
- **緊湊**：完整的 SQLite 版本小於 725KiB（x64 上）。
- **高效**：比流行的客戶端/服務器數據庫引擎快得多。
- **可靠**：即使在系統崩潰或電源故障後也能保持事務完整性。
- **易於使用**：簡單的 API 和 SQL 語法。
- **開源**：代碼在公有領域，任何人都可以自由使用。

## 設計哲學

SQLite 的設計目標是提供一個簡單、可靠的數據庫解決方案，適用於嵌入式應用和小型到中型項目。它不是為了取代大型企業級數據庫系統，而是為那些不需要完整客戶端/服務器架構的應用提供輕量級選擇。

## 使用場景

- 移動應用程序（Android、iOS）
- 桌面應用程序
- 小型 Web 應用
- 測試和開發環境
- 嵌入式系統
- 臨時數據存儲

SQLite 是公共領域軟件，這意味著任何人都可以免費使用它做任何事情。
