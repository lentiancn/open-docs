# Руководство по установке SQLite

## Обзор

Скомпилировать SQLite можно следующим образом:

- **Unix и Mac**: `./configure && make`
- **Windows**: `nmake /f Makefile.msc`

Приведенные выше команды соберут **амальгамацию** и **интерфейс командной строки** (CLI). Зависимостей нет, поэтому эти команды должны работать, если у вас установлен компилятор. Не требуется стороннего программного обеспечения.

## Амальгамация против отдельных исходных файлов

SQLite состоит из более чем ста файлов кода на C и скриптов, распределенных по нескольким каталогам. Для упрощения работы SQLite также доступен в виде предварительно упакованного файла исходного кода амальгамации: **sqlite3.c**.

Амальгамация — это один файл кода ANSI-C, который реализует всю библиотеку SQLite. Амальгамация намного проще в использовании. Весь код содержится в одном файле, поэтому его легко добавить в дерево исходного кода более крупной программы на C или C++. Все этапы генерации и преобразования кода уже выполнены, поэтому нет необходимости настраивать и компилировать вспомогательные программы C или запускать скрипты.

Использование амальгамации (скачанной с сайта или собранной самостоятельно из канонических исходников) рекомендуется для всех приложений.

## Компиляция интерфейса командной строки

Для сборки интерфейса командной строки (CLI) требуются три исходных файла:

- **sqlite3.c** — файл исходного кода амальгамации SQLite
- **sqlite3.h** — заголовочный файл, сопровождающий sqlite3.c
- **shell.c** — сама программа командной строки

Все три файла содержатся в архиве амальгамации, доступном на странице загрузки.

### Компиляция на Unix/Linux:

```bash
gcc shell.c sqlite3.c -lpthread -ldl -lm -o sqlite3
```

Для не-потокобезопасного режима (CLI однопоточный):
```bash
gcc -DSQLITE_THREADSAFE=0 shell.c sqlite3.c -ldl -lm -o sqlite3
```

Для полной функциональности:
```bash
gcc -Os -I. -DSQLITE_THREADSAFE=0 -DSQLITE_ENABLE_FTS4 \
 -DSQLITE_ENABLE_FTS5 -DSQLITE_ENABLE_JSON1 \
 -DSQLITE_ENABLE_RTREE -DSQLITE_ENABLE_EXPLAIN_COMMENTS \
 -DHAVE_READLINE \
 shell.c sqlite3.c -ldl -lm -lreadline -lncurses -o sqlite3
```

### Компиляция на Windows (MSVC):

```cmd
cl shell.c sqlite3.c -Fesqlite3.exe
```

## Сборка Windows DLL

Для создания DLL SQLite для Windows:

### С использованием MSVC:
```cmd
cl sqlite3.c -link -dll -out:sqlite3.dll
```

### С использованием MinGW:
```bash
gcc -shared sqlite3.c -o sqlite3.dll
```

Общие параметры компиляции:
- `-Os` — оптимизация по размеру (сделать DLL как можно меньше)
- `-O2` — оптимизация по скорости (увеличит размер DLL)
- `-DSQLITE_ENABLE_FTS4` — включить движок полнотекстового поиска
- `-DSQLITE_ENABLE_RTREE` — включить расширение R-Tree

## Предварительно скомпилированные двоичные файлы

На официальной странице загрузки доступны предварительно скомпилированные двоичные файлы для различных платформ:

### Linux
- **sqlite-tools-linux-x64-*.zip** — инструменты командной строки для Linux x64

### Mac OS X  
- **sqlite-tools-osx-arm64-*.zip** — инструменты для Mac OS-X на ARM
- **sqlite-tools-osx-x64-*.zip** — инструменты для Mac OS-X на x64

### Windows
- **sqlite-dll-win-arm64-*.zip** — DLL для Windows ARM64
- **sqlite-dll-win-x64-*.zip** — DLL для Windows x64  
- **sqlite-dll-win-x86-*.zip** — DLL для Windows x86 (32-бит)
- **sqlite-tools-win-x64-*.zip** — инструменты командной строки для Windows x64

## Сборка собственной амальгамации

Если вам нужно собрать собственную амальгамацию с определенными параметрами компиляции:

1. Скачайте исходные файлы с официального сайта или из системы управления версиями
2. Создайте подходящий Makefile (запустите configure или скопируйте шаблон)
3. Отредактируйте Makefile для включения желаемых параметров компиляции
4. Выполните команду: `make sqlite3.c`

Это создаст файлы sqlite3.c, sqlite3.h и tclsqlite3.c с вашими настройками.
