# SearXNG 설치 가이드

이 가이드는 자체 SearXNG 인스턴스를 설정하기 위한 여러 설치 방법을 다룹니다.

## 설치 방법

### 1. 컨테이너 설치 (권장)

가장 쉽고 신뢰할 수 있는 방법은 Docker 또는 Podman 컨테이너를 사용하는 것입니다.

**사전 요구 사항:**
- Docker 또는 Podman 설치됨
- 기본적인 컨테이너 관리 지식

**단계:**
```bash
# 공식 SearXNG 이미지 가져오기
docker pull searxng/searxng

# 기본 구성으로 실행
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. 설치 스크립트

uWSGI 설정을 포함한 대부분의 구성을 자동으로 처리하는 자동화된 설치 스크립트를 사용할 수 있습니다.

**단계:**
```bash
# 설치 스크립트 다운로드
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# 실행 권한 부여 및 실행
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. 단계별 수동 설치

설치 프로세스를 완전히 제어하려는 고급 사용자를 위한 방법입니다.

**사전 요구 사항:**
- Python 3.8 이상
- uWSGI
- Git
- 빌드 도구 (gcc, make 등)
- 웹 서버 (NGINX 또는 Apache)

**설치 단계:**

1. **필요한 패키지 설치:**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **전용 사용자 생성:**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **저장소 복제:**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **설정 구성:**
   ```bash
   # 기본 설정 복사
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # 필요에 따라 구성 편집
   sudo nano /etc/searxng/settings.yml
   ```

5. **웹 서버 설정:**
   
   **NGINX 구성 예시:**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## 설치 후

설치 후 `http://your-server:port`에서 SearXNG 인스턴스에 액세스하여 정상적으로 작동하는지 확인하세요. `settings.yml` 구성 파일을 통해 외관, 엔진 및 동작을 맞춤 설정할 수 있습니다.

## 문제 해결

- **권한 문제**: searxng 사용자가 모든 파일에 적절한 권한을 가지고 있는지 확인
- **포트 충돌**: 선택한 포트가 이미 사용 중인지 확인
- **엔진 구성**: 일부 검색 엔진은 API 키 또는 특정 구성이 필요할 수 있음
- **SSL 설정**: 프로덕션 사용을 위해 Let's Encrypt 또는 선호하는 CA를 사용하여 SSL 인증서 구성
