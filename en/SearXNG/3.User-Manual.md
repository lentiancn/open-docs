# SearXNG User Manual

This manual covers how to effectively use SearXNG for searching and customization.

## Search Syntax

SearXNG supports powerful search syntax to refine your queries:

### Engine Selection
- **`!` prefix**: Select specific engine or category
  - `!wp paris` - Search Wikipedia for "paris"
  - `!images Wau Holland` - Search images for "Wau Holland"
  - `!news climate change` - Search news engines for "climate change"

### Language Selection
- **`:` prefix**: Select search language
  - `:fr !wp Wau Holland` - Search French Wikipedia for "Wau Holland"
  - `:de climate change` - Search in German for "climate change"

### External Bangs
- **`!!` prefix**: Direct redirects to external services
  - `!!youtube cats` - Redirect directly to YouTube search for "cats"

### Special Queries
SearXNG supports various special query functions:
- `random uuid` - Generate a random UUID
- `avg 123 548` - Calculate average of numbers
- `user-agent` - Display your current user agent
- Hash functions: `md5 text`, `sha1 text`, `sha256 text`
- Unit conversions: `100 USD in EUR`, `10 km in miles`

## Configured Search Engines

SearXNG comes with **250 search engines** configured, with **96 enabled by default**. Engines are organized into categories:

### Categories
- **General**: Standard web search engines
- **Images**: Image search services
- **Videos**: Video search platforms
- **News**: News aggregation services
- **Map**: Mapping and location services
- **Music**: Music search and streaming
- **IT**: Technical and programming resources
- **Science**: Academic and scientific databases
- **Files**: File sharing and document search
- **Social Media**: Social platform search

### Subgroups
Each category contains subgroups for more specific searches:
- Books, Currency, Translate, Web, Wikimedia, and more

## Interface Customization

### Preferences
Access preferences through the settings icon to customize:
- **Default search language**
- **Enabled search engines**
- **Result display options**
- **Privacy settings**
- **Theme and appearance**

### Plugins
SearXNG includes useful plugins:
- **Calculator**: Perform mathematical calculations
- **Hash**: Generate various hash values
- **Self Information**: Display client information
- **Timezones**: Convert between time zones
- **Tor Check**: Verify Tor connectivity
- **Unit Converter**: Convert between units of measurement

## Privacy Features

### Anonymous Searching
- All searches are anonymous by default
- No cookies or tracking scripts
- IP address is not logged (in properly configured instances)

### Result Sanitization
- URLs are cleaned of tracking parameters
- Referrer information is stripped
- Third-party scripts are blocked

## Advanced Usage

### API Access
SearXNG provides a simple API for programmatic access:
```
GET /search?q=your_query&format=json
```

### Custom Engines
You can add custom search engines by modifying the `settings.yml` file:
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### Keyboard Shortcuts
- **`/`**: Focus search input
- **`Esc`**: Clear search or close dialogs
- **`Enter`**: Submit search
- **`Ctrl+Enter`**: Open results in new tab

This comprehensive manual should help you get the most out of your SearXNG experience while maintaining complete privacy and control over your search activity.
