# Oracle Database

Oracle Database は、オラクル社が開発したエンタープライズ向けリレーショナルデータベース管理システムです。

## ドキュメントバージョン

- **Oracle Database 26ai** - 最新バージョン（2026年リリース）
- **Oracle Database 19c** - 長期サポートバージョン

## ドキュメント構成

1. **概要** - Oracle Database の概要と主要機能
2. **インストールガイド** - 詳細なインストール手順とシステム要件
3. **ユーザーマニュアル** - 完全な SQL、PL/SQL プログラミングおよび管理操作
4. **よくある質問** - よくある質問とトラブルシューティング
