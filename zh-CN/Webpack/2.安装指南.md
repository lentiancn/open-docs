# Webpack 安装指南

## Webpack v5（现代版本）安装

### 本地安装（推荐）

对于大多数项目，建议将 Webpack 作为开发依赖进行本地安装：

```bash
# npm
npm init -y
npm install webpack webpack-cli --save-dev

# yarn
yarn init -y
yarn add webpack webpack-cli --dev

# pnpm
pnpm init
pnpm add webpack webpack-cli -D
```

### 全局安装（不推荐）

虽然可以全局安装，但不推荐，因为这可能导致项目间的版本冲突：

```bash
# npm
npm install --global webpack webpack-cli

# yarn
yarn global add webpack webpack-cli
```

### 基本项目设置

创建以下目录结构：

```
project/
├── package.json
├── dist/
│   └── index.html
└── src/
    └── index.js
```

安装需要打包的依赖：

```bash
# npm
npm install --save lodash

# yarn
yarn add lodash

# pnpm
pnpm add lodash
```

### 运行 Webpack

本地安装后，可以使用以下命令运行 Webpack：

```bash
# npm
npx webpack

# yarn
yarn webpack

# pnpm
pnpm exec webpack
```

## Webpack v4 安装

### 本地安装

```bash
# npm
npm init -y
npm install webpack@4.x webpack-cli@3.x --save-dev

# yarn
yarn init -y
yarn add webpack@4.x webpack-cli@3.x --dev
```

### 运行 Webpack v4

```bash
npx webpack
```

注意：Webpack v4 会显示警告，提示未设置 'mode' 选项。您可以通过添加 `--mode=production` 或 `--mode=development` 标志来解决此问题。

## NPM 脚本设置

在 `package.json` 中添加构建脚本，以更方便地使用：

```json
{
  "scripts": {
    "build": "webpack"
  }
}
```

然后运行：

```bash
# npm
npm run build

# yarn
yarn build

# pnpm
pnpm run build
```

## 版本选择建议

- **新项目**: 使用 Webpack v5，以利用现代特性、更好的性能和持久化缓存
- **现有项目**: 如果已经在使用 Webpack v4，可以考虑升级到 v5 以获得性能提升
- **企业环境**: Webpack v4 提供稳定的长期支持，而 v5 提供前沿功能

## 从 v4 迁移到 v5

Webpack 提供了平滑的迁移路径：

1. 更新依赖：`npm install webpack@latest webpack-cli@latest`
2. 查阅官方迁移指南，了解破坏性变更
3. 如果使用 ES Module，更新配置语法
4. 彻底测试以确保兼容性

官方迁移指南提供了处理特定破坏性变更和已弃用特性的详细说明。
