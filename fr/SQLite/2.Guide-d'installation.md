# Guide d'installation de SQLite

## Méthodes d'installation

### À partir des binaires précompilés

SQLite propose des binaires précompilés pour différentes plateformes :

#### Linux
- Téléchargez `sqlite-tools-linux-x64-*.zip` depuis la [page de téléchargement](https://www.sqlite.org/download.html)
- Décompressez l'archive et placez les exécutables dans votre `$PATH`

#### macOS
- Téléchargez `sqlite-tools-osx-arm64-*.zip` (pour Apple Silicon) ou `sqlite-tools-osx-x64-*.zip` (pour Intel)
- Décompressez l'archive
- Note : Ces binaires ne sont pas signés. Après installation, exécutez :
  ```bash
  xattr -d com.apple.quarantine <nom_du_programme>
  ```

#### Windows
- Téléchargez `sqlite-tools-win-x64-*.zip`
- Décompressez l'archive dans un répertoire de votre choix
- Ajoutez ce répertoire à votre variable d'environnement `PATH`

### Compilation à partir des sources

#### Prérequis
- Un compilateur C (gcc, clang, MSVC, etc.)
- Make (sur Unix/Linux/macOS)
- Pour les builds avancés : Tcl (nécessaire pour compiler à partir du dépôt source)

#### Méthode recommandée : Utilisation de l'amalgame

L'amalgame SQLite (`sqlite3.c`) est un fichier source unique contenant l'intégralité de la bibliothèque SQLite. C'est la méthode recommandée pour tous les projets.

1. Téléchargez l'amalgame depuis la [page de téléchargement](https://www.sqlite.org/download.html):
   - `sqlite-amalgamation-*.zip` (fichiers sources C)
   - `sqlite-autoconf-*.tar.gz` (inclut également un script "configure")

2. **Sur Unix/Linux/macOS** :
   ```bash
   # Avec le script configure (méthode la plus simple)
   tar xzf sqlite-autoconf-*.tar.gz
   cd sqlite-autoconf-*
   ./configure
   make
   sudo make install
   
   # Ou compilation directe
   gcc shell.c sqlite3.c -lpthread -ldl -lm -o sqlite3
   ```

3. **Sur Windows avec MSVC** :
   ```cmd
   cl shell.c sqlite3.c -Fesqlite3.exe
   ```

4. **Sur Windows avec MinGW** :
   ```bash
   gcc shell.c sqlite3.c -lpthread -ldl -lm -o sqlite3.exe
   ```

#### Compilation avec options personnalisées

Vous pouvez personnaliser la compilation avec diverses options :

```bash
# Exemple complet sur Unix
gcc -Os -I. -DSQLITE_THREADSAFE=0 -DSQLITE_ENABLE_FTS4 \
    -DSQLITE_ENABLE_FTS5 -DSQLITE_ENABLE_JSON1 \
    -DSQLITE_ENABLE_RTREE -DSQLITE_ENABLE_EXPLAIN_COMMENTS \
    -DHAVE_READLINE \
    shell.c sqlite3.c -ldl -lm -lreadline -lncurses -o sqlite3
```

Options courantes :
- `-DSQLITE_ENABLE_FTS4` ou `-DSQLITE_ENABLE_FTS5` : recherche plein texte
- `-DSQLITE_ENABLE_RTREE` : extension R*Tree
- `-DSQLITE_ENABLE_JSON1` : fonctions JSON
- `-DSQLITE_THREADSAFE=0` : désactive la sécurité thread (améliore les performances pour les applications mono-thread)

### Création d'une DLL Windows

Pour créer une DLL SQLite sous Windows :

**Avec MSVC** :
```cmd
cl sqlite3.c -link -dll -out:sqlite3.dll
```

**Avec MinGW** :
```bash
gcc -shared sqlite3.c -o sqlite3.dll
```

## Vérification de l'installation

Après installation, vérifiez que SQLite fonctionne correctement :

```bash
sqlite3 --version
```

Vous devriez voir la version de SQLite installée.

## Intégration dans les projets

### C/C++
Pour intégrer SQLite dans votre projet C/C++, copiez simplement `sqlite3.c` et `sqlite3.h` dans votre arborescence source et compilez-les avec votre code.

### Autres langages
SQLite dispose de liaisons pour de nombreux langages :
- **Python** : inclus par défaut (`import sqlite3`)
- **Java** : plusieurs bibliothèques disponibles (SQLite JDBC, etc.)
- **C#/.NET** : System.Data.SQLite
- **TCL** : interface TCL incluse dans la distribution
- **JavaScript** : via WebAssembly ou Node.js modules

## Notes importantes

- L'amalgame source (`sqlite3.c`) est recommandé pour tous les projets car il permet des optimisations plus avancées par le compilateur (5-10% d'amélioration des performances).
- La compilation à partir des fichiers sources individuels est possible mais beaucoup plus complexe.
- Pour les applications spécialisées nécessitant des options de compilation non standards, il est recommandé de générer un amalgame personnalisé plutôt que d'utiliser les fichiers sources individuels directement.
