# SQLite 安裝指南

SQLite 有多種安裝方式，取決於您的操作系統和使用需求。

## 預編譯二進制文件

### Windows

1. 訪問 [SQLite 下載頁面](https://www.sqlite.org/download.html)
2. 下載以下文件：
   - `sqlite-tools-win32-*.zip`：命令行 shell 程序
   - `sqlite-dll-win32-*.zip`：SQLite DLL（動態鏈接庫）
3. 解壓縮文件到您選擇的目錄
4. 將該目錄添加到系統 PATH 環境變量中（可選）

### macOS

使用 Homebrew 安裝：
```bash
brew install sqlite
```

或使用 MacPorts：
```bash
sudo port install sqlite3
```

### Linux

大多數 Linux 發行版已經預裝了 SQLite。如果沒有，可以使用包管理器安裝：

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install sqlite3
```

**CentOS/RHEL/Fedora:**
```bash
# CentOS/RHEL
sudo yum install sqlite

# Fedora
sudo dnf install sqlite
```

## 從源碼編譯

如果您需要最新版本或自定義編譯選項，可以從源碼編譯：

1. 下載源碼包：
   ```bash
   wget https://www.sqlite.org/2023/sqlite-autoconf-3430000.tar.gz
   ```

2. 解壓縮：
   ```bash
   tar xzf sqlite-autoconf-3430000.tar.gz
   cd sqlite-autoconf-3430000
   ```

3. 配置和編譯：
   ```bash
   ./configure --prefix=/usr/local
   make
   sudo make install
   ```

## 驗證安裝

安裝完成後，可以通過以下命令驗證：

```bash
sqlite3 --version
```

這應該顯示 SQLite 的版本號。

## 開發庫安裝

如果您計劃在自己的程序中使用 SQLite，還需要安裝開發庫：

**Ubuntu/Debian:**
```bash
sudo apt-get install libsqlite3-dev
```

**CentOS/RHEL/Fedora:**
```bash
# CentOS/RHEL
sudo yum install sqlite-devel

# Fedora
sudo dnf install sqlite-devel
```

**macOS (Homebrew):**
```bash
brew install sqlite3
```

安裝完成後，您就可以在應用程序中使用 SQLite 了。
