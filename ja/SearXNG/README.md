# SearXNG

SearXNGは、250以上の検索サービスからの結果を集約することでプライバシーを保護する無料のインターネットメタ検索エンジンです。ユーザーを追跡またはプロファイリングしません。

## 公式リソース
- **ウェブサイト**：https://searxng.org
- **ドキュメント**：https://docs.searxng.org  
- **ソースコード**：https://github.com/searxng/searxng
- **パブリックインスタンス**：https://searx.space

## 主な特徴
- プライバシー重視のメタ検索エンジン
- ユーザーの追跡やデータ収集なし
- 匿名性を強化するためのTorサポート
- 高度にカスタマイズ可能で設定可能
- オープンソースでコミュニティ主導

## はじめに
searx.spaceの任意のパブリックインスタンスにアクセスするか、最大限のプライバシー制御を得るために独自のプライベートインスタンスをセットアップしてください。
