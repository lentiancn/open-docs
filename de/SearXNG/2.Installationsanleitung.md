# SearXNG Installationsanleitung

Dieser Leitfaden behandelt mehrere Installationsmethoden zum Einrichten Ihrer eigenen SearXNG-Instanz.

## Installationsmethoden

### 1. Container-Installation (Empfohlen)

Die einfachste und zuverlässigste Methode ist die Verwendung von Docker- oder Podman-Containern.

**Voraussetzungen:**
- Docker oder Podman installiert
- Grundlegende Kenntnisse der Container-Verwaltung

**Schritte:**
```bash
# Offizielles SearXNG-Image ziehen
docker pull searxng/searxng

# Mit grundlegender Konfiguration ausführen
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. Installationsskript

Ein automatisiertes Installationsskript ist verfügbar, das die meisten Konfigurationen automatisch durchführt, einschließlich der uWSGI-Einrichtung.

**Schritte:**
```bash
# Installationsskript herunterladen
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# Ausführungsrechte vergeben und ausführen
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. Schritt-für-Schritt manuelle Installation

Für fortgeschrittene Benutzer, die die volle Kontrolle über den Installationsprozess haben möchten.

**Voraussetzungen:**
- Python 3.8 oder höher
- uWSGI
- Git
- Build-Tools (gcc, make, etc.)
- Webserver (NGINX oder Apache)

**Installationsschritte:**

1. **Erforderliche Pakete installieren:**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **Dedizierten Benutzer erstellen:**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **Repository klonen:**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **Einstellungen konfigurieren:**
   ```bash
   # Standard-Einstellungen kopieren
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # Konfiguration nach Bedarf bearbeiten
   sudo nano /etc/searxng/settings.yml
   ```

5. **Webserver einrichten:**
   
   **NGINX-Konfigurationsbeispiel:**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## Nach der Installation

Nach der Installation greifen Sie auf Ihre SearXNG-Instanz unter `http://your-server:port` zu und überprüfen, ob sie korrekt funktioniert. Sie können das Erscheinungsbild, die Suchmaschinen und das Verhalten über die Konfigurationsdatei `settings.yml` anpassen.

## Fehlerbehebung

- **Berechtigungsprobleme**: Stellen Sie sicher, dass der searxng-Benutzer die richtigen Berechtigungen für alle Dateien hat
- **Port-Konflikte**: Überprüfen Sie, ob der gewählte Port nicht bereits verwendet wird
- **Suchmaschinen-Konfiguration**: Einige Suchmaschinen benötigen möglicherweise API-Schlüssel oder spezielle Konfigurationen
- **SSL-Einrichtung**: Für den Produktiveinsatz konfigurieren Sie SSL-Zertifikate mit Let's Encrypt oder Ihrer bevorzugten Zertifizierungsstelle
