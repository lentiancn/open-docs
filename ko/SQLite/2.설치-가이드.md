# SQLite 설치 가이드

SQLite는 다양한 플랫폼에서 사용할 수 있으며 여러 가지 방법으로 설치하거나 통합할 수 있습니다.

## 소스 코드 다운로드

SQLite 공식 웹사이트(https://www.sqlite.org/download.html)에서는 다음과 같은 소스 코드 패키지를 제공합니다:

### 1. 완전한 소스 트리 (sqlite-src-*.zip)
- 버전 3.x.x용 완전한 정규 소스 트리
- 테스트 케이스 및 확장 기능 포함
- 모든 다른 소스 코드 번들은 이 패키지에서 파생됨

### 2. 앰벌게이션 (sqlite-amalgamation-*.zip)
- 단일 C 파일(`sqlite3.c`)과 헤더 파일(`sqlite3.h`)로 구성
- 가장 일반적으로 사용되는 형태
- 프로젝트에 쉽게 통합 가능

### 3. 자동 설정 스크립트 포함 (sqlite-autoconf-*.tar.gz)
- 앰벌게이션 소스 코드 포함
- Unix/Linux 시스템용 configure 스크립트 제공
- 표준 `./configure && make && make install` 절차로 빌드 가능

## 미리 컴파일된 바이너리

### Linux
- **sqlite-tools-linux-x64-*.zip**: x64 아키텍처용 명령줄 도구
  - sqlite3 명령줄 셸
  - sqldiff (데이터베이스 비교 도구)
  - sqlite3_analyzer (데이터베이스 분석기)
  - sqlite3_rsync (원격 데이터베이스 복사 도구)

### macOS
- **sqlite-tools-osx-arm64-*.zip**: Apple Silicon(M1/M2)용 도구
- **sqlite-tools-osx-x64-*.zip**: Intel Mac용 도구
- 참고: 다운로드한 바이너리는 서명되지 않았으므로 실행 전 다음 명령어로 격리 해제 필요:
  ```bash
  xattr -d com.apple.quarantine <프로그램_이름>
  ```

### Windows
- **sqlite-dll-win-*.zip**: Windows용 DLL 파일 (ARM64, x64, x86 지원)
- **sqlite-tools-win-x64-*.zip**: Windows x64용 명령줄 도구

### Android
- **sqlite-android-*.aar**: Android Studio 프로젝트에 바로 사용 가능한 AAR 라이브러리

### WebAssembly & JavaScript
- **sqlite-wasm-*.zip**: 웹 애플리케이션용 WebAssembly 및 JavaScript API 번들

## 빌드 방법

### Unix/Linux 시스템에서 빌드
```bash
# 자동 설정 패키지 사용
tar xzf sqlite-autoconf-*.tar.gz
cd sqlite-autoconf-*
./configure --prefix=/usr/local
make
sudo make install

# 또는 앰벌게이션 직접 컴파일
gcc -o sqlite3 sqlite3.c -lpthread -ldl
```

### Windows에서 빌드
Visual Studio 또는 MinGW를 사용하여 `sqlite3.c` 파일을 컴파일할 수 있습니다.

### macOS에서 빌드
```bash
gcc -o sqlite3 sqlite3.c -ldl
```

## 패키지 매니저를 통한 설치

### Ubuntu/Debian
```bash
sudo apt-get install sqlite3 libsqlite3-dev
```

### CentOS/RHEL/Fedora
```bash
# CentOS/RHEL
sudo yum install sqlite sqlite-devel

# Fedora
sudo dnf install sqlite sqlite-devel
```

### macOS (Homebrew)
```bash
brew install sqlite3
```

### Windows (Chocolatey)
```bash
choco install sqlite
```

## 개발 라이브러리 통합

### C/C++ 프로젝트
1. `sqlite3.c`와 `sqlite3.h` 파일을 프로젝트에 추가
2. 소스 코드에서 `#include "sqlite3.h"`로 헤더 포함
3. 링크 시 pthread와 dl 라이브러리 연결 필요 (Linux/macOS)

### 다른 언어 바인딩
- **Python**: 표준 라이브러리에 sqlite3 모듈 포함
- **Java**: SQLite JDBC 드라이버 또는 Android 내장 SQLite
- **C#**: System.Data.SQLite
- **Node.js**: sqlite3, better-sqlite3 등의 패키지 사용

## 확인 방법

설치가 완료되면 다음 명령어로 버전을 확인할 수 있습니다:
```bash
sqlite3 --version
```

또는 SQLite CLI를 실행하여 대화형 셸을 시작할 수 있습니다:
```bash
sqlite3
```
