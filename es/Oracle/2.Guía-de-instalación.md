# Guía de Instalación de Oracle Database

## Instalación de Oracle Database 19c

### Requisitos del Sistema

#### Soporte de Sistemas Operativos
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### Requisitos de Hardware
- **Memoria**: Mínimo 2GB RAM (4GB o más recomendado)
- **Espacio en Disco**: Mínimo 6.5GB de espacio disponible (Edición Enterprise)
- **Procesador**: Arquitectura de procesador soportada por el sistema operativo

### Pasos de Instalación

#### 1. Descargar Software
Obtenga los paquetes de instalación de Oracle Database 19c desde Oracle Software Delivery Cloud:
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. Preparar el Entorno del Sistema
```bash
# Ejemplo para sistemas Linux
# Crear usuario y grupos oracle
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# Establecer parámetros del kernel
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# Establecer límites de usuario
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. Ejecutar el Instalador
```bash
# Descomprimir paquete de instalación y ejecutar instalador
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. Asistente de Instalación Gráfico
- Seleccionar tipo de instalación (clase escritorio, clase servidor)
- Configurar identificación de base de datos (nombre global de base de datos, SID)
- Establecer contraseñas de administración
- Ejecutar scripts root
- Completar instalación

### Instalación de Versión Gratuita
Oracle Database Free (19c) proporciona una versión gratuita que se puede implementar rápidamente mediante Docker:
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Instalación de Oracle Database 26ai

Oracle Database 26ai es la versión más reciente. La guía de instalación debe consultarse en la documentación oficial de Oracle:
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### Implementación en Contenedores
Oracle Database 26ai soporta métodos modernos de implementación en contenedores:
```bash
# Ejemplo de implementación con Docker (el nombre de imagen específico debe consultarse en la documentación oficial)
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## Implementación en Servicios Cloud

### Oracle Cloud Infrastructure (OCI)
- Seleccionar servicio Database en la consola de OCI
- Elegir versión de Oracle Database (19c o 26ai)
- Configurar instancia de cómputo y almacenamiento
- Finalización automática de instalación y configuración

### Otros Proveedores Cloud
- AWS RDS for Oracle
- Azure Database for Oracle
- Soluciones Oracle de Google Cloud

## Solución de Problemas

### Problemas Comunes
- **Problemas de Permisos**: Asegurarse de que el usuario oracle tenga los permisos correctos de archivos y directorios
- **Conflictos de Puerto**: Puerto de escucha predeterminado 1521, asegurarse de que el puerto no esté ocupado
- **Memoria Insuficiente**: Ajustar parámetros de memoria SGA y PGA
- **Problemas de Conjunto de Caracteres**: Seleccionar correctamente el conjunto de caracteres de la base de datos durante la instalación

### Ubicaciones de Registros
- Registros de instalación: `$ORACLE_BASE/cfgtoollogs/dbca/`
- Registros de alertas de base de datos: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
