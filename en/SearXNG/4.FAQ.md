# SearXNG Frequently Asked Questions (FAQ)

## General Questions

### What is SearXNG?
SearXNG is a free internet metasearch engine that aggregates results from up to 250 different search services. It's designed to protect user privacy by not tracking or profiling users, ensuring complete anonymity during searches.

### Why should I use SearXNG instead of regular search engines?
- **Privacy Protection**: No user tracking, profiling, or data collection
- **No Filter Bubbles**: Results aren't personalized based on your history
- **Multiple Sources**: Aggregates results from many search engines
- **Open Source**: Transparent code that can be audited by anyone
- **Customizable**: Highly configurable for personal preferences
- **Free to Use**: No cost and no ads

### How does SearXNG work?
SearXNG acts as a metasearch engine that sends your query to multiple search services simultaneously, then aggregates and presents the results in a unified interface. It removes identifying information from requests and sanitizes results to protect your privacy.

## Usage Questions

### How do I set SearXNG as my default search engine?
SearXNG supports OpenSearch, which allows you to easily add it to your browser's search providers:
1. Visit any SearXNG instance
2. Look for the "Add to browser" or settings option
3. Follow your browser's instructions to add it as a search provider
4. Set it as default in your browser settings

### Can I use SearXNG with Tor?
Yes! SearXNG can be used over Tor for enhanced online anonymity. Many public instances support Tor connections, and you can also set up your own instance to work with Tor.

### What search syntax does SearXNG support?
SearXNG supports powerful search syntax including:
- `!engine_name query` - Search specific engine
- `:language query` - Search in specific language  
- `!!external_service query` - Direct redirect to external service
- Special functions like `random uuid`, `avg numbers`, hash functions, etc.

## Technical Questions

### What's the difference between public and private instances?
- **Public Instances**: Hosted by volunteers, convenient but require trust in the operator
- **Private Instances**: Self-hosted, giving you complete control over privacy settings and configuration

### How many search engines does SearXNG support?
SearXNG comes configured with **250 search engines**, with **96 enabled by default**. You can enable/disable engines based on your preferences through the settings.

### Does SearXNG store any user data?
Properly configured SearXNG instances store **no user data**. They implement three levels of data removal:
1. From requests to search services
2. From third-party services  
3. From result pages

### Can I contribute to SearXNG development?
Yes! SearXNG is open source and welcomes contributions. You can:
- Report bugs or suggest features on GitHub
- Contribute code improvements
- Help with documentation
- Translate the interface to other languages
- Run and maintain public instances

## Installation Questions

### What are the system requirements for self-hosting?
- Python 3.8 or higher
- Basic web server knowledge
- Approximately 500MB disk space
- Any modern Linux distribution (Ubuntu, Debian, CentOS, etc.)

### Is Docker installation recommended?
Yes, Docker/Podman container installation is the **recommended method** as it provides the easiest setup, automatic updates, and proper isolation.

### How do I update my SearXNG instance?
- **Docker**: Pull the latest image and restart the container
- **Script Installation**: Run the installation script again
- **Manual Installation**: Pull latest changes from git and restart services

## Privacy and Security

### How secure is SearXNG?
SearXNG is designed with security and privacy as top priorities:
- No user tracking or profiling
- HTTPS support for encrypted connections
- Regular security audits and updates
- Open source code for transparency

### Can SearXNG be trusted?
Since SearXNG is open source, you can:
- Review the code yourself
- Run your own private instance for complete control
- Choose reputable public instances from searx.space
- Verify the integrity of installations

For maximum privacy and trust, running your own instance is always the best option.
