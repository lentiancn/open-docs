# SearXNG Foire Aux Questions (FAQ)

## Questions Générales

### Qu'est-ce que SearXNG ?
SearXNG est un moteur de méta-recherche internet gratuit qui agrège les résultats de jusqu'à 250 services de recherche différents. Il est conçu pour protéger la vie privée des utilisateurs en ne les suivant ni en les profilant, assurant ainsi un anonymat complet pendant les recherches.

### Pourquoi devrais-je utiliser SearXNG au lieu des moteurs de recherche réguliers ?
- **Protection de la vie privée** : Aucun suivi, profilage ou collecte de données des utilisateurs
- **Pas de bulles de filtre** : Les résultats ne sont pas personnalisés en fonction de votre historique
- **Sources multiples** : Agrège les résultats de nombreux moteurs de recherche
- **Open Source** : Code transparent qui peut être audité par n'importe qui
- **Personnalisable** : Hautement configurable pour les préférences personnelles
- **Gratuit à utiliser** : Pas de coût et pas de publicités

### Comment fonctionne SearXNG ?
SearXNG agit comme un moteur de méta-recherche qui envoie votre requête à plusieurs services de recherche simultanément, puis agrège et présente les résultats dans une interface unifiée. Il supprime les informations d'identification des requêtes et assainit les résultats pour protéger votre vie privée.

## Questions d'Utilisation

### Comment définir SearXNG comme mon moteur de recherche par défaut ?
SearXNG prend en charge OpenSearch, ce qui vous permet d'ajouter facilement aux fournisseurs de recherche de votre navigateur :
1. Visitez n'importe quelle instance SearXNG
2. Recherchez l'option "Ajouter au navigateur" ou les paramètres
3. Suivez les instructions de votre navigateur pour l'ajouter comme fournisseur de recherche
4. Définissez-le comme par défaut dans les paramètres de votre navigateur

### Puis-je utiliser SearXNG avec Tor ?
Oui ! SearXNG peut être utilisé via Tor pour améliorer l'anonymat en ligne. De nombreuses instances publiques prennent en charge les connexions Tor, et vous pouvez également configurer votre propre instance pour fonctionner avec Tor.

### Quelle syntaxe de recherche SearXNG prend-il en charge ?
SearXNG prend en charge une syntaxe de recherche puissante incluant :
- `!nom_moteur requête` - Rechercher dans un moteur spécifique
- `:langue requête` - Rechercher dans une langue spécifique  
- `!!service_externe requête` - Redirection directe vers un service externe
- Fonctions spéciales comme `random uuid`, `avg nombres`, fonctions de hachage, etc.

## Questions Techniques

### Quelle est la différence entre les instances publiques et privées ?
- **Instances Publiques** : Hébergées par des bénévoles, pratiques mais nécessitent la confiance en l'opérateur
- **Instances Privées** : Auto-hébergées, vous donnant un contrôle total sur les paramètres de confidentialité et la configuration

### Combien de moteurs de recherche SearXNG prend-il en charge ?
SearXNG est configuré avec **250 moteurs de recherche**, avec **96 activés par défaut**. Vous pouvez activer/désactiver des moteurs en fonction de vos préférences via les paramètres.

### SearXNG stocke-t-il des données utilisateur ?
Les instances SearXNG correctement configurées **ne stockent aucune donnée utilisateur**. Elles implémentent trois niveaux de suppression des données :
1. Des requêtes vers les services de recherche
2. Des services tiers  
3. Des pages de résultats

### Puis-je contribuer au développement de SearXNG ?
Oui ! SearXNG est open source et accueille les contributions. Vous pouvez :
- Signaler des bogues ou suggérer des fonctionnalités sur GitHub
- Contribuer aux améliorations du code
- Aider à la documentation
- Traduire l'interface dans d'autres langues
- Exécuter et maintenir des instances publiques

## Questions d'Installation

### Quelles sont les exigences système pour l'auto-hébergement ?
- Python 3.8 ou supérieur
- Connaissances de base en serveur web
- Environ 500 Mo d'espace disque
- Toute distribution Linux moderne (Ubuntu, Debian, CentOS, etc.)

### L'installation Docker est-elle recommandée ?
Oui, l'installation par conteneur Docker/Podman est la **méthode recommandée** car elle fournit la configuration la plus simple, des mises à jour automatiques et un isolement approprié.

### Comment mettre à jour mon instance SearXNG ?
- **Docker** : Tirer la dernière image et redémarrer le conteneur
- **Installation par script** : Exécuter à nouveau le script d'installation
- **Installation manuelle** : Tirer les dernières modifications depuis git et redémarrer les services

## Vie Privée et Sécurité

### À quel point SearXNG est-il sécurisé ?
SearXNG est conçu avec la sécurité et la vie privée comme priorités principales :
- Aucun suivi ou profilage des utilisateurs
- Prise en charge HTTPS pour les connexions chiffrées
- Audits de sécurité et mises à jour régulières
- Code open source pour la transparence

### Peut-on faire confiance à SearXNG ?
Puisque SearXNG est open source, vous pouvez :
- Examiner le code vous-même
- Exécuter votre propre instance privée pour un contrôle total
- Choisir des instances publiques réputées depuis searx.space
- Vérifier l'intégrité des installations

Pour une confidentialité et une confiance maximales, exécuter votre propre instance est toujours la meilleure option.
