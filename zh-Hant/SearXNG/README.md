# SearXNG

SearXNG 是一個免費的網際網路元搜尋引擎，透過聚合來自 250+ 搜尋服務的結果來保護您的隱私，不會追蹤或畫像使用者。

## 官方資源
- **網站**：https://searxng.org
- **文件**：https://docs.searxng.org  
- **原始碼**：https://github.com/searxng/searxng
- **公共實例**：https://searx.space

## 主要特性
- 隱私優先的元搜尋引擎
- 無使用者追蹤或資料收集
- 支援 Tor 以增強匿名性
- 高度可自訂和可設定
- 開源且社群驅動
