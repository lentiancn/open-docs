# Yarn 安装指南

## Yarn 4+ (现代版本) 安装

### 推荐安装方式（使用 Corepack）

Corepack 是一个中介工具，允许您按项目配置包管理器版本：

```bash
# 全局安装 Corepack
npm install -g corepack

# 初始化新项目（使用 Yarn Berry）
yarn init -2
```

### 更新 Yarn

任何时候想要更新到最新版本，只需运行：

```bash
yarn set version stable
yarn install
```

Yarn 将配置您的项目使用最新的稳定二进制文件。

### 使用 Canary 版本

Yarn 经常发布 Release Candidate 构建。如果您需要尚未在稳定频道发布的功能：

```bash
yarn set version canary
```

这些构建非常稳定，与常规频道的唯一区别是在主要版本之间采用更渐进的迁移方式。

### 从源码安装最新版本

如果您想测试尚未发布甚至未合并的 Yarn 版本：

```bash
# 从主分支克隆、构建并安装
yarn set version from sources

# 测试特定 PR
yarn set version from sources --branch 1211
```

**注意**: `yarn set version from sources` 命令无法利用 Corepack，需要将 Yarn 二进制文件存储在 `.yarn/releases` 文件夹中，并从项目的 `.yarnrc.yml` 文件中引用它。

## Yarn Classic (v1) 安装

### 通过 npm 安装（推荐）

建议通过 npm 包管理器安装 Yarn，npm 随 Node.js 一起安装：

```bash
# 安装或升级 Yarn Classic
npm install --global yarn
```

### 验证安装

安装完成后，通过以下命令检查 Yarn 是否正确安装：

```bash
yarn --version
```

## 版本选择建议

- **新项目**: 推荐使用 Yarn 4+ (现代版本)，享受最新的功能和改进
- **现有项目**: 
  - 如果已经在使用 Yarn Classic，可以继续使用
  - 考虑迁移到现代版本以获得更好的性能和功能
- **企业环境**: 现代版本提供更好的工作区支持和稳定性保证

## 系统要求

- **Node.js**: 所有版本都需要 Node.js 环境
- **npm**: Yarn Classic 需要 npm 进行全局安装
- **Corepack**: 现代版本推荐使用 Corepack 进行版本管理

> **注意**: 本文档基于官方 yarnpkg.com 和 classic.yarnpkg.com 网站内容整理。
