# SearXNG Руководство по установке

Это руководство охватывает несколько методов установки для настройки собственного инстанса SearXNG.

## Методы установки

### 1. Установка через контейнер (рекомендуется)

Самый простой и надежный метод — использование контейнеров Docker или Podman.

**Предварительные требования:**
- Установлен Docker или Podman
- Базовые знания управления контейнерами

**Шаги:**
```bash
# Загрузить официальный образ SearXNG
docker pull searxng/searxng

# Запустить с базовой конфигурацией
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. Скрипт установки

Доступен автоматизированный скрипт установки, который автоматически обрабатывает большую часть конфигурации, включая настройку uWSGI.

**Шаги:**
```bash
# Скачать скрипт установки
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# Сделать исполняемым и запустить
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. Пошаговая ручная установка

Для продвинутых пользователей, желающих иметь полный контроль над процессом установки.

**Предварительные требования:**
- Python 3.8 или выше
- uWSGI
- Git
- Инструменты сборки (gcc, make и т.д.)
- Веб-сервер (NGINX или Apache)

**Шаги установки:**

1. **Установить необходимые пакеты:**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **Создать выделенного пользователя:**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **Клонировать репозиторий:**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **Настроить параметры:**
   ```bash
   # Скопировать настройки по умолчанию
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # При необходимости отредактировать конфигурацию
   sudo nano /etc/searxng/settings.yml
   ```

5. **Настроить веб-сервер:**
   
   **Пример конфигурации NGINX:**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## После установки

После установки перейдите к своему инстансу SearXNG по адресу `http://your-server:port` и убедитесь, что он работает правильно. Вы можете настроить внешний вид, движки и поведение через файл конфигурации `settings.yml`.

## Устранение неполадок

- **Проблемы с правами**: Убедитесь, что пользователь searxng имеет соответствующие права на все файлы
- **Конфликты портов**: Проверьте, не используется ли выбранный порт
- **Конфигурация движков**: Некоторые поисковые движки могут требовать API-ключи или специальную конфигурацию
- **Настройка SSL**: Для производственного использования настройте SSL-сертификаты с помощью Let's Encrypt или вашего предпочтительного центра сертификации
