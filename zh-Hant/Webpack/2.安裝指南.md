# Webpack 安裝指南

## Webpack v5（現代版本）安裝

### 本地安裝（推薦）

對於大多數專案，將 webpack 作為開發依賴本地安裝：

```bash
# npm
npm init -y
npm install webpack webpack-cli --save-dev

# yarn
yarn init -y
yarn add webpack webpack-cli --dev

# pnpm
pnpm init
pnpm add webpack webpack-cli -D
```

### 全域安裝（不推薦）

雖然可以實現，但不建議進行全域安裝，因為它可能導致專案之間的版本衝突：

```bash
# npm
npm install --global webpack webpack-cli

# yarn
yarn global add webpack webpack-cli
```

### 基本專案設定

建立以下目錄結構：

```
project/
├── package.json
├── dist/
│   └── index.html
└── src/
    └── index.js
```

安裝一個要捆綁的依賴：

```bash
# npm
npm install --save lodash

# yarn
yarn add lodash

# pnpm
pnpm add lodash
```

### 執行 Webpack

本地安裝後，您可以使用以下命令執行 webpack：

```bash
# npm
npx webpack

# yarn
yarn webpack

# pnpm
pnpm exec webpack
```

## Webpack v4 安裝

### 本地安裝

```bash
# npm
npm init -y
npm install webpack@4.x webpack-cli@3.x --save-dev

# yarn
yarn init -y
yarn add webpack@4.x webpack-cli@3.x --dev
```

### 執行 Webpack v4

```bash
npx webpack
```

注意：Webpack v4 將顯示有關未設定 'mode' 選項的警告。您可以通过新增 `--mode=production` 或 `--mode=development` 標誌來解決此問題。

## NPM 腳本設定

在 `package.json` 中新增建置指令，以便更方便使用：

```json
{
  "scripts": {
    "build": "webpack"
  }
}
```

然後執行：

```bash
# npm
npm run build

# yarn
yarn build

# pnpm
pnpm run build
```

## 版本選擇建議

- **新專案**：使用 Webpack v5 以利用現代特性、更好的效能和持久化快取
- **現有專案**：如果已在使用 Webpack v4，請考慮遷移至 v5 以獲得效能改進
- **企業環境**：Webpack v4 提供穩定的長期支援，而 v5 提供尖端特性

## 從 v4 到 v5 的遷移

Webpack 提供了平滑的遷移路徑：

1. 更新依賴：`npm install webpack@latest webpack-cli@latest`
2. 查閱官方遷移指南中的破壞性變更
3. 如果使用 ES 模組，更新配置語法
4. 進行全面測試以確保相容性

官方遷移指南提供了處理特定破壞性變更和已棄用特性的詳細說明。
