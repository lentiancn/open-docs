# Oracle Database

Oracle Database — это корпоративная реляционная система управления базами данных, разработанная корпорацией Oracle.

## Версии документации

- **Oracle Database 26ai** — новейшая версия (выпущена в 2026 году)
- **Oracle Database 19c** — версия с долгосрочной поддержкой

## Структура документации

1. **Введение** — обзор Oracle Database и основные функции
2. **Руководство по установке** — подробные шаги установки и системные требования
3. **Руководство пользователя** — полные операции программирования SQL, PL/SQL и администрирования
4. **Часто задаваемые вопросы** — часто задаваемые вопросы и устранение неполадок
