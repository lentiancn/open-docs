# Guide d'installation de Yarn

## Installation de Yarn 4+ (Version moderne)

### Méthode d'installation recommandée (Utilisation de Corepack)

Corepack est un outil intermédiaire qui vous permet de configurer la version de votre gestionnaire de paquets par projet :

```bash
# Installer Corepack globalement
npm install -g corepack

# Initialiser un nouveau projet (utilisation de Yarn Berry)
yarn init -2
```

### Mise à jour de Yarn

Pour mettre à jour vers la dernière version à tout moment, exécutez simplement :

```bash
yarn set version stable
yarn install
```

Yarn configurera alors votre projet pour utiliser le binaire stable le plus récent.

### Utilisation des versions Canary

Yarn publie fréquemment des builds Release Candidate. Si vous avez besoin d'une fonctionnalité qui n'a pas encore été publiée sur le canal stable :

```bash
yarn set version canary
```

Ces builds sont très stables, la seule différence avec le canal régulier étant une migration plus échelonnée entre les versions majeures à mesure que nous implémentons de nouveaux changements cassants.

### Installation de la dernière version depuis master

Si vous souhaitez tester une version de Yarn si récente qu'elle n'a pas encore été publiée dans un Release Candidate, ou même non fusionnée :

```bash
# Cloner, construire et installer depuis la branche master
yarn set version from sources

# Tester une PR spécifique
yarn set version from sources --branch 1211
```

**Note**: La commande `yarn set version from sources` ne peut pas tirer parti de Corepack et devra stocker le binaire Yarn dans le dossier `.yarn/releases` et y faire référence depuis le fichier `.yarnrc.yml` de votre projet.

## Installation de Yarn Classic (v1)

### Installation via npm (Recommandé)

Il est recommandé d'installer Yarn via le gestionnaire de paquets npm, qui est inclus avec Node.js :

```bash
# Installer ou mettre à jour Yarn Classic
npm install --global yarn
```

### Vérification de l'installation

Après l'installation, vérifiez que Yarn est correctement installé en exécutant :

```bash
yarn --version
```

## Recommandations de sélection de version

- **Nouveaux projets**: Il est recommandé d'utiliser Yarn 4+ (version moderne) pour profiter des dernières fonctionnalités et améliorations
- **Projets existants**: 
  - Si vous utilisez déjà Yarn Classic, vous pouvez continuer à l'utiliser
  - Envisagez de migrer vers la version moderne pour obtenir de meilleures performances et fonctionnalités
- **Environnements professionnels**: La version moderne offre un meilleur support pour les workspaces et des garanties de stabilité

## Configuration système requise

- **Node.js**: Toutes les versions nécessitent l'environnement Node.js
- **npm**: Yarn Classic nécessite npm pour l'installation globale
- **Corepack**: La version moderne recommande d'utiliser Corepack pour la gestion des versions
