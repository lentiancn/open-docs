# SQLite 常见问题 (FAQ)

## 基础问题

### 1. SQLite 是什么？

SQLite 是一个 C 语言库，实现了一个小型、快速、自包含、高可靠、全功能的 SQL 数据库引擎。它将整个数据库（包括定义、表、索引和数据）存储在单个跨平台的磁盘文件中。

### 2. SQLite 适合什么场景？

SQLite 适合以下场景：

- 移动应用程序（Android、iOS）
- 桌面应用程序
- 网站后端（低到中等流量）
- 数据分析和报表
- 本地缓存
- 嵌入式系统
- 教育和研究

### 3. SQLite 不适合什么场景？

SQLite 不适合以下场景：

- 高并发写入场景（并发写入限制）
- 非本地文件系统上的数据库（网络文件系统限制）
- 需要多用户同时写入的应用程序
- 非常大的数据集（TB 级别）

## 安装和配置

### 1. 如何安装 SQLite？

**Windows：**
```bash
# 使用 Chocolatey
choco install sqlite

# 或下载预编译二进制文件
# 访问 https://www.sqlite.org/download.html
```

**macOS：**
```bash
# 使用 Homebrew
brew install sqlite

# 或使用系统自带版本
sqlite3 --version
```

**Linux：**
```bash
# Debian/Ubuntu
sudo apt install sqlite3 sqlite3-dev

# CentOS/RHEL
sudo yum install sqlite sqlite-devel
```

### 2. SQLite 需要单独的服务器进程吗？

不需要。SQLite 是嵌入式数据库，直接集成在应用程序中，不需要单独的服务器进程。

### 3. 如何检查 SQLite 版本？

```bash
sqlite3 --version
```

## SQL 语法和使用

### 1. SQLite 支持哪些数据类型？

SQLite 支持以下数据类型：

- `NULL`：空值
- `INTEGER`：有符号整数
- `REAL`：浮点数
- `TEXT`：文本字符串
- `BLOB`：二进制数据

SQLite 也支持其他类型指定，但会映射到上述类型。

### 2. 如何创建表？

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    age INTEGER,
    email TEXT UNIQUE
);
```

### 3. 如何插入数据？

```sql
INSERT INTO users (name, age, email) 
VALUES ('张三', 30, 'zhangsan@example.com');
```

### 4. 如何查询数据？

```sql
SELECT * FROM users WHERE age > 25 ORDER BY name;
```

### 5. 如何更新数据？

```sql
UPDATE users SET age = 31 WHERE name = '张三';
```

### 6. 如何删除数据？

```sql
DELETE FROM users WHERE age < 18;
```

### 7. SQLite 支持外键吗？

是的，从 SQLite 3.6.19 开始支持外键。需要显式启用：

```sql
PRAGMA foreign_keys = ON;
```

### 8. 如何处理日期和时间？

SQLite 提供了日期和时间函数：

```sql
SELECT date('now');           -- 当前日期
SELECT time('now');           -- 当前时间
SELECT datetime('now');       -- 当前日期时间
SELECT date('now', '+1 day'); -- 明天
```

### 9. 如何创建索引？

```sql
CREATE INDEX idx_users_name ON users(name);
```

### 10. 如何创建视图？

```sql
CREATE VIEW young_users AS
SELECT * FROM users WHERE age < 30;
```

## 事务和并发

### 1. SQLite 支持事务吗？

是的，SQLite 完全支持 ACID 事务：

```sql
BEGIN TRANSACTION;
-- 执行操作
INSERT INTO users (name) VALUES ('李四');
UPDATE users SET age = 31 WHERE name = '张三';
COMMIT;
```

### 2. SQLite 的并发控制如何？

SQLite 使用锁机制来控制并发：

- 读操作可以并发执行
- 写操作需要独占锁
- 多个写入者不能同时进行

**(WAL 模式)** 可以允许多个读者和一个写入者同时访问：

```sql
PRAGMA journal_mode = WAL;
```

### 3. 为什么我的写入被阻塞？

可能是其他事务持有写锁。可以：

1. 检查长时间运行的事务
2. 使用 WAL 模式
3. 减少事务范围

### 4. 如何处理死锁？

SQLite 不会死锁，但写入者可能被长时间阻塞。

## 性能优化

### 1. 如何提高 SQLite 性能？

- 使用适当的索引
- 使用事务批量操作
- 减小 page_size（默认 4096）
- 使用 WAL 模式
- 避免频繁的 VACUUM

### 2. 如何分析查询性能？

```sql
EXPLAIN QUERY PLAN SELECT * FROM users WHERE name = '张三';
```

### 3. 什么是 VACUUM？

VACUUM 重新组织数据库文件，回收未使用的空间：

```sql
VACUUM;
```

### 4. 如何查看表统计信息？

```sql
ANALYZE;
SELECT * FROM sqlite_stat1;
```

## 数据库维护

### 1. 如何备份 SQLite 数据库？

**简单复制文件：**
```bash
cp mydb.db backup.db
```

**使用 .dump 命令：**
```sql
.dump > backup.sql
```

**命令行备份：**
```bash
sqlite3 mydb.db ".dump" | gzip > backup.sql.gz
```

### 2. 如何恢复数据库？

```sql
.read backup.sql
```

### 3. 如何更改表结构？

SQLite 的 ALTER TABLE 功能有限：

```sql
-- 添加列
ALTER TABLE users ADD COLUMN phone TEXT;

-- 其他修改需要：
-- 1. 创建新表
-- 2. 迁移数据
-- 3. 删除旧表
-- 4. 重命名新表
```

### 4. 如何检查数据库完整性？

```sql
PRAGMA integrity_check;
```

```java
        db.execSQL("CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)");
    }
```


## 编程接口

### 1. Python 如何使用 SQLite？

```python
import sqlite3

# 连接数据库
conn = sqlite3.connect('mydb.db')
cursor = conn.cursor()

# 执行查询
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall()

# 关闭连接
conn.close()
```

### 2. Node.js 如何使用 SQLite？

```javascript
// 使用 sqlite3 包
const sqlite3 = require('sqlite3').verbose();

const db = new sqlite3.Database('mydb.db');

db.serialize(() => {
  db.run("CREATE TABLE IF NOT EXISTS users (id INTEGER, name TEXT)");
  db.run("INSERT INTO users VALUES (?, ?)", [1, "张三"]);
});

db.close();
```

### 3. Java 如何使用 SQLite？

```java
import java.sql.*;

public class SQLiteExample {
    public static void main(String[] args) {
        try (Connection conn = DriverManager.getConnection("jdbc:sqlite:mydb.db")) {
            Statement stmt = conn.createStatement();
            stmt.execute("CREATE TABLE users (id INTEGER, name TEXT)");
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

### 4. C/C++ 如何使用 SQLite？

```c
#include <sqlite3.h>
#include <stdio.h>

int main() {
    sqlite3 *db;
    int rc = sqlite3_open("mydb.db", &db);
    
    if (rc) {
        printf("无法打开数据库: %s\n", sqlite3_errmsg(db));
        return 1;
    }
    
    sqlite3_close(db);
    return 0;
}
```

## 高级主题

### 1. 什么是 WAL 模式？

Write-Ahead Logging (WAL) 模式允许多个读者和一个写入者同时访问数据库：

```sql
PRAGMA journal_mode = WAL;
```

### 2. 如何使用虚拟表？

虚拟表由扩展模块提供：

```sql
-- 全文搜索
CREATE VIRTUAL TABLE articles USING fts5(content);

-- 读取文件内容
CREATE VIRTUAL TABLE files USING fsdir('.');

-- 读取 CSV 文件
CREATE VIRTUAL TABLE csv_data USING csv(filename='data.csv');
```

### 3. 如何使用 FTS5 全文搜索？

```sql
-- 创建 FTS5 表
CREATE VIRTUAL TABLE articles USING fts5(title, content);

-- 插入数据
INSERT INTO articles (title, content) VALUES ('文章1', '这是内容');

-- 搜索
SELECT * FROM articles WHERE articles MATCH '内容';
```

### 4. 如何使用 RTREE 扩展？

```sql
-- 创建 RTREE 表（多维范围树）
CREATE VIRTUAL TABLE session USING rtree(
    id,              -- 主键
    minX, maxX,      -- X 坐标范围
    minY, maxY       -- Y 坐标范围
);

-- 插入数据
INSERT INTO session VALUES (1, 10.0, 20.0, 15.0, 25.0);

-- 范围查询
SELECT * FROM session WHERE maxX >= 15 AND minY <= 20;
```

## 安全相关

### 1. SQLite 支持用户认证吗？

SQLite 本身不提供用户认证，认证由文件系统控制。

### 2. 如何加密 SQLite 数据库？

使用 SQLCipher 或 SEE 扩展：

```bash
# 使用 SQLCipher
sqlcipher mydb.db
PRAGMA key = 'your-password';
```

### 3. SQLite 有什么安全注意事项？

- 数据库文件权限
- SQL 注入防护（使用参数化查询）
- 检查文件路径
- 限制数据库访问
