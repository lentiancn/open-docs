# Руководство по установке Oracle Database

## Установка Oracle Database 19c

### Системные требования

#### Поддерживаемые операционные системы
- Windows x64
- Linux x86-64  
- Linux ARM
- Solaris
- AIX
- HP-UX
- Linux on System z

#### Требования к оборудованию
- **Память**: Минимум 2 ГБ ОЗУ (рекомендуется 4 ГБ или больше)
- **Дисковое пространство**: Минимум 6,5 ГБ свободного места (Enterprise Edition)
- **Процессор**: Архитектура процессора, поддерживаемая операционной системой

### Шаги установки

#### 1. Загрузка программного обеспечения
Получите пакеты установки Oracle Database 19c из Oracle Software Delivery Cloud:
- https://www.oracle.com/database/technologies/oracle-database-software-downloads.html

#### 2. Подготовка системной среды
```bash
# Пример для систем Linux
# Создание пользователя и групп oracle
groupadd oinstall
groupadd dba
useradd -g oinstall -G dba oracle

# Установка параметров ядра
echo "fs.file-max = 6815744" >> /etc/sysctl.conf
echo "kernel.sem = 250 32000 100 128" >> /etc/sysctl.conf
echo "net.ipv4.ip_local_port_range = 9000 65500" >> /etc/sysctl.conf
sysctl -p

# Установка ограничений пользователя
echo "oracle soft nproc 2047" >> /etc/security/limits.conf
echo "oracle hard nproc 16384" >> /etc/security/limits.conf
echo "oracle soft nofile 1024" >> /etc/security/limits.conf
echo "oracle hard nofile 65536" >> /etc/security/limits.conf
```

#### 3. Запуск установщика
```bash
# Распаковка установочного пакета и запуск установщика
unzip LINUX.X64_193000_db_home.zip
cd database
./runInstaller
```

#### 4. Графический мастер установки
- Выбор типа установки (класс рабочего стола, класс сервера)
- Настройка идентификации базы данных (глобальное имя базы данных, SID)
- Установка паролей управления
- Выполнение скриптов root
- Завершение установки

### Установка бесплатной версии
Oracle Database Free (19c) предоставляет бесплатную версию, которую можно быстро развернуть через Docker:
```bash
docker pull container-registry.oracle.com/database/free:19.3.0.0
docker run -d -p 1521:1521 --name oracle-free container-registry.oracle.com/database/free:19.3.0.0
```

## Установка Oracle Database 26ai

Oracle Database 26ai — это новейшая версия. Руководство по установке следует смотреть в официальной документации Oracle:
- https://docs.oracle.com/en/database/oracle/oracle-database/26/install.html

### Контейнеризированное развертывание
Oracle Database 26ai поддерживает современные методы контейнеризированного развертывания:
```bash
# Пример развертывания Docker (конкретное имя образа следует смотреть в официальной документации)
docker pull container-registry.oracle.com/database/26ai:latest
docker run -d -p 1521:1521 --name oracle-26ai container-registry.oracle.com/database/26ai:latest
```

## Устранение неполадок

### Распространенные проблемы
- **Проблемы с правами**: убедитесь, что пользователь oracle имеет правильные права на файлы и каталоги
- **Конфликты портов**: стандартный порт прослушивания 1521, убедитесь, что порт не занят
- **Недостаток памяти**: настройте параметры памяти SGA и PGA
- **Проблемы с кодировкой символов**: правильно выберите кодировку базы данных во время установки

### Расположение журналов
- Журналы установки: `$ORACLE_BASE/cfgtoollogs/dbca/`
- Журналы предупреждений базы данных: `$ORACLE_BASE/diag/rdbms/<DB_NAME>/trace/alert_<SID>.log`
