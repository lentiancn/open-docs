# Häufig gestellte Fragen zu SQLite

## 1. Wie erstelle ich ein AUTOINCREMENT-Feld?

Kurze Antwort: Eine Spalte, die als `INTEGER PRIMARY KEY` deklariert ist, wird automatisch inkrementiert.

Längere Antwort: Wenn Sie eine Spalte einer Tabelle als `INTEGER PRIMARY KEY` deklarieren, wird beim Einfügen eines NULL-Werts in diese Spalte automatisch eine Ganzzahl eingefügt, die um eins größer ist als der größte Wert dieser Spalte in allen anderen Zeilen der Tabelle (oder 1, wenn die Tabelle leer ist).

Beispiel:
```sql
CREATE TABLE t1(
 a INTEGER PRIMARY KEY,
 b INTEGER
);

INSERT INTO t1 VALUES(NULL,123);
-- Äquivalent zu: INSERT INTO t1 VALUES((SELECT max(a) FROM t1)+1,123);
```

Um Schlüssel zu erstellen, die über die gesamte Lebensdauer der Tabelle eindeutig sind, fügen Sie das `AUTOINCREMENT`-Schlüsselwort hinzu:

```sql
CREATE TABLE t1(
 a INTEGER PRIMARY KEY AUTOINCREMENT,
 b INTEGER
);
```

## 2. Welche Datentypen unterstützt SQLite?

SQLite verwendet dynamische Typisierung. Inhalte können als INTEGER, REAL, TEXT, BLOB oder NULL gespeichert werden.

## 3. SQLite lässt mich einen String in eine Integer-Spalte einfügen!

Dies ist eine Funktion, keine Fehler. SQLite verwendet dynamische Typisierung und erzwingt keine Datentyp-Einschränkungen. Daten beliebigen Typs können (normalerweise) in jede Spalte eingefügt werden.

SQLite verwendet jedoch den deklarierten Typ einer Spalte als Hinweis und versucht, Werte entsprechend zu konvertieren. Dieses Feature heißt "Typ-Affinität".

## 4. Warum kann ich '0' und '0.0' nicht als Primärschlüssel in zwei verschiedenen Zeilen verwenden?

Dieses Problem tritt auf, wenn Ihr Primärschlüssel ein numerischer Typ ist. Ändern Sie den Datentyp Ihres Primärschlüssels in TEXT.

SQLite betrachtet '0' und '0.0' als denselben Wert, da sie numerisch gleich sind.

## 5. Können mehrere Anwendungen gleichzeitig auf eine SQLite-Datenbank zugreifen?

Ja, mehrere Prozesse können dieselbe Datenbankdatei gleichzeitig öffnen. Mehrere Prozesse können gleichzeitig SELECT-Abfragen ausführen, aber nur ein Prozess kann zu einem bestimmten Zeitpunkt Änderungen an der Datenbank vornehmen.

SQLite verwendet Leser-/Schreibersperren zur Zugriffskontrolle. Vorsicht ist geboten, wenn die Datenbankdatei auf einem NFS-Dateisystem gespeichert ist, da fcntl()-Dateisperren auf vielen NFS-Implementierungen fehlerhaft sind.

## 6. Ist SQLite threadsicher?

Ja, SQLite ist threadsicher, wenn es mit dem `SQLITE_THREADSAFE`-Präprozessormakro auf 1 kompiliert wurde. Die vorkompilierten Binärdateien für Windows und Linux werden auf diese Weise kompiliert.

Unter Unix sollten Sie eine offene SQLite-Datenbank nicht über einen fork()-Systemaufruf in den Kindprozess übertragen.

## 7. Wie liste ich alle Tabellen/Indizes in einer SQLite-Datenbank auf?

Verwenden Sie in der sqlite3-Befehlszeile:
- `.tables` - Listet alle Tabellen auf
- `.schema` - Zeigt das vollständige Datenbankschema an

Aus einem C/C++-Programm heraus:
```sql
SELECT name FROM sqlite_schema WHERE type='table' ORDER BY name;
```

## 8. Gibt es bekannte Größenbeschränkungen für SQLite-Datenbanken?

Siehe [limits.html](https://www.sqlite.org/limits.html) für eine vollständige Diskussion der SQLite-Grenzen.

## 9. Was ist die maximale Größe eines VARCHAR in SQLite?

SQLite erzwingt die Länge von VARCHAR nicht. Sie können VARCHAR(10) deklarieren und SQLite speichert problemlos einen 500-Millionen-Zeichen-String. Der Inhalt wird niemals abgeschnitten.

## 10. Unterstützt SQLite einen BLOB-Typ?

Ja, SQLite ermöglicht das Speichern von BLOB-Daten in jeder Spalte, sogar in Spalten, die für einen anderen Typ deklariert sind. BLOBs können sogar als PRIMARY KEY verwendet werden.

## 11. Wie füge ich Spalten hinzu, lösche oder benenne sie um?

SQLite bietet eingeschränkte ALTER TABLE-Unterstützung zum Hinzufügen, Umbenennen oder Löschen von Spalten sowie zum Ändern des Tabellennamens.

Für komplexere Änderungen müssen Sie die Tabelle neu erstellen:
1. Bestehende Daten in eine temporäre Tabelle speichern
2. Die alte Tabelle löschen
3. Die neue Tabelle erstellen
4. Die Daten aus der temporären Tabelle zurückkopieren

## 12. Ich habe viele Daten gelöscht, aber die Datenbankdatei ist nicht kleiner geworden. Ist das ein Fehler?

Nein. Gelöschter Speicherplatz wird einer internen "Free-List" hinzugefügt und bei zukünftigen Einfügungen wiederverwendet, aber nicht an das Betriebssystem zurückgegeben.

Führen Sie den `VACUUM`-Befehl aus, um die Datenbankdatei zu verkleinern:
```sql
VACUUM;
```

## 13. Kann ich SQLite in meinem kommerziellen Produkt ohne Lizenzgebühren verwenden?

Ja. SQLite befindet sich in der Public Domain. Kein Eigentumsanspruch wird auf irgendeinen Teil des Codes erhoben. Sie können damit alles tun, was Sie möchten.

## 14. Wie verwende ich ein String-Literal mit einem eingebetteten einfachen Anführungszeichen?

Gemäß SQL-Standard werden einfache Anführungszeichen in Strings durch zwei aufeinanderfolgende einfache Anführungszeichen maskiert:

```sql
INSERT INTO xyz VALUES('5 O''clock');
```

## 15. Was ist ein SQLITE_SCHEMA-Fehler?

Ein `SQLITE_SCHEMA`-Fehler tritt auf, wenn eine vorbereitete SQL-Anweisung nicht mehr gültig ist. Die Anweisung muss neu kompiliert werden.

Die einfachste Lösung ist, immer `sqlite3_prepare_v2()` statt `sqlite3_prepare()` zu verwenden, da dies automatische Neukompilierung bei Schemaänderungen ermöglicht.

## 16. Meine INSERT-Anweisungen sind sehr langsam – ich kann nur wenige Dutzend pro Sekunde ausführen

Standardmäßig ist jede INSERT-Anweisung ihre eigene Transaktion. Um die Leistung zu verbessern, gruppieren Sie mehrere INSERTs in einer einzigen Transaktion:

```sql
BEGIN;
INSERT INTO ...;
INSERT INTO ...;
...
COMMIT;
```

Alternativ können Sie `PRAGMA synchronous=OFF` verwenden, aber dies kann bei Stromausfällen zu Datenbankbeschädigungen führen.

## 17. Ich habe wichtige Informationen aus meiner SQLite-Datenbank gelöscht. Wie kann ich sie wiederherstellen?

Wenn Sie ein Backup haben, stellen Sie die Informationen daraus wieder her.

Ohne Backup ist die Wiederherstellung sehr schwierig. Möglicherweise finden Sie teilweise String-Daten in einem binären Dump der Rohdatenbankdatei. Die Wiederherstellung numerischer Daten könnte ebenfalls möglich sein, aber es gibt keine bekannten Werkzeuge dafür.

## 18. Was ist ein SQLITE_CORRUPT-Fehler?

Ein `SQLITE_CORRUPT`-Fehler wird zurückgegeben, wenn SQLite einen Fehler in der Struktur oder im Format der Datenbankdatei erkennt.

SQLite beschädigt Datenbankdateien nicht ohne externe Hilfe. Wenn Ihre Anwendung mitten in einem Update abstürzt, sind Ihre Daten sicher.

Verwenden Sie `PRAGMA integrity_check`, um die Datenbankintegrität gründlich zu testen.

## 19. Unterstützt SQLite Fremdschlüssel?

Ab Version 3.6.19 (2009-10-14) unterstützt SQLite Fremdschlüssel-Einschränkungen. Die Durchsetzung ist jedoch standardmäßig deaktiviert (aus Gründen der Abwärtskompatibilität).

Aktivieren Sie Fremdschlüssel-Einschränkungen mit:
```sql
PRAGMA foreign_keys=ON;
```

## 20. Wo ist meine Datenbank geblieben? (Oder: Wie wurde meine Datenbank leer?)

SQLite erstellt eine Datenbank automatisch, wenn sie nicht existiert. Neu erstellte Datenbanken sind zunächst leer. Dies kann verwirrend sein, wenn versehentlich verschiedene Datenbankdateien in unterschiedlichen Kontexten geöffnet werden.
