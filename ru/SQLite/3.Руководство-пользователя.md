# Руководство пользователя SQLite

## Начало работы

Программа командной строки SQLite (sqlite3 или sqlite3.exe в Windows) позволяет вручную вводить и выполнять SQL-операторы над базой данных SQLite или ZIP-архивом.

### Запуск CLI

Запустите программу sqlite3, набрав "sqlite3" в командной строке, с необязательным указанием имени файла базы данных SQLite:

```bash
$ sqlite3 ex1
SQLite version 3.36.0 2021-06-18 18:36:39
Enter ".help" for usage hints.
sqlite> create table tbl1(one text, two int);
sqlite> insert into tbl1 values('hello!',10);
sqlite> insert into tbl1 values('goodbye', 20);
sqlite> select * from tbl1;
hello!|10
goodbye|20
sqlite>
```

Если указанный файл не существует, он будет автоматически создан. Если файл базы данных не указан, используется временная база данных в памяти.

Для завершения работы введите символ конца файла (обычно Ctrl+D). Для прерывания долгой SQL-операции используйте символ прерывания (обычно Ctrl+C).

**Важно**: Не забывайте ставить точку с запятой в конце каждого SQL-оператора!

## Специальные команды (dot-commands)

Строки ввода, начинающиеся с точки ("."), интерпретируются самой программой sqlite3. Эти "точечные команды" используются для изменения формата вывода или выполнения специальных операций.

Для получения списка доступных команд введите `.help`:

```
.archive ...           Manage SQL archives
.auth ON|OFF          Show authorizer callbacks
.backup ?DB? FILE     Backup DB (default "main") to FILE
.bail on|off          Stop after hitting an error. Default OFF
.cd DIRECTORY         Change the working directory to DIRECTORY
.changes on|off       Show number of rows changed by SQL
.databases            List names and files of attached databases
.dump ?OBJECTS?       Render database content as SQL
.echo on|off          Turn command echo on or off
.exit ?CODE?          Exit this program with return-code CODE
.headers on|off       Turn display of headers on or off
.help ?-all? ?PATTERN? Show help text for PATTERN
.import FILE TABLE    Import data from FILE into TABLE
.indexes ?TABLE?      Show names of indexes
.mode ?MODE? ?OPTIONS? Set output mode
.nullvalue STRING     Use STRING in place of NULL values
.open ?OPTIONS? ?FILE? Close existing database and reopen FILE
.output ?FILE?        Send output to FILE or stdout if FILE is omitted
.print STRING...      Print literal STRING
.quit                 Stop interpreting input stream, exit if primary.
.read FILE            Read input from FILE or command output
.schema ?PATTERN?     Show the CREATE statements matching PATTERN
.separator COL ?ROW?  Change the column and row separators
.show                 Show the current values for various settings
.tables ?TABLE?       List names of tables matching LIKE pattern TABLE
.timer on|off         Turn SQL timer on or off
```

## Изменение форматов вывода

Программа sqlite3 может показывать результаты запроса в 14 различных форматах вывода:

- **list** (по умолчанию) — каждая строка результата на одной строке, столбцы разделены символом "|"
- **column** — табличный формат с выравниванием по столбцам
- **box** — табличный формат с рамками в виде Unicode-символов
- **table** — табличный формат с ASCII-рамками
- **markdown** — таблица в формате Markdown
- **csv** — значения, разделенные запятыми
- **json** — результат в формате JSON
- **line** — каждый столбец на отдельной строке в формате "имя = значение"

Примеры использования:

```sql
sqlite> .mode list
sqlite> select * from tbl1;
hello!|10
goodbye|20

sqlite> .mode column
sqlite> select * from tbl1;
one         two
--------    ---
hello!      10
goodbye     20

sqlite> .mode box
sqlite> select * from tbl1;
┌─────────┬─────┐
│ one     │ two │
├─────────┼─────┤
│ hello!  │ 10  │
│ goodbye │ 20  │
└─────────┴─────┘
```

Команда `.separator` изменяет разделитель столбцов:
```sql
sqlite> .separator ", "
sqlite> select * from tbl1;
hello!, 10
goodbye, 20
```

## Запрос схемы базы данных

Удобные команды для просмотра схемы базы данных:

- **`.tables`** — список всех таблиц в базе данных
- **`.indexes`** — список всех индексов (с именем таблицы показывает индексы только для этой таблицы)
- **`.schema`** — полная схема базы данных или конкретной таблицы
- **`.databases`** — список всех открытых баз данных
- **`.fullschema`** — полная схема включая статистические таблицы sqlite_stat1, sqlite_stat3, sqlite_stat4

Пример:
```sql
sqlite> .tables
tbl1 tbl2

sqlite> .schema tbl2
CREATE TABLE tbl2 (
 f1 varchar(30) primary key,
 f2 text,
 f3 real
);
```

## Перенаправление ввода/вывода

### Запись результатов в файл

Команда `.output` перенаправляет последующий вывод в файл:
```sql
sqlite> .output test_file.txt
sqlite> select * from tbl1;
sqlite> .output  -- вернуться к стандартному выводу
```

Команда `.once` перенаправляет вывод только для следующей команды:
```sql
sqlite> .once result.csv
sqlite> select * from users;
```

### Чтение SQL из файла

Команда `.read` выполняет SQL-скрипт из файла:
```sql
sqlite> .read myscript.sql
```

### Экспорт в CSV

Для экспорта таблицы в CSV:
```sql
sqlite> .headers on
sqlite> .mode csv
sqlite> .once dataout.csv
sqlite> SELECT * FROM tab1;
```

Команда `.excel` (или `.once -x`) отправляет результат запроса напрямую в электронную таблицу:
```sql
sqlite> .excel
sqlite> SELECT * FROM tab1;
```

## Работа с ZIP-архивами

SQLite может читать и записывать ZIP-архивы как базы данных. Просто укажите имя ZIP-файла вместо файла базы данных:

```bash
$ sqlite3 document.docx
```

ZIP-архив представляется как база данных с одной таблицей:
```sql
CREATE TABLE zip(
 name,      -- Имя файла
 mode,      -- Права доступа в стиле Unix
 mtime,     -- Временная метка (секунды с 1970)
 sz,        -- Размер файла после распаковки
 rawdata,   -- Сырые сжатые данные файла
 data,      -- Распакованное содержимое файла
 method     -- Код метода сжатия ZIP
);
```

Пример запроса:
```sql
sqlite> SELECT name, (100.0*length(rawdata))/sz FROM zip ORDER BY 2;
```

## Преобразование всей базы данных в текстовый файл

Команда `.dump` преобразует всё содержимое базы данных в один текстовый файл UTF-8:

```bash
$ sqlite3 ex1 .dump | gzip -c >ex1.dump.gz
```

Для восстановления базы данных:
```bash
$ zcat ex1.dump.gz | sqlite3 ex2
```

## Загрузка расширений

Новые пользовательские функции SQL, последовательности сравнения, виртуальные таблицы и VFS можно добавить во время выполнения с помощью команды `.load`:

```sql
sqlite> .load /path/to/my_extension
```

SQLite автоматически добавляет соответствующее расширение файла (".dll" в Windows, ".dylib" на Mac, ".so" в Unix).

## Криптографические хэши содержимого базы данных

Команда `.sha3sum` вычисляет хэш SHA3 содержимого базы данных:

```sql
sqlite> .sha3sum --sha3-256
```

Хэш вычисляется по содержимому базы данных, а не по её представлению на диске, поэтому операции вроде VACUUM не изменяют хэш.
