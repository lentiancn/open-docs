# SQLite Introduction

## Overview

SQLite is a C-language library that implements a small, fast, self-contained, high-reliability, full-featured SQL database engine. SQLite is the most used database engine in the world.

SQLite is built into all mobile phones and most computers and comes bundled inside countless other applications that people use every day.

SQLite stores the entire database (definitions, tables, indexes, and data) in a single cross-platform disk file. SQLite is perfect for use inside other programs.

## Main Features

- **Small** - SQLite is very compact, with minimal memory usage
- **Fast** - SQLite is one of the fastest database engines
- **Reliable** - SQLite is thoroughly tested and highly reliable
- **Self-contained** - No separate server process required
- **Zero configuration** - Zero-config, out of the box
- **Transactional** - Supports ACID transactions
- **Zero dependencies** - No additional libraries or dependencies required

## Technical Specifications

- Full SQL language support including multi-table queries, joins, views, and triggers
- Supports transactions (BEGIN, COMMIT, ROLLBACK)
- ACID compliant
- Supports foreign key constraints
- Supports multiple data types
- Supports virtual tables and extended APIs

## Use Cases

SQLite is suitable for the following scenarios:

- Mobile applications (Android, iOS)
- Desktop applications
- Web backends (low to medium traffic)
- Data analysis and reporting
- Local caching
- Embedded systems
- Education and research

##不适合的场景

SQLite is not suitable for:

- High-concurrency write scenarios (concurrent write limitations)
- Databases on non-local file systems (network file system limitations)
- Applications requiring multiple users to write simultaneously
- Very large datasets (TB-level)
