# SearXNG インストールガイド

このガイドでは、独自のSearXNGインスタンスをセットアップするための複数のインストール方法を紹介します。

## インストール方法

### 1. コンテナインストール（推奨）

最も簡単で信頼性の高い方法は、DockerまたはPodmanコンテナを使用することです。

**前提条件：**
- DockerまたはPodmanがインストール済み
- 基本的なコンテナ管理知識

**手順：**
```bash
# 公式SearXNGイメージをプル
docker pull searxng/searxng

# 基本設定で実行
docker run -d --name searxng -p 8080:8080 searxng/searxng
```

### 2. インストールスクリプト

uWSGI設定を含むほとんどの設定を自動的に処理する自動化インストールスクリプトが利用できます。

**手順：**
```bash
# インストールスクリプトをダウンロード
curl -O https://raw.githubusercontent.com/searxng/searxng/master/utils/searxng.sh

# 実行権限を付与して実行
chmod +x searxng.sh
sudo ./searxng.sh
```

### 3. ステップバイステップ手動インストール

インストールプロセスを完全に制御したい上級ユーザー向けです。

**前提条件：**
- Python 3.8以上
- uWSGI
- Git
- ビルドツール（gcc、makeなど）
- Webサーバー（NGINXまたはApache）

**インストール手順：**

1. **必要なパッケージをインストール：**
   ```bash
   # Ubuntu/Debian
   sudo apt install python3 python3-pip python3-venv python3-dev build-essential git uwsgi uwsgi-plugin-python3
   
   # CentOS/RHEL
   sudo yum install python3 python3-pip python3-devel gcc git uwsgi uwsgi-plugin-python3
   ```

2. **専用ユーザーを作成：**
   ```bash
   sudo useradd -r -s /bin/false searxng
   ```

3. **リポジトリをクローン：**
   ```bash
   sudo -u searxng git clone https://github.com/searxng/searxng.git /opt/searxng
   cd /opt/searxng
   ```

4. **設定を構成：**
   ```bash
   # デフォルト設定をコピー
   sudo cp /opt/searxng/searxng/settings.yml /etc/searxng/settings.yml
   
   # 必要に応じて設定を編集
   sudo nano /etc/searxng/settings.yml
   ```

5. **Webサーバーをセットアップ：**
   
   **NGINX設定例：**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           include uwsgi_params;
           uwsgi_pass unix:/run/uwsgi/app/searxng/socket;
       }
   }
   ```

## インストール後

インストール完了後、`http://your-server:port`でSearXNGインスタンスにアクセスし、正常に動作していることを確認してください。`settings.yml`設定ファイルを通じて、外観、エンジン、動作をカスタマイズできます。

## トラブルシューティング

- **権限の問題**：searxngユーザーがすべてのファイルに対して適切な権限を持っていることを確認
- **ポートの競合**：選択したポートがすでに使用されていないか確認
- **エンジンの設定**：一部の検索エンジンにはAPIキーまたは特定の設定が必要な場合があります
- **SSL設定**：本番環境では、Let's Encryptまたはお好みのCAを使用してSSL証明書を設定
