# SearXNG 사용 매뉴얼

이 매뉴얼은 검색 및 맞춤 설정을 위해 SearXNG를 효과적으로 사용하는 방법을 다룹니다.

## 검색 구문

SearXNG는 쿼리를 세부적으로 조정하기 위한 강력한 검색 구문을 지원합니다:

### 엔진 선택
- **`!` 접두사**: 특정 엔진 또는 카테고리 선택
  - `!wp paris` - 위키백과에서 "paris" 검색
  - `!images Wau Holland` - "Wau Holland" 이미지 검색
  - `!news climate change` - 뉴스 엔진에서 "climate change" 검색

### 언어 선택
- **`:` 접두사**: 검색 언어 선택
  - `:fr !wp Wau Holland` - 프랑스어 위키백과에서 "Wau Holland" 검색
  - `:de climate change` - 독일어로 "climate change" 검색

### 외부 밴
- **`!!` 접두사**: 외부 서비스로 직접 리디렉션
  - `!!youtube cats` - YouTube 검색으로 직접 리디렉션하여 "cats" 검색

### 특수 쿼리
SearXNG는 다양한 특수 쿼리 기능을 지원합니다:
- `random uuid` - 임의의 UUID 생성
- `avg 123 548` - 숫자의 평균 계산
- `user-agent` - 현재 사용자 에이전트 표시
- 해시 함수: `md5 text`, `sha1 text`, `sha256 text`
- 단위 변환: `100 USD in EUR`, `10 km in miles`

## 구성된 검색 엔진

SearXNG는 **250개의 검색 엔진**이 구성되어 있으며, 기본적으로 **96개가 활성화**되어 있습니다. 엔진은 카테고리별로 구성됩니다:

### 카테고리
- **일반**: 표준 웹 검색 엔진
- **이미지**: 이미지 검색 서비스
- **동영상**: 동영상 검색 플랫폼
- **뉴스**: 뉴스 집계 서비스
- **지도**: 지도 및 위치 서비스
- **음악**: 음악 검색 및 스트리밍
- **IT**: 기술 및 프로그래밍 리소스
- **과학**: 학술 및 과학 데이터베이스
- **파일**: 파일 공유 및 문서 검색
- **소셜 미디어**: 소셜 플랫폼 검색

### 하위 그룹
각 카테고리는 보다 구체적인 검색을 위한 하위 그룹을 포함합니다:
- 책, 통화, 번역, 웹, 위키미디어 등

## 인터페이스 맞춤 설정

### 환경설정
설정 아이콘을 통해 환경설정에 액세스하여 맞춤 설정:
- **기본 검색 언어**
- **활성화된 검색 엔진**
- **결과 표시 옵션**
- **개인정보 보호 설정**
- **테마 및 외관**

### 플러그인
SearXNG에는 유용한 플러그인이 포함되어 있습니다:
- **계산기**: 수학적 계산 수행
- **해시**: 다양한 해시 값 생성
- **자기 정보**: 클라이언트 정보 표시
- **시간대**: 시간대 간 변환
- **Tor 확인**: Tor 연결성 확인
- **단위 변환기**: 측정 단위 간 변환

## 개인정보 보호 기능

### 익명 검색
- 모든 검색은 기본적으로 익명
- 쿠키나 추적 스크립트 없음
- IP 주소는 기록되지 않음 (제대로 구성된 인스턴스의 경우)

### 결과 정화
- URL에서 추적 매개변수 제거
- 리퍼러 정보 제거
- 제3자 스크립트 차단

## 고급 사용법

### API 액세스
SearXNG는 프로그래밍 방식 액세스를 위한 간단한 API를 제공합니다:
```
GET /search?q=your_query&format=json
```

### 사용자 정의 엔진
`settings.yml` 파일을 수정하여 사용자 정의 검색 엔진을 추가할 수 있습니다:
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### 키보드 단축키
- **`/`**: 검색 입력에 포커스
- **`Esc`**: 검색 지우기 또는 대화 상자 닫기
- **`Enter`**: 검색 제출
- **`Ctrl+Enter`**: 새 탭에서 결과 열기

이 포괄적인 매뉴얼은 완전한 개인정보 보호와 검색 활동에 대한 제어를 유지하면서 SearXNG 경험을 최대한 활용하는 데 도움이 될 것입니다.
