# SearXNG ユーザーマニュアル

このマニュアルでは、SearXNGを効果的に使用して検索およびカスタマイズする方法を説明します。

## 検索構文

SearXNGは、クエリを最適化するための強力な検索構文をサポートしています：

### エンジン選択
- **`!` 接頭辞**：特定のエンジンまたはカテゴリを選択
  - `!wp paris` - Wikipediaで「paris」を検索
  - `!images Wau Holland` - 「Wau Holland」の画像を検索
  - `!news climate change` - ニュースエンジンで「climate change」を検索

### 言語選択
- **`:` 接頭辞**：検索言語を選択
  - `:fr !wp Wau Holland` - フランス語版Wikipediaで「Wau Holland」を検索
  - `:de climate change` - ドイツ語で「climate change」を検索

### 外部バン
- **`!!` 接頭辞**：外部サービスに直接リダイレクト
  - `!!youtube cats` - YouTube検索に直接リダイレクトして「cats」を検索

### 特殊クエリ
SearXNGはさまざまな特殊クエリ機能をサポートしています：
- `random uuid` - ランダムUUIDを生成
- `avg 123 548` - 数値の平均を計算
- `user-agent` - 現在のユーザーエージェントを表示
- ハッシュ関数：`md5 text`、`sha1 text`、`sha256 text`
- 単位変換：`100 USD in EUR`、`10 km in miles`

## 設定済み検索エンジン

SearXNGには**250の検索エンジン**が設定されており、デフォルトで**96個が有効**になっています。エンジンはカテゴリ別に整理されています：

### カテゴリ
- **一般**：標準的なウェブ検索エンジン
- **画像**：画像検索サービス
- **動画**：動画検索プラットフォーム
- **ニュース**：ニュース集約サービス
- **地図**：マッピングおよび位置情報サービス
- **音楽**：音楽検索およびストリーミング
- **IT**：技術およびプログラミングリソース
- **科学**：学術および科学データベース
- **ファイル**：ファイル共有およびドキュメント検索
- **ソーシャルメディア**：ソーシャルプラットフォーム検索

### サブグループ
各カテゴリには、より具体的な検索のためのサブグループが含まれています：
- 書籍、通貨、翻訳、ウェブ、ウィキメディアなど

## インターフェースのカスタマイズ

### 設定
設定アイコンから設定にアクセスしてカスタマイズできます：
- **デフォルト検索言語**
- **有効な検索エンジン**
- **結果表示オプション**
- **プライバシー設定**
- **テーマと外観**

### プラグイン
SearXNGには便利なプラグインが含まれています：
- **電卓**：数学的計算を実行
- **ハッシュ**：さまざまなハッシュ値を生成
- **自己情報**：クライアント情報を表示
- **タイムゾーン**：タイムゾーン間で変換
- **Torチェック**：Tor接続を検証
- **単位変換器**：測定単位間で変換

## プライバシー機能

### 匿名検索
- すべての検索はデフォルトで匿名
- Cookieやトラッキングスクリプトなし
- IPアドレスは記録されません（適切に設定されたインスタンスの場合）

### 結果のサニタイズ
- URLからトラッキングパラメータをクリーンアップ
- リファラ情報を削除
- サードパーティースクリプトをブロック

## 高度な使用法

### APIアクセス
SearXNGはプログラムによるアクセスのためのシンプルなAPIを提供します：
```
GET /search?q=your_query&format=json
```

### カスタムエンジン
`settings.yml`ファイルを編集することで、カスタム検索エンジンを追加できます：
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### キーボードショートカット
- **`/`**：検索入力にフォーカス
- **`Esc`**：検索をクリアまたはダイアログを閉じる
- **`Enter`**：検索を送信
- **`Ctrl+Enter`**：結果を新しいタブで開く

この包括的なマニュアルにより、完全なプライバシーと検索活動の制御を維持しながら、SearXNGの体験を最大限に活用できるはずです。
