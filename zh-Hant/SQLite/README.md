## 關於 SQLite

SQLite 是一個實現了小型、快速、自包含、高可靠性、全功能 SQL 數據庫引擎的 C 語言庫。它是世界上最廣泛部署的數據庫引擎，內置於幾乎所有手機和大多數計算機中。

SQLite 的主要優勢包括：
- 零配置：無需安裝或管理
- 自包含：整個數據庫存儲在單個跨平台磁盤文件中
- 緊湊：完整版本小於 725KiB
- 高效：比流行的客戶端/服務器數據庫引擎快得多
- 可靠：即使在系統崩潰後也能保持事務完整性
- 易於使用：簡單的 API 和 SQL 語法
- 開源：代碼在公有領域，任何人都可以自由使用
