# Webpack 使用手冊

## 核心概念

### 入口點

入口點指示 Webpack 應該使用哪個模組來開始構建其內部依賴關係圖。預設值為 `./src/index.js`，但您可以指定不同的（或多個）入口點。

**單入口：**
```javascript
// webpack.config.js
export default {
  entry: './path/to/my/entry/file.js',
};
```

**多入口：**
```javascript
export default {
  entry: {
    app: './src/app.js',
    admin: './src/admin.js'
  }
};
```

### 輸出設定

output 屬性告訴 Webpack 將打包檔案輸出到何處以及如何命名。預設輸出檔案為 `./dist/main.js`。

```javascript
import path from "node:path";

export default {
  entry: './path/to/my/entry/file.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'my-first-webpack.bundle.js',
  },
};
```

### 載入器（Loaders）

載入器允許 Webpack 處理非 JavaScript 檔案，並將其轉換為有效模組。

**基本載入器設定：**
```javascript
export default {
  module: {
    rules: [
      { test: /\.txt$/, use: 'raw-loader' },
      { test: /\.css$/, use: ['style-loader', 'css-loader'] },
      { test: /\.(png|svg|jpg|jpeg|gif)$/i, type: 'asset/resource' }
    ],
  },
};
```

### 外掛（Plugins）

外掛執行更廣泛的任務，如打包檔案最佳化、資源管理和環境變數注入。

**常用外掛：**
```javascript
import HtmlWebpackPlugin from "html-webpack-plugin";
import MiniCssExtractPlugin from "mini-css-extract-plugin";
import webpack from "webpack";

export default {
  plugins: [
    new HtmlWebpackPlugin({ template: './src/index.html' }),
    new MiniCssExtractPlugin(),
    new webpack.DefinePlugin({
      'process.env.NODE_ENV': JSON.stringify('production')
    })
  ],
};
```

### 模式（Mode）

mode 參數啟用內建最佳化：

- **development**: 啟用有用的錯誤訊息和快速重建
- **production**: 啟用壓縮、作用域提升和其他最佳化
- **none**: 停用所有預設最佳化

```javascript
export default {
  mode: 'production',
};
```

## 進階功能

### 程式碼分割

Webpack 提供了多種程式碼分割方式：

**入口點：**
透過建立多個入口點手動分割程式碼。

**防止重複：**
使用 `SplitChunksPlugin` 移除重複相依。

**動態匯入：**
使用動態匯入按需分割程式碼：
```javascript
// 之前
import _ from 'lodash';

// 之後
const _ = await import('lodash');
```

### 快取

Webpack 提供了多種快取策略：

- **輸出檔名**: 使用 `[contenthash]` 建立唯一檔名
- **SplitChunks**: 分離供應商程式碼和應用程式程式碼
- **執行階段區塊**: 將 Webpack 執行階段提取到單獨的區塊中

### 開發工具

**Source Maps：**
啟用 source maps 以便於偵錯：
```javascript
export default {
  devtool: 'inline-source-map',
};
```

**開發伺服器：**
使用 webpack-dev-server 實現即時重載：
```bash
npm install --save-dev webpack-dev-server
```

```javascript
// package.json
{
  "scripts": {
    "start": "webpack serve --open"
  }
}
```

## 設定檔

### 基本設定

```javascript
// webpack.config.js
import path from "node:path";

export default {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader']
      }
    ]
  },
  plugins: [],
  mode: 'development'
};
```

### 環境特定設定

為不同環境建立單獨的設定：

- `webpack.common.js`: 共用設定
- `webpack.dev.js`: 開發環境特定設定
- `webpack.prod.js`: 生產環境特定設定

使用 webpack-merge 合併設定：
```javascript
import { merge } from 'webpack-merge';
import common from './webpack.common.js';

export default merge(common, {
  mode: 'development',
  devtool: 'inline-source-map',
});
```

## 版本差異

### Webpack v5 與 Webpack v4

| 功能 | Webpack v5 | Webpack v4 |
|------|------------|------------|
| **模組系統** | ES Module + CommonJS | 僅 CommonJS |
| **快取** | 持久化快取 | 記憶體快取 |
| **資源處理** | 內建資源模組 | 需要 file-loader/url-loader |
| **效能** | 使用持久化快取，建置更快 | 標準效能 |
| **模組聯合** | 內建支援 | 不可用 |
| **Node.js 支援** | Node.js 10.13.0+ | Node.js 6.11.5+ |

### 遷移注意事項

- 更新載入器設定，使用資源模組而不是 file-loader/url-loader
- 檢查外掛與 Webpack v5 的相容性
- 如果遷移到 ES Module，更新設定語法
- 彻底測試，因為某些外掛可能存在破壞性變更
