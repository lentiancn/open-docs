# SearXNG Manuel d'utilisation

Ce manuel couvre comment utiliser efficacement SearXNG pour la recherche et la personnalisation.

## Syntaxe de Recherche

SearXNG prend en charge une syntaxe de recherche puissante pour affiner vos requêtes :

### Sélection du Moteur
- **Préfixe `!`** : Sélectionner un moteur ou une catégorie spécifique
  - `!wp paris` - Rechercher "paris" sur Wikipedia
  - `!images Wau Holland` - Rechercher des images de "Wau Holland"
  - `!news climate change` - Rechercher dans les moteurs d'actualités "climate change"

### Sélection de Langue
- **Préfixe `:`** : Sélectionner la langue de recherche
  - `:fr !wp Wau Holland` - Rechercher "Wau Holland" sur Wikipedia français
  - `:de climate change` - Rechercher en allemand "climate change"

### Bangs Externes
- **Préfixe `!!`** : Redirections directes vers des services externes
  - `!!youtube cats` - Rediriger directement vers la recherche YouTube "cats"

### Requêtes Spéciales
SearXNG prend en charge diverses fonctions de requête spéciales :
- `random uuid` - Générer un UUID aléatoire
- `avg 123 548` - Calculer la moyenne des nombres
- `user-agent` - Afficher votre agent utilisateur actuel
- Fonctions de hachage : `md5 text`, `sha1 text`, `sha256 text`
- Conversions d'unités : `100 USD in EUR`, `10 km in miles`

## Moteurs de Recherche Configurés

SearXNG est livré avec **250 moteurs de recherche** configurés, avec **96 activés par défaut**. Les moteurs sont organisés en catégories :

### Catégories
- **Général** : Moteurs de recherche web standard
- **Images** : Services de recherche d'images
- **Vidéos** : Plateformes de recherche vidéo
- **Actualités** : Services d'agrégation d'actualités
- **Cartes** : Services de cartographie et de localisation
- **Musique** : Recherche et streaming musical
- **IT** : Ressources techniques et de programmation
- **Science** : Bases de données académiques et scientifiques
- **Fichiers** : Partage de fichiers et recherche de documents
- **Réseaux Sociaux** : Recherche sur les plateformes sociales

### Sous-groupes
Chaque catégorie contient des sous-groupes pour des recherches plus spécifiques :
- Livres, Devise, Traduire, Web, Wikimedia, et plus encore

## Personnalisation de l'Interface

### Préférences
Accédez aux préférences via l'icône des paramètres pour personnaliser :
- **Langue de recherche par défaut**
- **Moteurs de recherche activés**
- **Options d'affichage des résultats**
- **Paramètres de confidentialité**
- **Thème et apparence**

### Plugins
SearXNG inclut des plugins utiles :
- **Calculatrice** : Effectuer des calculs mathématiques
- **Hachage** : Générer diverses valeurs de hachage
- **Informations Personnelles** : Afficher les informations du client
- **Fuseaux Horaires** : Convertir entre les fuseaux horaires
- **Vérification Tor** : Vérifier la connectivité Tor
- **Convertisseur d'Unités** : Convertir entre les unités de mesure

## Fonctionnalités de Confidentialité

### Recherche Anonyme
- Toutes les recherches sont anonymes par défaut
- Pas de cookies ni de scripts de suivi
- L'adresse IP n'est pas enregistrée (dans les instances correctement configurées)

### Assainissement des Résultats
- Les URL sont nettoyées des paramètres de suivi
- Les informations de référent sont supprimées
- Les scripts tiers sont bloqués

## Utilisation Avancée

### Accès API
SearXNG fournit une API simple pour l'accès programmatique :
```
GET /search?q=your_query&format=json
```

### Moteurs Personnalisés
Vous pouvez ajouter des moteurs de recherche personnalisés en modifiant le fichier `settings.yml` :
```yaml
engines:
  - name: custom_engine
    engine: json_engine
    shortcut: ce
    paging: true
    search_url: https://api.example.com/search?q={query}&page={pageno}
```

### Raccourcis Clavier
- **`/`** : Mettre le focus sur l'entrée de recherche
- **`Esc`** : Effacer la recherche ou fermer les dialogues
- **`Enter`** : Soumettre la recherche
- **`Ctrl+Enter`** : Ouvrir les résultats dans un nouvel onglet

Ce manuel complet devrait vous aider à tirer le meilleur parti de votre expérience SearXNG tout en maintenant une confidentialité et un contrôle complets sur votre activité de recherche.
