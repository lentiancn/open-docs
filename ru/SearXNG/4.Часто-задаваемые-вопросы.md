# SearXNG Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое SearXNG?
SearXNG — это бесплатная интернет-метапоисковая система, которая агрегирует результаты из до 250 различных поисковых сервисов. Она разработана для защиты конфиденциальности пользователей, не отслеживая и не профилируя их, обеспечивая полную анонимность во время поиска.

### Почему мне следует использовать SearXNG вместо обычных поисковых систем?
- **Защита конфиденциальности**: Без отслеживания, профилирования или сбора данных пользователей
- **Без фильтровых пузырей**: Результаты не персонализируются на основе вашей истории
- **Множественные источники**: Агрегирует результаты из многих поисковых систем
- **Открытый исходный код**: Прозрачный код, который может быть проверен кем угодно
- **Настраиваемость**: Высоко настраиваемый под личные предпочтения
- **Бесплатное использование**: Без стоимости и рекламы

### Как работает SearXNG?
SearXNG действует как метапоисковая система, которая отправляет ваш запрос одновременно в несколько поисковых сервисов, затем агрегирует и представляет результаты в унифицированном интерфейсе. Он удаляет идентификационную информацию из запросов и очищает результаты для защиты вашей конфиденциальности.

## Вопросы по использованию

### Как установить SearXNG как мою поисковую систему по умолчанию?
SearXNG поддерживает OpenSearch, что позволяет легко добавить его в поставщики поиска вашего браузера:
1. Посетите любой инстанс SearXNG
2. Найдите опцию "Добавить в браузер" или настройки
3. Следуйте инструкциям вашего браузера для добавления в качестве поставщика поиска
4. Установите его как по умолчанию в настройках браузера

### Могу ли я использовать SearXNG с Tor?
Да! SearXNG можно использовать через Tor для улучшения онлайн-анонимности. Многие публичные инстансы поддерживают подключения Tor, и вы также можете настроить свой собственный инстанс для работы с Tor.

### Какой синтаксис поиска поддерживает SearXNG?
SearXNG поддерживает мощный синтаксис поиска, включая:
- `!название_движка запрос` - Поиск в конкретном движке
- `:язык запрос` - Поиск на конкретном языке  
- `!!внешний_сервис запрос` - Прямое перенаправление на внешний сервис
- Специальные функции, такие как `random uuid`, `avg numbers`, хэш-функции и т.д.

## Технические вопросы

### В чем разница между публичными и частными инстансами?
- **Публичные инстансы**: Размещаются волонтерами, удобны, но требуют доверия к оператору
- **Частные инстансы**: Самостоятельно размещаются, предоставляя полный контроль над настройками конфиденциальности и конфигурацией

### Сколько поисковых движков поддерживает SearXNG?
SearXNG настроен с **250 поисковыми движками**, из которых **96 включены по умолчанию**. Вы можете включать/отключать движки в зависимости от ваших предпочтений через настройки.

### Хранит ли SearXNG какие-либо данные пользователя?
Правильно настроенные инстансы SearXNG **не хранят никаких данных пользователя**. Они реализуют три уровня удаления данных:
1. Из запросов к поисковым сервисам
2. От сторонних сервисов  
3. Со страниц результатов

### Могу ли я внести вклад в разработку SearXNG?
Да! SearXNG имеет открытый исходный код и приветствует вклад. Вы можете:
- Сообщать об ошибках или предлагать функции на GitHub
- Вносить улучшения в код
- Помогать с документацией
- Переводить интерфейс на другие языки
- Запускать и поддерживать публичные инстансы

## Вопросы по установке

### Какие системные требования для самостоятельного размещения?
- Python 3.8 или выше
- Базовые знания веб-сервера
- Примерно 500 МБ дискового пространства
- Любое современное дистрибутив Linux (Ubuntu, Debian, CentOS и т.д.)

### Рекомендуется ли установка Docker?
Да, установка через контейнер Docker/Podman является **рекомендуемым методом**, так как она обеспечивает самую простую настройку, автоматические обновления и надлежащую изоляцию.

### Как обновить мой инстанс SearXNG?
- **Docker**: Загрузите последний образ и перезапустите контейнер
- **Установка через скрипт**: Запустите скрипт установки снова
- **Ручная установка**: Загрузите последние изменения из git и перезапустите службы

## Конфиденциальность и безопасность

### Насколько безопасен SearXNG?
SearXNG разработан с безопасностью и конфиденциальностью как главными приоритетами:
- Без отслеживания или профилирования пользователей
- Поддержка HTTPS для зашифрованных соединений
- Регулярные аудиты безопасности и обновления
- Открытый исходный код для прозрачности

### Можно ли доверять SearXNG?
Поскольку SearXNG имеет открытый исходный код, вы можете:
- Проверить код самостоятельно
- Запустить свой собственный частный инстанс для полного контроля
- Выбрать репутационные публичные инстансы с searx.space
- Проверить целостность установок

Для максимальной конфиденциальности и доверия запуск собственного инстанса всегда является лучшим вариантом.
