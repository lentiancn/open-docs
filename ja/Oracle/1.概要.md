# Oracle Database 概要

Oracle Database は、オラクル社（Oracle Corporation）が開発したリレーショナルデータベース管理システム（RDBMS）であり、世界で最も有名なエンタープライズ向けデータベースソリューションの一つです。

## 主要バージョン

### Oracle Database 26ai
Oracle Database 26ai（正式名称：Oracle AI Database 26ai）は、2026年にリリースされた Oracle Database の最新バージョンです。このバージョンは高度な人工知能機能を統合し、強化された自動化管理とパフォーマンス最適化機能を提供します。

**注記**：Oracle Database 26ai は最新リリースバージョンです。詳細な技術ドキュメントについては、Oracle 公式ウェブサイトを参照してください。

### Oracle Database 19c
Oracle Database 19c は、Oracle Database の長期サポートバージョンであり、安定性と信頼性に優れたエンタープライズ向けデータベース機能を提供します。このバージョンは、Windows x64、Linux x86-64、Linux ARM、Solaris、AIX、HP-UX、Linux on System z など、複数のオペレーティングシステムプラットフォームをサポートしています。

## コア機能

- **高可用性**：Real Application Clusters (RAC)、Data Guard などの高可用性ソリューションを提供
- **セキュリティ**：透明なデータ暗号化、監査、アクセス制御を含む高度なセキュリティ機能を内蔵
- **スケーラビリティ**：単一インスタンスから大規模分散クラスターまでのさまざまなデプロイメントモデルをサポート
- **パフォーマンス最適化**：自動 SQL チューニング、メモリ管理、ストレージ最適化
- **マルチモデルサポート**：リレーショナル、JSON、XML、グラフなど複数のデータモデルをサポート
- **クラウドネイティブ**：コンテナ化デプロイメントとクラウド環境統合をサポート
