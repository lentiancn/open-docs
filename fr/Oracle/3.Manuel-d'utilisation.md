# Manuel d'Utilisation d'Oracle Database

## Connexion à la Base de Données

### Connexion SQL*Plus
```sql
-- Connexion locale
sqlplus username/password@localhost:1521/SID

-- Connexion distante
sqlplus username/password@hostname:1521/service_name

-- Connexion administrateur système
sqlplus / as sysdba
```

### Chaîne de Connexion JDBC

## Opérations SQL de Base

### Langage de Définition de Données (LDD)
```sql
-- Créer une table
CREATE TABLE employees (
    employee_id NUMBER PRIMARY KEY,
    first_name VARCHAR2(50),
    last_name VARCHAR2(50) NOT NULL,
    email VARCHAR2(100) UNIQUE,
    hire_date DATE DEFAULT SYSDATE,
    salary NUMBER(8,2)
);

-- Modifier la structure de la table
ALTER TABLE employees ADD department_id NUMBER;
ALTER TABLE employees MODIFY salary NUMBER(10,2);
ALTER TABLE employees DROP COLUMN department_id;

-- Supprimer une table
DROP TABLE employees;
```

### Langage de Manipulation de Données (LMD)
```sql
-- Insérer des données
INSERT INTO employees (employee_id, first_name, last_name, email, salary)
VALUES (101, 'John', 'Doe', 'john.doe@example.com', 5000.00);

-- Interroger les données
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > 4000
ORDER BY last_name;

-- Mettre à jour les données
UPDATE employees
SET salary = salary * 1.1
WHERE department_id = 10;

-- Supprimer des données
DELETE FROM employees
WHERE employee_id = 101;
```

## Programmation PL/SQL

### Procédures Stockées
```sql
CREATE OR REPLACE PROCEDURE update_employee_salary(
    p_employee_id IN NUMBER,
    p_new_salary IN NUMBER
)
IS
BEGIN
    UPDATE employees
    SET salary = p_new_salary
    WHERE employee_id = p_employee_id;
    
    IF SQL%ROWCOUNT = 0 THEN
        RAISE_APPLICATION_ERROR(-20001, 'Employee not found');
    END IF;
    
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE;
END;
/
```

### Fonctions
```sql
CREATE OR REPLACE FUNCTION get_employee_name(
    p_employee_id IN NUMBER
) RETURN VARCHAR2
IS
    v_full_name VARCHAR2(101);
BEGIN
    SELECT first_name || ' ' || last_name
    INTO v_full_name
    FROM employees
    WHERE employee_id = p_employee_id;
    
    RETURN v_full_name;
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        RETURN NULL;
END;
/
```

### Déclencheurs (Triggers)
```sql
CREATE OR REPLACE TRIGGER employees_audit_trigger
    BEFORE INSERT OR UPDATE OR DELETE ON employees
    FOR EACH ROW
DECLARE
    v_action VARCHAR2(10);
BEGIN
    IF INSERTING THEN
        v_action := 'INSERT';
    ELSIF UPDATING THEN
        v_action := 'UPDATE';
    ELSE
        v_action := 'DELETE';
    END IF;
    
    INSERT INTO employees_audit (
        employee_id, action, action_date, user_name
    ) VALUES (
        NVL(:OLD.employee_id, :NEW.employee_id),
        v_action,
        SYSDATE,
        USER
    );
END;
/
```

## Optimisation des Performances

### Gestion des Index
```sql
-- Créer un index B-tree
CREATE INDEX idx_employees_last_name ON employees(last_name);

-- Créer un index bitmap (approprié pour les colonnes à faible cardinalité)
CREATE BITMAP INDEX idx_employees_department ON employees(department_id);

-- Créer un index basé sur une fonction
CREATE INDEX idx_employees_upper_name ON employees(UPPER(last_name));
```

### Analyse du Plan d'Exécution
```sql
-- Afficher le plan d'exécution
EXPLAIN PLAN FOR
SELECT * FROM employees WHERE last_name = 'Smith';

SELECT * FROM TABLE(DBMS_XPLAN.DISPLAY);
```

### Collecte des Statistiques
```sql
-- Collecter les statistiques de table
EXEC DBMS_STATS.GATHER_TABLE_STATS('HR', 'EMPLOYEES');

-- Collecter les statistiques de schéma
EXEC DBMS_STATS.GATHER_SCHEMA_STATS('HR');
```

## Sauvegarde et Restauration

### Sauvegarde RMAN
```bash
# Se connecter à RMAN
rman target /

# Sauvegarde complète de la base de données
BACKUP DATABASE;

# Sauvegarde incrémentielle
BACKUP INCREMENTAL LEVEL 1 DATABASE;

# Sauvegarde des journaux d'archivage
BACKUP ARCHIVELOG ALL;
```

### Export/Import Data Pump
```bash
# Exporter toute la base de données
expdp system/password FULL=Y DIRECTORY=DATA_PUMP_DIR DUMPFILE=full_db.dmp

# Exporter un schéma spécifique
expdp hr/hr SCHEMAS=HR DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp

# Importer des données
impdp system/password DIRECTORY=DATA_PUMP_DIR DUMPFILE=hr_schema.dmp
```

## Surveillance et Gestion

### Vues Dynamiques de Performance
```sql
-- Afficher les informations de session
SELECT sid, serial#, username, status, machine, program
FROM v$session
WHERE username IS NOT NULL;

-- Afficher les informations de verrouillage
SELECT session_id, lock_type, mode_held, mode_requested
FROM dba_locks;

-- Afficher l'utilisation de l'espace de table
SELECT tablespace_name, 
       ROUND(SUM(bytes)/1024/1024, 2) AS size_mb,
       ROUND(SUM(maxbytes)/1024/1024, 2) AS max_size_mb
FROM dba_data_files
GROUP BY tablespace_name;
```

## Nouvelles Fonctionnalités d'Oracle Database 26ai

Oracle Database 26ai introduit des fonctionnalités d'automatisation pilotées par l'IA :
- **Réglage Automatique SQL** : L'IA analyse les modèles de requêtes et optimise automatiquement
- **Maintenance Prédictive** : Prédit les problèmes potentiels et fournit des alertes précoces
- **Gestion Intelligente des Ressources** : Ajuste dynamiquement l'allocation de mémoire et de CPU
- **Surveillance de Sécurité Améliorée** : Détection d'anomalies pilotée par l'IA

La documentation détaillée des nouvelles fonctionnalités doit être consultée sur le site officiel d'Oracle.

## Bonnes Pratiques

- Utiliser des politiques de mot de passe robustes

- Configurer Data Guard ou RAC

- Surveiller l'état de santé du système
