# Yarn 包管理器

Yarn 是一个专注于速度、正确性、安全性和开发者体验的开源包管理器，用于管理 JavaScript 项目中的依赖关系。

## 版本概述

### Yarn 4+ (现代版本)
- **官方文档**: https://yarnpkg.com/
- **状态**: 活跃开发和维护
- **特点**: 
  - 工作区支持（首个专门为工作区构建的包管理器）
  - 稳定性保证（今天能工作的安装在未来也会以相同方式工作）
  - 插件系统（提供解决各种问题的工具）
  - 创新性（挑战现状，改进工作流程）
  - 完全独立的开源项目

### Yarn v3
- **官方文档**: https://v3.yarnpkg.com/
- **状态**: 维护中
- **特点**: Yarn Berry 的进一步演进，适用于大型单体仓库和企业用户

### Yarn Classic (v1)
- **官方文档**: https://classic.yarnpkg.com/
- **状态**: 维护中（但已不是主要推荐版本）
- **特点**: 传统的 Yarn 包管理器，与 npm 元数据格式兼容

## 核心功能

- **速度**: 并行安装、离线缓存
- **正确性**: 确定性安装、锁定文件
- **安全性**: 硬化模式、漏洞审计
- **开发者体验**: 交互式命令、完整的 CLI 重实现

## 与其他包管理器的区别

与其他大多数包管理器不同，Yarn 重新实现了所有命令，而不是依赖 npm 来处理非安装相关的命令。这使得 Yarn 能够完全控制开发者体验和稳定性。

## 适用场景

- 简单的个人项目
- 大型企业级单体仓库
- 开源项目开发
- 需要稳定依赖管理的生产环境
